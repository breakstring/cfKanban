## 首页与本地闲置

公开首页右上角提供账户入口，只读核验当前 Cookie Session。有有效 Session 时显示“进入工作台”，点击重新核验并使用服务端安全的同站 `entry_path`；无 Session 时显示 Passkey 登录。临时网络故障不作为未登录证据，既有 scope 不扩大，也不因读取首页而续期。

本地回环服务已兑换的 view 不因普通闲置销毁 Bridge、binding、checkpoint 或原操作账本；只要进程仍在固定 8 小时生命周期内，原 Cookie 持有者可继续操作。无 view 且无未确定写入时，15 分钟闲置退出。每次业务操作仍核验当前私有 Credential、固定 Principal 和实时 Project 权限，不新增后台远端数据轮询，不自动重放写入。显式关闭释放 view；页签离开采用带当前页面代际的释放请求和 60 秒宽限，刷新或 BFCache 不破坏恢复，迟到旧页面释放不能关闭新页面。未确定操作阻止普通释放。服务关闭、连接中断或 8 小时绝对截止后明确提示让 Agent 重新打开，并保留对原不确定写入的核实要求。

## 分组、树与进度

本地列表复用看板的五个状态独立查询与 cursor。展示顺序为进行中、待办、Backlog、已完成、已取消，后两组默认折叠；每组可独立展开、滚动续页和手动加载。每次状态页最多 25 条，状态筛选缩小所查分组，其余筛选仍在服务端分页前执行。组数量表示已加载真实事项，仍有下一页加“+”；父上下文行不计入数量。每组最多 1000 条摘要、40 次成功分页，集合字节及完整快照结构预算继续适用；达到上限提示缩小范围，不冒充已加载全部。

同组已加载父 Issue 使用真实行，未在本组页内的直接父以只读上下文行显示；可以折叠已加载的后代，缺失的祖先不全历史追查。关系保留多父语义，展示选择服务端稳定排序的首个可见父，并提示其余父数量。跨项目上下文不能通过本地 binding 越界打开或修改。历史循环采用迭代检测、确定性切断展示连接及异常提示，每个匹配 Issue 只出现一次，不写回关系；深层树限制视觉缩进，保留行和导航。

完整 Web 与本地看板、列表共用直接子事项 `done/total` 进度指示。仅统计当前身份与 Session 可读、未删除且容器活动的直接子 Issue；`done` 才表示完成，`canceled` 仍计入分母。子进度不受当前事项列表的状态、优先级或负责人筛选影响，不统计孙级，隐藏事项不得影响可见计数。零子事项不显示进度；旧 Service 没有层级字段时不伪造计数。已知状态修改后刷新已加载父的进度，读回失败隐藏未核验的进度。

## API 与查询

Issue 读取投影增加可选 `hierarchy: {parents, parent_count, children: {total, done}}`。每个父摘要包含稳定 ID、identifier、title、workspace_id、project_id、status.key / display_name。父摘要按 number 升序，最多 10 个；`parent_count` 表示所有当前可见直接父数量，其余关系继续通过已有分页关系 API 读取。普通列表、候选、详情和 context 共用此投影；写响应可以省略，新客户端兼容旧响应。

仅对当前页的有界 Issue ID 集合，通过现有 source / target 关系索引读取直接关系和端点权限，不为每张卡发出详情 HTTP 请求，不扫全部 Issue 历史。统计随当前页相关关系规模增长，精确子计数不承诺固定页大小读量。SQL 与返回前继续核验来源、Session、容器和实时授权。既有排序、筛选 hash、cursor、CAS 及完成证据规则不变；复用现有索引，无新增 migration。查询计划与本地 D1 `rows_read` / `rows_written` 用隔离 fixture 记录，不冒充线上计费证据。

## 父子关系防环

API 的 `parent` 方向为 source 子事项指向 target 父事项。新建或恢复 parent 边时，必须在同一原子写事务中检查 target 沿父边是否能到达 source；并发相向或交叉写入也不能形成新环。检查使用去重递归遍历，包含同 Workspace 内所有未软删除的 parent 关系，不因中间端点无权、Issue 软删除或容器暂停而遗漏路径；这些端点恢复后不应凭空形成环。读取仍按实时可见性过滤，不暴露检查路径。

可达 source 时返回 `RELATION_CYCLE`（409，`choose_different_parent`）。最多探测 1000 个不同祖先（包含 target）；达到第 1001 个而无法安全证明时返回 `RELATION_GRAPH_TOO_LARGE`（400，`simplify_parent_graph`），不得将截断结果解释为无环。预算控制节点数量，高密度关系仍可能多读边。错误不返回祖先路径、实际数量或不可见端点。原两端 CAS、权限、幂等和原子审计继续有效，拒绝不改变任何业务行或完成记录。历史关系不自动删除或改写，普通 `related` 关系不受父子防环约束。

## 验收

覆盖首页已登录 / 未登录 / 故障、同 scope 返回、本地超过原闲置阈值的导航、关闭 / 刷新 / 迟到释放与 pending；列表独立状态页、失败保留 cursor、并发和旧响应失效、容量与折叠；多父、跨状态上下文、历史环与深树；可见直接进度、隐藏端点及撤销 / 权限变化；防环新建 / 恢复 / 并发、不可见路径和范围预算。实际运行证据保存在上述 Issue 的完成记录。
