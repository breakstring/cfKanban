# Machine-readable contracts

This directory contains executable contract artifacts derived from the Frozen
product contracts and the API/Schema SPEC.

- `openapi.json` is generated by `npm run contracts:generate` and currently
  describes 91 validated operations.
- Edit `scripts/generate-openapi.mjs`, not the generated JSON file directly.
- `npm run contracts:check` verifies the tracked artifact without rewriting it;
  any generated drift fails validation and points back to the explicit generate
  command.
- The API/Schema SPEC is Frozen at contract version 0.1.0. These artifacts are
  stable implementation inputs, but they are not evidence that an endpoint has
  been implemented or deployed.
