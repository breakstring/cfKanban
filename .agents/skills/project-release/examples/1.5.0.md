# cfKanban 1.5.0

## 简体中文

相对 `1.4.0`，本正式版让日常看板操作更连贯，增加个人主题，并改善首次页面加载。

- 登录后的看板、Issue、个人设置和管理页面采用一致的操作界面，适配桌面与手机，并完善键盘操作。
- 可选择「暖橙」或「静蓝」主题；偏好随账户保存，重新登录或换浏览器后仍然保留，Web 与 Agent 均可修改。
- 看板列数准确反映当前筛选的匹配总数；新建、移动、完成和改优先级后局部更新卡片，保留已加载内容和滚动位置。
- 业务页面按需加载，减少首次打开公开首页所需的脚本；页面加载失败可显式重试。
- 普通安装继续默认发现最新正式版；支持 Git 来源的 Agent 宿主可跟随正式 `main`，无需为日常更新固定版本 tag。

## English

Compared with `1.4.0`, this stable release makes everyday board operations smoother, adds personal themes, and improves initial page loading.

- Boards, Issues, personal settings, and management pages share a consistent interface, with desktop/mobile layouts and improved keyboard interaction.
- Choose Warm orange or Calm blue. Preferences stay with your account after signing in again or switching browsers, and both Web and Agent clients can update them.
- Column counts reflect all matches for current filters. Creating, moving, completing, or reprioritizing an Issue updates its card locally while retaining loaded content and scroll positions.
- Business pages load on demand, reducing the scripts needed when first opening the public homepage. Failed page loads offer explicit retry.
- Ordinary installation continues to discover the latest stable release. Git-backed Agent hosts can follow stable `main` without pinning a version tag for routine updates.

## 升级与已知限制 / Upgrade and known limitations

从 `1.4.0` 升级须先应用 `0014_principal_theme.sql`，将 schema `13` 升至 `14`，再部署 Worker；已使用 1.5.0 RC 且 ledger 与实际 schema 均确认是 `14` 的实例无新增 migration。API 兼容版本仍为 `0.1.0`，无新增云资源、付费要求或权限。Skills 更新与实例升级分别执行。

When upgrading from `1.4.0`, apply `0014_principal_theme.sql` to advance schema `13` to `14` before deploying the Worker. Instances already on a 1.5.0 RC with both the ledger and actual schema verified as `14` need no new migration. API compatibility remains `0.1.0`; no cloud resources, paid requirements, or permissions are added. Skill updates and instance upgrades are separate operations.

首次进入按需加载页面仍需下载资源，会话固定有效 8 小时且不自动续期。首屏改善来自[本地性能测量](https://github.com/breakstring/cfKanban/blob/b8210c40dc4d481e9cc21f1f49cda675d9e83fd1/docs/research/2026-10-01-web-initial-load-performance.md)，不代表线上性能结论。验收与发行证据见 [CFK-536](https://cfkanban.dev/app/issues/CFK-536) / [CFK-537](https://cfkanban.dev/app/issues/CFK-537)。

The first visit to an on-demand page still downloads resources. Sessions expire after eight hours and do not renew automatically. Initial-load improvements come from [local performance measurements](https://github.com/breakstring/cfKanban/blob/b8210c40dc4d481e9cc21f1f49cda675d9e83fd1/docs/research/2026-10-01-web-initial-load-performance.md), rather than live performance results. See [CFK-536](https://cfkanban.dev/app/issues/CFK-536) / [CFK-537](https://cfkanban.dev/app/issues/CFK-537) for acceptance and release evidence.
