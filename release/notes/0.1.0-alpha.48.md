# cfKanban 0.1.0-alpha.48

## English

- Resolve the trusted local instance before opening Web: explicit target, repository scope, then a unique local Credential; ambiguous candidates require one choice.
- Add `host_browser` delivery for IAB and named browsers using a single-use, 60-second loopback handoff. Remote tickets stay in memory.
- Treat opening cfKanban as authenticated navigation and verify the final identity/target page.
- This update changes the Git marketplace plugin only. It does not publish a canonical bundle or upgrade an Instance; the existing verified deployment pointer remains unchanged.

## 简体中文

- 打开 Web 前解析本地可信实例：明确目标、仓库范围、本地唯一凭据；多个候选只询问一次。
- 新增 IAB 与指定浏览器的 `host_browser` 交付，使用一次性、60 秒有效的本机入口，远端票据只留在内存。
- 将打开 cfKanban 解释为认证后进入，并验证最终身份与目标页面。
- 本次只更新 Git marketplace 插件，不发布 canonical bundle、不升级实例；既有可验证部署指针保持不变。
