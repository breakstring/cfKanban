# cfKanban 0.1.0-alpha.27

Testing prerelease / 测试发行版

## English

This testing prerelease makes the Cloudflare authentication resolver's required private execution context explicit and recoverable.

Changes:

- requires an absolute private cfKanban deployment/config `contextDirectory` outside user repositories even when `selectedProfile` is supplied;
- explains that this directory is only a controlled Wrangler cwd for the bounded membership probe and is not persisted as a second auth source in a named-profile deployment plan;
- returns `CLOUDFLARE_AUTH_CONTEXT_REQUIRED` before starting Wrangler when the directory is missing, with a concrete recovery that rejects `process.cwd()` and user repositories;
- exposes the same requirement in command help, the portable deployment Skill, and its English and Simplified Chinese workflow guides;
- adds regression coverage for the missing-input boundary and the self-describing command catalog.

The Service implementation, REST API, D1 schema, and Web UI are unchanged from alpha.26. Existing alpha.26 instances do not need a Worker deployment; the alpha.27 Skill bundle remains compatible with them. The paired Service bundle is still published so the immutable release manifest remains complete.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.27
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行把 Cloudflare 认证 resolver 必需的私有执行上下文说清楚，并提供可直接照做的恢复方式。

变更：

- 即使传入 `selectedProfile`，也必须提供位于用户仓库之外、绝对路径形式的私有 cfKanban 部署/config `contextDirectory`；
- 明确该目录只是有界 membership 探测所需的 Wrangler 受控 cwd，named-profile 部署计划不会把它保存为第二个认证来源；
- 缺少目录时，在启动 Wrangler 前返回 `CLOUDFLARE_AUTH_CONTEXT_REQUIRED`，并明确要求补传私有路径，不能改用 `process.cwd()` 或用户仓库；
- 命令 help、portable 部署 Skill 与中英文工作流说明使用同一合同；
- 增加缺参边界和自描述命令目录的回归测试。

Service 实现、REST API、D1 schema 与 Web UI 相对 alpha.26 均未变化。现有 alpha.26 实例无需重新部署 Worker；alpha.27 Skill bundle 与其保持兼容。发行仍提供配对的 Service bundle，以保持不可变 manifest 完整。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.27
codex plugin add cfkanban-agent-skills@cfkanban
```
