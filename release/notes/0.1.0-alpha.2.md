# cfKanban 0.1.0-alpha.2

Testing prerelease / 测试发行版

## English

This testing prerelease keeps the same cfKanban Service and deployment safety model as `0.1.0-alpha.1`, while expanding the verified local toolchain range to Node.js 26.

Changes:

- accepts Node.js `>=22.12.0 <27` for the bundled Skills and Wrangler workflow;
- keeps Wrangler pinned to `4.127.1` and the Service API compatibility range unchanged;
- records the release inputs in a versioned machine-readable configuration;
- updates the plugin, documentation, and testing pointer to this immutable release.

The complete repository validation, including Wrangler local D1, Worker integration tests, and the production build dry run, was run with Node.js `26.8.1` before publication.

Important limits:

- this is not the stable channel and must be selected explicitly;
- use a non-production Cloudflare account and review the exact plan before approving real cloud writes;
- resource cleanup is separate and is never performed automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.2
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这个测试发行版保持 `0.1.0-alpha.1` 的 cfKanban Service 和部署安全模型不变，同时把经过验证的本地工具链范围扩展到 Node.js 26。

变更：

- bundled Skills 与 Wrangler 流程现在接受 Node.js `>=22.12.0 <27`；
- Wrangler 仍固定为 `4.127.1`，Service API 兼容范围不变；
- 使用版本化的机器可读配置记录发行输入；
- plugin、文档和测试发行指针全部更新到这个不可变版本。

发布前已使用 Node.js `26.8.1` 执行完整仓库验证，包括 Wrangler local D1、Worker 集成测试和生产构建 dry run。

重要限制：

- 这不是稳定发行通道，必须由用户明确选择；
- 请使用非生产 Cloudflare 账户，并在授权真实云端写入前核对准确计划；
- 资源清理是独立操作，绝不会自动执行。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.2
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-deploy 为我部署一套 cfKanban。
```
