# cfKanban 0.1.0-alpha.50

## English

- Fix the health endpoint reporting schema version 1 after the container purge migration. Health and bootstrap now derive the supported schema version from the migration manifest, allowing verified upgrade finalization.
- Retain the compact Archive/Restore UI and guarded permanent deletion introduced in alpha.49. No additional migration or data deletion is performed by this release.

## 简体中文

- 修复容器永久删除迁移完成后健康检查仍报告 schema 1 的问题。健康检查与首次初始化统一从迁移清单读取支持的 schema 版本，使升级验收能够准确收口。
- 保留 alpha.49 的紧凑归档/恢复界面和受保护的永久删除功能。本版没有新增迁移，发布本身不会删除业务数据。
