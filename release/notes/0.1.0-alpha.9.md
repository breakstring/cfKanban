# cfKanban 0.1.0-alpha.9

Testing prerelease / 测试发行版

## English

This testing prerelease simplifies Wrangler profile/account handling and fixes the D1 migration readback problem found during the `0.1.0-alpha.8` deployment rehearsal.

Changes:

- reuses an exact profile/account already frozen in a journal or receipt before rediscovery;
- otherwise asks Wrangler to resolve the current private deployment/config context first, following environment-token, directory-bound, and default-profile precedence;
- only after that context fails, lists bounded profile names and inspects account memberships for the sole or explicitly selected profile instead of enumerating every profile;
- prevents an unrelated or stale profile from blocking a usable current/selected context;
- continues to pin the exact account in private `wrangler.jsonc.account_id`; explicitly selected named profiles use `--profile`, while environment/config-directory resolution remains Wrangler-owned;
- executes fixed migration SELECT readback with `d1 execute --command --json`, because Wrangler's remote `--file` ingestion path returns statistics rather than SELECT rows;
- validates exactly two successful readback result sets and returns only bounded ledger/table/index facts, never raw schema SQL;
- updates the Frozen Agent Skills contract, English/Simplified Chinese operational documents, plugin metadata, and tests.

The `0.1.0-alpha.8` rehearsal created the test D1 and initialized its checksum-ledger table, then stopped safely before the initial application migration. No Worker or Owner Credential was created. This release can resume that unchanged journal and Service plan after the local Skill update is separately authorized.

Important limits:

- this is not the stable channel and must be selected explicitly;
- use a non-production Cloudflare account and review each exact local, authentication, and deployment plan before approval;
- resource cleanup is separate and is never performed automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.9
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这个测试发行版简化了 Wrangler profile/account 处理，并修复 `0.1.0-alpha.8` 部署演练发现的 D1 migration 读回问题。

变更：

- 重新发现前，先复用 journal 或 receipt 中已固定的准确 profile/account；
- 其他情况先让 Wrangler 按环境 Token、目录绑定和 default profile 的优先级解析当前私有部署/config 上下文；
- 只有当前上下文失败后才列出范围受控的 profile 名称，并且只检查唯一或用户明确选中 profile 的 account memberships，不再遍历所有 profiles；
- 无关或失效 profile 不再阻塞可用的当前/选中上下文；
- 继续用私有 `wrangler.jsonc.account_id` 固定准确 account；明确选择的 named profile 使用 `--profile`，环境/config 目录解析仍交给 Wrangler；
- 固定 migration SELECT 读回改用 `d1 execute --command --json`，因为 Wrangler 的远端 `--file` ingestion 路径只返回统计信息而没有 SELECT rows；
- 严格验证两个成功的 readback result sets，并且只返回有界 ledger/table/index facts，不返回原始 schema SQL；
- 同步更新 Frozen Agent Skills 合同、English/简体中文操作文档、plugin metadata 与测试。

`0.1.0-alpha.8` 演练已经创建测试 D1 并初始化 checksum-ledger table，随后在初始应用 migration 之前安全停止；没有创建 Worker 或 Owner Credential。本版在本地 Skill 更新单独获得授权后，可以沿用未变化的 journal 与 Service plan 继续。

重要限制：

- 这不是稳定发行通道，必须由用户明确选择；
- 请使用非生产 Cloudflare 账户，并分别核对准确的本地、认证与部署计划后再授权；
- 资源清理是独立操作，绝不会自动执行。

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.9
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：
