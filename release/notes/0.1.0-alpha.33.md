# cfKanban 0.1.0-alpha.33

Testing prerelease / 测试发行版

## English

This testing prerelease turns the public instance home into a complete starting point and fixes two contracts exposed by live dogfooding.

Changes:

- adds versioned English and Simplified Chinese deployment and joining guides to every Service bundle, with concrete Skill installation, environment, authorization, deployment/join, readback, and recovery steps;
- routes the public deployment prompt, Public Join copy, and one-time Invite copy through those guides instead of asking an unprepared Agent to infer a workflow from the README;
- gives the public home an intentional two-line, locale-responsive Agent-first headline and an understated footer for guides, OpenAPI, source, Service version, and Instance identity;
- treats one-time-delivery `event_cursor` values as bounded opaque strings instead of assuming decimal digits, fixing a false failure after a successfully created Browser Launch;
- makes OpenAPI, the Admin Skill, and Owner Web say explicitly that Public Join and resource-limit CAS writes use `project.version`, while `policy_version` is read-only policy history;
- keeps the internal Skill E2E Project private and uses a separate Public Demo Project for anonymous enrollment and homepage testing.

The D1 schema and deployment topology are unchanged from alpha.32. Existing instances can upgrade by deploying the alpha.33 Service bundle without a D1 migration. Local Skill update and Instance upgrade remain independent.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.33
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行把公开实例首页补成了一个完整入口，并修复真实 dogfood 暴露出的两处合同问题。

变更：

- 每个 Service bundle 新增带版本的 English/简体中文部署与加入指南，逐步说明 Skill 安装、环境、授权、部署/加入、读回和恢复；
- 公开部署话术、Public Join 话术和一次性 Invite 话术都先指向专用指南，不再让尚未准备好的 Agent 从 README 自己猜流程；
- 公开首页采用按语言调整的固定双行 Agent-first 标题，并增加克制页脚，提供指南、OpenAPI、源码、Service 版本和 Instance 身份；
- 把一次性交付的 `event_cursor` 当作有界不透明字符串，不再假设它只能是十进制数字，修复 Browser Launch 已成功创建后被客户端误报失败的问题；
- OpenAPI、Admin Skill 与 Owner Web 直接说明 Public Join 和 resource-limit 写入使用 `project.version` 做 CAS，`policy_version` 只表示只读 Policy 历史；
- 内部 Skill E2E Project 保持非公开，匿名加入与首页测试改用独立的“公开演示项目”。

D1 schema 与部署拓扑相对 alpha.32 均未变化。现有实例可以直接部署 alpha.33 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是彼此独立的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.33
codex plugin add cfkanban-agent-skills@cfkanban
```
