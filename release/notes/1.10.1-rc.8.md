# cfKanban 1.10.1-rc.8

## 简体中文

相对 `1.10.1-rc.7`，本 RC 让项目看板与列表容纳更多内容，并将用量与访问设置集中到一次保存的表单中。

- 统计、每日历史、账户汇总、套餐声明、UTC 账期及五组访问频率集中在常驻表单中，草稿实时展示前后差异，一次保存所有修改。
- 保存使用同一配置计划与一次 Worker 配置写入；冲突保留草稿，结果未知时按原请求核验，不自动重新写入。
- Agent 与公共 CLI 支持同样的多项配置及原请求查询；旧单项配置与历史操作恢复保持兼容。
- 修复配置读回发生外部漂移后无法恢复原正确版本的问题。附件存储上限仍使用独立的应用设置入口。
- 压缩完整版 Web 与本地工作台的项目标题、视图切换和筛选区域；窄屏保留可操作的筛选与展开入口，长描述可滚动阅读。

## English

Compared with `1.10.1-rc.7`, this RC gives project boards and lists more room and combines usage and access settings in a form that saves all changes together.

- Analytics, daily history, account totals, the declared plan, UTC billing cycle, and five request limits share one persistent form. Drafts show before/after differences and save together.
- Saving uses one configuration plan and one Worker settings write. Conflicts preserve drafts; uncertain outcomes are checked using the original request without another write.
- Agents and the public CLI support the same combined configuration and original-request lookup. Existing individual settings and historical operation recovery remain compatible.
- Configuration readback can recover the original matching version after external drift. Attachment capacity keeps its separate application setting.
- Compact project headers, view controls, and filters in the full Web UI and local workbench make more room for Issues. Narrow screens retain usable filter and expand controls, and long descriptions remain scrollable.

## 升级与已知限制 / Upgrade and known limitations

相对 `1.10.1-rc.7` 无新增 migration，schema 保持 **27**，API 保持 **0.1.0**；升级仍需核对真实 ledger/schema。套餐是已有 Cloudflare 配置声明，不会购买订阅。历史与账户汇总仍需显式开启；未知写入保留原请求与锁。

No migration is added relative to `1.10.1-rc.7`: schema remains **27** and API remains **0.1.0**; the actual ledger and schema must still be checked during upgrade. The plan field describes existing Cloudflare configuration and does not purchase a subscription. History and account totals require explicit opt-in; uncertain writes retain their original request and lock.
