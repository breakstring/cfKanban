# cfKanban 1.9.4-rc.1

## 简体中文

相对正式版 `1.9.3`，本 RC 精简接入和使用文档，让用户先通过技能协作，再按需要使用宿主扩展。

- Codex App 和 DeepSeek Harness 指南先介绍技能与自然语言任务，侧栏、看板和搜索作为增强体验。
- Codex App 页面保留常用提示词、搜索步骤和实际配图，安装、更新与常见问题更简洁。
- 文档站的命令行栏目标注 CLI，页头新增官方 GitHub 入口，窄屏也可从导航菜单访问。
- 移除公开 MCP 接入参考和相关推荐链接，让接入指南聚焦用户实际使用。

## English

Compared with stable `1.9.3`, this RC simplifies integration and usage guides, putting collaboration through Skills before optional host extensions.

- Codex App and DeepSeek Harness guides introduce Skills and natural-language tasks first, with sidebars, boards and search as additional features.
- The Codex App guide keeps common prompts, search steps and real screenshots while shortening setup, update and troubleshooting instructions.
- The documentation's command-line section now includes CLI in its title. A new official GitHub link is available in the header and narrow-screen navigation menu.
- Removes the public MCP connection reference and recommendations linking to it, keeping integration guides focused on everyday use.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.3` 升级无新增 migration，schema 保持 **20**，API 保持 **0.1.0**，仍需核对实际 ledger/schema。新版在线文档随 Service 升级提供；本地技能更新分别进行。原公开 MCP 参考的 HTML 和 Markdown 地址退役后返回 404，请使用 [Agent 接入指南](https://cfkanban.dev/docs/zh-CN/integrations/)。

Upgrading from `1.9.3` adds no migration, retaining schema **20** and API **0.1.0**; verify the actual ledger/schema. Updated online documentation ships with the Service upgrade, independently of local Skill updates. The retired public MCP reference's HTML and Markdown URLs return 404; use the [Agent integration guides](https://cfkanban.dev/docs/en/integrations/).

文档与本地验收 / Documentation and local acceptance: [CFK-616](https://cfkanban.dev/app/issues/CFK-616). 发行与实例升级 / Release and instance upgrade: [CFK-617](https://cfkanban.dev/app/issues/CFK-617).
