# cfKanban 0.1.0-alpha.13

Testing prerelease / 测试发行版

## English

This testing prerelease removes an unnecessary repeated-confirmation trap discovered while resuming the alpha.12 Owner-bootstrap recovery.

Changes:

- makes the strict-zero plan explicitly declare that a zero-state-proven Owner-bootstrap retry is included in the full deployment authorization;
- tells the deployment Skill to request approval for the complete plan instead of asking the user to authorize one command or one process attempt;
- continues the same task, operation, plan, config, SQL, pending Credential, and Cloudflare target after an `absent` readback without another application-level confirmation;
- still requires new authorization for a new task, any plan drift, or an explicitly user-authored narrower limit;
- keeps alpha.12's fixed six-table readback, one guarded retry per fresh readback, and stop behavior for present, partial, malformed, successful, or drifted state.

This changes the Skill and future plan shape only. It does not require an already deployed alpha.8 Service bundle to be upgraded.

Important limits:

- this is not the stable channel and must be selected explicitly;
- use a non-production Cloudflare account and review the exact complete deployment plan before approval;
- host or operating-system permission prompts remain independent of cfKanban's application-level authorization.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.13
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这个测试发行版修复了 alpha.12 Owner bootstrap 恢复演练中发现的不必要重复确认问题。

变更：

- strict-zero plan 会明确声明：经零状态证明安全的 Owner bootstrap 重试已经包含在完整部署授权中；
- 部署 Skill 必须请求完整计划授权，不能让用户单独授权某一个命令或某一次进程执行；
- `absent` 读回后，只要 task、operation、plan、config、SQL、pending Credential 和 Cloudflare target 均未变化，就不再重复索要应用层确认；
- 新任务、任何 plan 漂移或用户亲自提出的更窄限制仍需要新授权；
- 保留 alpha.12 的固定六表读回、每次新鲜读回只放行一次受保护重试，以及对存在、部分、畸形、已成功或漂移状态的停止规则。

本次只改变 Skill 与后续生成的 plan 结构；已经部署的 alpha.8 Service bundle 无需因此升级。

重要限制：

- 这不是 stable channel，必须由用户明确选择；
- 请使用非生产 Cloudflare 账户，并在授权前核对准确的完整部署计划；
- Agent 宿主或操作系统自己的权限提示仍独立于 cfKanban 应用层授权。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.13
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-deploy 为我部署一套 cfKanban。
```
