# cfKanban 1.9.1-rc.3

## 简体中文

相对 `1.9.1-rc.2`，本 RC 让终端与 Agent 更直接地围绕当前项目开展工作。

- 自动识别仓库、子目录及 worktree 上下文，减少重复输入 UUID。
- 用 `context show/use/clear` 查看、保存或切换目录与全局默认范围。
- 终端提供候选选择；JSON、CI 和 Agent 调用返回结构化候选，不等待输入。
- `web open` 可直接打开当前项目看板。
- 帮助和双语文档按查找、创建、推进、评论、完成组织，高级入口按需查看。

## English

Compared with `1.9.1-rc.2`, this RC lets terminal users and Agents work more directly with the current Project.

- Resolve repository, subdirectory and worktree context with fewer repeated UUID arguments.
- Inspect, save or switch directory and global defaults with `context show/use/clear`.
- Offer terminal selections while JSON, CI and Agent calls return structured choices without prompting.
- Open the current Project board directly with `web open`.
- Follow task-focused help and bilingual guides, with advanced commands available when needed.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration；schema 保持 19，API 保持 0.1.0，升级仍需核对真实 ledger/schema。显式 UUID 调用保持兼容，自动补齐范围的调用附带 `resolved_context`。Node 要求仍为 >=22.12.0。CLI 随完整 Skills 更新；本 RC 不推进 stable。Windows 原生、独立 WSL2 与其他 Agent 宿主的真实验收尚未完成。

No new migration is required; schema stays at 19 and API at 0.1.0. Verify the actual migration ledger/schema during upgrade. Explicit-ID calls remain compatible; context-assisted calls add `resolved_context`. Node remains >=22.12.0. The CLI updates with the full Skills bundle; this RC does not advance stable. Native Windows, independent WSL2 and other Agent-host acceptance remain unverified.

验证与发行记录 / Validation and release record: [CFK-597](https://cfkanban.dev/app/issues/CFK-597). 用户将在发布与部署后进行实际使用验收 / User acceptance follows publication and deployment.
