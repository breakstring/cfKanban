# cfKanban 1.10.2

## 简体中文

相对正式版 `1.10.1`，本版精简完整版 WebUI 的 Owner 服务信息区域，移除缺少实例上下文和明确目标的 Agent 复制按钮。

- 「概览 → 服务信息」不再显示无实际用途的「复制给 Agent」按钮。
- 发行版本、实例 ID、当前访问地址和首选地址继续保留，方便查看和排查。
- 首选地址仍在网页中只读；确需修改时，由 Owner 明确提出目标并通过 `cfkanban-admin` 执行。

## English

Compared with stable `1.10.1`, this release simplifies the Owner's service information in the full Web UI by removing an Agent copy button that lacked instance context and a clear goal.

- **Overview → Service information** no longer shows the unhelpful **Copy for Agent** button.
- Release details, the instance ID, the current address and the preferred address remain available for inspection and troubleshooting.
- The preferred address remains read-only in the Web UI. Owners can request a specific change through `cfkanban-admin` when needed.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.1` 升级无新增数据库迁移，schema 保持 **27**，API 保持 **0.1.0**。本次为局部界面修复，按用户授权跳过 RC，使用源码全量验收与正式工件校验直接发布；保留既有身份、资源、配置及数据。

Upgrading from `1.10.1` adds no database migrations; schema remains **27** and API remains **0.1.0**. This localized UI fix goes directly to stable, as authorized, using full source validation and stable artifact verification. Existing identities, resources, configuration and data are preserved.
