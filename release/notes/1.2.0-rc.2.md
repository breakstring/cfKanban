# cfKanban 1.2.0-rc.2

## 简体中文

本候选版本保留 `1.2.0-rc.1` 的 Owner 多设备与已有部署接入能力，修复真实 D1 验收中发现的部署检查失败。

- 已有部署检查在读取业务表列信息前排除 Cloudflare 与 SQLite 保留表，避免对 D1 内部表执行 PRAGMA 时收到 `SQLITE_AUTH`。业务表、migration ledger、schema、资源及 Owner 身份的核验保持不变。
- 增加内部表与业务列共存的回归验证；继续使用有界、只读查询，不修改远端数据或权限。

## English

This candidate retains the Owner multi-device and existing-deployment attachment features from `1.2.0-rc.1` and fixes an inspection failure found during live D1 acceptance.

- Existing-deployment inspection excludes Cloudflare and SQLite reserved tables before reading business-table columns, avoiding `SQLITE_AUTH` from PRAGMA calls against D1 internal tables. Business tables, migration history, schema, resources and Owner identity remain verified.
- Regression coverage checks reserved tables alongside business columns. Inspection continues to use bounded, read-only queries without changing remote data or permissions.

## 升级与验证边界 / Upgrade and verification boundaries

从 `1.2.0-rc.1` 升级没有新的数据库迁移，schema 保持 `12`，API 保持 `0.1.0`。从 `1.1.1` 升级仍只应用 `0012_owner_devices.sql`，增加可空 `credentials.device_name`；既有 Owner 和 Credential 不重签发。

Upgrading from `1.2.0-rc.1` requires no new database migration; schema remains `12` and API remains `0.1.0`. Upgrading from `1.1.1` still applies only `0012_owner_devices.sql`, adding nullable `credentials.device_name` without reissuing the existing Owner or credentials.

这是预发行版，不推进 GitHub Latest 或 canonical stable。跨设备批准/撤销及新会话中的宿主技能加载仍需真实验收；更新磁盘上的 Skills 不会自动重载当前任务已加载的技能。工件、线上部署与本机安装分别读回。

This prerelease does not advance GitHub Latest or the canonical stable pointer. Real cross-device approval/revocation and Skill loading in a new host session remain pending. Updating Skills on disk does not reload those already loaded in the current task. Release artifacts, live deployment and local installation require separate readback.
