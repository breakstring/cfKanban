# cfKanban 1.12.0-rc.6

## 简体中文

RC6 在 RC5 基础上新增公开 `/auth.md`，让 Agent 在接入前读清现有鉴权与凭据获取流程。

- 提供自包含双语 Markdown 指引，说明现有 Bearer 凭据、身份与权限检查，以及邀请和公开加入的凭据获取方式。
- 说明 Agent 打开已登录网页、Passkey、参与者及 Owner 恢复的现有入口，保留原身份与项目权限合同。
- 在 API Catalog、首页、公开 Agent 阅读入口及 robots 中发现同实例 Auth.md，无需 OAuth、额外注册机制或 Owner 设置。

本次无新增数据库迁移，API 兼容版本仍为 0.1.0、schema 仍为 28。读取 Auth.md 不建立身份、不签发凭据、不授予项目权限；原有邀请、公开加入、API 鉴权和安全恢复流程继续有效。无需修改 Cloudflare 控制台设置。本次部署不包含本机 Skill/plugin 更新。

## English

RC6 adds a public `/auth.md` on top of RC5 so Agents can read the existing authentication and credential provisioning workflows before connecting.

- Provide a self-contained bilingual Markdown guide to existing Bearer credentials, identity and permission checks, and credential provisioning through invitations or Public Join.
- Explain the existing entrypoints for Agent-opened browser sessions, Passkeys, and participant or Owner recovery, preserving identity and project permission contracts.
- Discover the same-instance Auth.md through the API Catalog, homepage, public Agent reading entrypoints, and robots without OAuth, another registration mechanism, or an Owner setting.

No new database migrations; API compatibility remains 0.1.0 and schema remains 28. Reading Auth.md does not create an identity, issue a credential, or grant project access. Existing invitation, Public Join, API authentication, and secure recovery workflows remain in effect. No Cloudflare dashboard changes are needed. This deployment does not update local Skills or plugins.
