# cfKanban 1.11.0-rc.1

## 简体中文

相对正式版 `1.10.2`，本 RC 优化 Owner「工作区与项目」的浏览与设置路径，让常用操作更容易找到。

- 工作区与项目行将重命名、公开加入和归档等低频操作收进「更多」，减少重复文字和操作干扰。
- 新建工作区与新建项目采用一致的主次按钮层级；项目说明放在名称下方，长内容和窄屏更易浏览。
- 项目设置统一进入完整设置页；工作区设置直接打开设置分区，管理员和成员仍可在同一管理页面维护。
- 从 Owner 列表进入设置后，可返回管理中心并展开原工作区；设置分区切换保留来路，原看板返回行为继续保留。

## English

Compared with stable `1.10.2`, this RC improves browsing and settings navigation in the Owner's **Workspaces & Projects** section, making common actions easier to find.

- Workspace and project rows move less frequent actions, including rename, Public Join and archive, into **More actions**, reducing repeated text and visual clutter.
- New workspace and new project actions use consistent primary and secondary buttons. Project descriptions sit below names for easier reading with long content and narrow screens.
- Project settings opens the complete settings page. Workspace settings opens its settings section directly, with administrators and members still managed in the same management page.
- Settings opened from the Owner list can return to management with the original workspace expanded. Switching settings sections preserves that origin, while existing board return behavior remains available.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.2` 升级无新增数据库迁移，schema 保持 **27**，API 保持 **0.1.0**；升级前仍需核对真实 ledger/schema。保留既有身份、资源、配置及数据。本版为预发行，GitHub stable 与 main 不随 RC 推进。源码与本地隔离浏览器验收记录见 [CFK-695](https://cfkanban.dev/app/issues/CFK-695)；线上升级结果另行记录，不将本地检查当作线上验收。

Upgrading from `1.10.2` adds no database migrations; schema remains **27** and API remains **0.1.0**. Verify the actual ledger and schema before upgrading. Existing identities, resources, configuration and data are preserved. This is a prerelease and does not advance GitHub stable or main. Source and isolated local browser validation is recorded in [CFK-695](https://cfkanban.dev/app/issues/CFK-695); live upgrade results are recorded separately.
