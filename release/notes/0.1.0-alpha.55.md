# cfKanban 0.1.0-alpha.55

## English

- Refine the overview, board, Issue detail, and project selection layouts, including readable labels, compact status actions, and accessible mobile logout.
- Simplify routine Skill workflows and remove stale container-key guidance. Add bounded file upload, idempotent recovery, and verified download commands.
- Add optional private Issue attachments backed by R2 and D1 metadata. Project permissions cover upload, download, safe image preview, and reversible deletion. Limits are 10 MiB per file, 20 active/pending attachments per Issue, and a 1 GiB instance reservation budget; this is not a Cloudflare billing cap.
- Keep Worker + D1 as the default deployment. Enabling attachments explicitly plans one private Standard R2 bucket, the `ATTACHMENTS` binding, hourly garbage collection, and permission/cost changes. Unknown buckets are never adopted.
- Add schema 4 with `0004_issue_attachments.sql`, retaining existing migration digests. Record a D1 restore point before upgrading; Worker rollback does not revert D1 or delete R2 objects. Skill updates and instance upgrades remain separate operations.

## 简体中文

本次测试发行改善日常 Skill 和 Web 协作体验，并增加可选的私有 Issue 附件。

- **Web**：调整概览、看板、事项详情和项目选择的视觉层级；标签可自然换行，状态操作更紧凑，窄屏保留退出入口与横向看板提示。
- **Skills**：精简重复探索与确认，纠正过时的容器 key 指引，明确 UUID、既有授权和独立更新平面；增加安全的附件上传、恢复重试和下载命令。
- **附件**：支持日志、截图等单文件上传与下载，经过类型校验的常见图片可预览；沿用 Project 权限、Session scope、幂等与 CAS。文件默认最多 10 MiB，每个 Issue 最多 20 个 active/pending 附件，实例预留预算为 1 GiB。预算不是 Cloudflare 账单硬上限。
- **存储**：D1 保存元数据，私有 R2 保存文件；删除可恢复，项目永久清理通过持久队列回收对象。R2 未启用时核心看板继续可用。
- **部署**：默认仍只创建 Worker + D1。附件启用需要显式规划 Standard R2 bucket、`ATTACHMENTS` binding、每小时清理任务以及 Cloudflare 权限和费用影响；不会自动接管同名桶。旧 OAuth profile 可能需要额外授权，脚本不会自动登录或扩大权限。

Schema 从 3 升至 4，新增 `0004_issue_attachments.sql`；既有 migration 内容与 digest 不变。升级前记录 D1 restore point，逐条 migration 与 Worker 发布均需读回。Worker 回滚不会回退 D1，也不会删除 R2 文件。

本版本仍是 prerelease；Skill bundle 更新与云端实例升级分别执行。
