# cfKanban 1.8.0-rc.2

## 简体中文

相对 [1.8.0-rc.1](https://github.com/breakstring/cfKanban/releases/tag/1.8.0-rc.1)，此 RC 补齐 Codex 等 Git 插件副本与已安装本地工作台之间的运行时衔接。

- **从 Git 插件打开本地工作台**：插件副本没有预构建页面时，可加载同版本完整 Skill bundle 中已校验的运行时。
- **准确版本与完整性核验**：缺失、被修改、来源不连续或版本不匹配的 canonical bundle 会明确拒绝，不临时编译、下载或切换线上。
- **更清楚的安装指南**：通用代理集成和日常技能说明 Git 插件与完整 bundle 的职责，以及本地 WebUI 的安装前提。

### 升级与已知限制

没有新增 migration；schema 仍为 18，API 仍为 0.1.0。Git 插件和 canonical Skill bundle 必须更新到同一准确版本；更新后重启所属 MCP / 工作台，并在新 Codex 任务核对 Skills 加载。其它宿主验收范围和本地/线上功能范围沿用 rc.1。普通安装入口继续使用 stable，此 RC 需明确选择。

## English

Compared with [1.8.0-rc.1](https://github.com/breakstring/cfKanban/releases/tag/1.8.0-rc.1), this RC connects Git plugin projections in Codex and similar hosts to the installed local workbench runtime.

- **Open locally from a Git plugin**: When the projection has no prebuilt page, load the verified runtime from the complete Skill bundle of the same release.
- **Verify the exact version and integrity**: Missing, modified, discontinuous, or mismatched canonical bundles are refused without compiling, downloading, or switching online automatically.
- **Clarify installation**: The general integration guide and daily Skill explain the roles of Git plugins and complete bundles, including the local WebUI prerequisites.

### Upgrade and known limitations

No migration is added; schema remains 18 and API remains 0.1.0. Update both the Git plugin and canonical Skill bundle to the same exact release. Restart the owning MCP / workbench and use a new Codex task to verify Skill loading. The host test coverage and local/online feature scope remain those of rc.1. Normal installation continues to select stable; choose this RC explicitly.
