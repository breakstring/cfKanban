# cfKanban 0.1.0-alpha.41

Testing prerelease / 测试发行版

## English

This testing prerelease gives the first-party Web surface one coherent orange interaction palette that fits the cfKanban mark and its Cloudflare deployment context.

Changes:

- replaces the former blue primary, link, focus, selection, and active-control colors with accessible deep-orange and warm-orange tokens;
- keeps the brighter orange brand mark distinct from the deeper control color so white button text retains sufficient contrast;
- removes blue-dominant literal colors from first-party Web source while leaving user-authored Label colors untouched;
- preserves intentional two-line hero copy and verifies the 1440px, 390px, and 320px layouts without horizontal overflow;
- extends source and real-browser tests to read back the computed primary, focus, button, and link colors on desktop and mobile;
- changes no REST contract, D1 schema, migration, authorization rule, or user data.

The public deployment and join guides are refreshed with the alpha.41 immutable ref. Existing instances need only a Worker/OpenAPI/static-assets refresh; the Skill update and Instance upgrade remain independently planned operations.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.41
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行把第一方 Web 的交互色统一为一套与 cfKanban 标志、Cloudflare 部署语境更协调的橙色系。

变更：

- 把原先蓝色的主按钮、链接、焦点、选中和激活控件统一替换为满足可访问性要求的深橙与暖橙 token；
- 标志继续使用更明快的橙色，控件使用更深的橙色，确保按钮白字保持足够对比度；
- 从第一方 Web 源码中移除偏蓝的字面颜色，但不改写用户自行设置的 Label 颜色；
- 保留首页标题的主动两行排版，并验证 1440px、390px 与 320px 布局不会横向溢出；
- 扩展源码测试与真实浏览器测试，分别读回桌面和移动端的主色、focus、按钮与链接实际颜色；
- 不改变 REST 合同、D1 schema、migration、授权规则或用户数据。

公开部署与加入指南同步更新为 alpha.41 的不可变 ref。现有实例只需刷新 Worker/OpenAPI/静态资源；Skill update 与 Instance upgrade 仍然是分别规划的操作。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.41
codex plugin add cfkanban-agent-skills@cfkanban
```
