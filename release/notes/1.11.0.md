# cfKanban 1.11.0

## 简体中文

相对正式版 `1.10.2`，本正式版优化 Owner「工作区与项目」的浏览和设置路径，并将项目资料维护与成员权限管理清楚分开。

- 工作区与项目行将重命名、公开加入和归档等低频操作收进「更多」；新建工作区与项目采用一致的主次按钮层级，项目说明归于名称下方，长内容与窄屏更易浏览。
- 项目设置统一进入完整设置页；工作区设置直接打开设置标签，可在同一页面切换项目及成员与权限，减少入口含义不一致带来的查找。
- 独立的「成员与权限」标签集中管理员、有效成员与权限来源、直接成员授权和项目邀请；「项目管理」聚焦名称与说明、状态显示名及归档或恢复。
- 按所选项目设置标签读取对应管理数据，打开项目资料时不再同时加载成员与邀请区域。
- 从 Owner 列表进入设置后，可返回管理中心并展开原工作区；标签切换保留来路与看板返回路径，旧项目管理链接继续默认打开「项目管理」，权限范围与归档行为保持不变。

## English

Compared with stable `1.10.2`, this stable release improves browsing and settings navigation in the Owner's **Workspaces & Projects** section and separates Project information from access management.

- Workspace and Project rows move less frequent actions, including rename, Public Join and archive, into **More actions**. Consistent primary and secondary creation buttons and descriptions beneath Project names make long content and narrow screens easier to browse.
- Project settings opens the complete settings page. Workspace settings opens its settings tab directly, with Projects and Members and permissions available on the same page, making entry points easier to understand.
- The dedicated **Members and permissions** tab brings together administrators, effective members and their permission sources, direct memberships, and Project invitations. **Management** focuses on names and notes, status labels, and archive or restore actions.
- Management data loads for the selected Project settings tab. Opening Project information no longer loads the member and invitation areas at the same time.
- Settings opened from the Owner list can return to management with the original Workspace expanded. Tab changes preserve their origin and board return paths, existing Project management links still open **Management** by default, and permissions and archive behavior remain unchanged.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.2` 升级无新增数据库迁移，schema 保持 **27**，API 保持 **0.1.0**；升级前仍需核对真实 ledger/schema。保留既有身份、资源、配置及数据。业务功能已在 `1.11.0-rc.2` 完成线上验收，源码与验收记录见 [CFK-695](https://cfkanban.dev/app/issues/CFK-695) 和 [CFK-697](https://cfkanban.dev/app/issues/CFK-697)。准备本候选时，正式版线上验证及本机技能与宿主验证尚未执行，结果另行记录。

Upgrading from `1.10.2` adds no database migrations; schema remains **27** and API remains **0.1.0**. Verify the actual ledger and schema before upgrading. Existing identities, resources, configuration and data are preserved. The features passed live validation in `1.11.0-rc.2`; source and validation records are available in [CFK-695](https://cfkanban.dev/app/issues/CFK-695) and [CFK-697](https://cfkanban.dev/app/issues/CFK-697). When this candidate was prepared, live validation of the stable release and local Skill and host validation had not yet been performed; those results are recorded separately.
