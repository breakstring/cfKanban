# cfKanban 1.12.0-rc.5

## 简体中文

RC5 在 RC4 基础上补齐公开内容使用信号和 Markdown 阅读，让 Agent 从普通页面地址直接读取公开正文。

- 固定声明 `ai-train=no, search=yes, ai-input=yes`，允许搜索和回答输入，不允许模型训练，无需 Owner 设置。
- 公开文档按请求偏好提供原始 Markdown，浏览器默认继续显示 HTML；保留原有 Markdown 地址和双语内容。
- 首页提供静态双语 Markdown 概览，链接公开手册、API 与 Skills 发现、官方安装引导；不读取私有项目或动态首页数据。

本次无新增数据库迁移，API 兼容版本仍为 0.1.0、schema 仍为 28。内容协商由同一 Worker 实现，无需开启 Cloudflare Markdown 转换或修改控制台设置。公开 HTML 与 Markdown 声明同一内容政策，私有页面权限保持原合同。本次部署不包含本机 Skill/plugin 更新。

## English

RC5 adds public content signals and Markdown reading on top of RC4, letting Agents read public source content from ordinary page URLs.

- Declare fixed `ai-train=no, search=yes, ai-input=yes`: allow search and input to answers, disallow model training, and require no Owner setting.
- Serve original Markdown for public documentation according to request preferences, keeping HTML as the browser default and preserving existing Markdown URLs and bilingual content.
- Provide a static bilingual Markdown homepage overview linking to public documentation, API and Skills discovery, and official installation guides, without reading private projects or dynamic homepage data.

No new database migrations; API compatibility remains 0.1.0 and schema remains 28. The same Worker handles content negotiation without enabling Cloudflare Markdown conversion or changing dashboard settings. Public HTML and Markdown declare the same content policy; private-page permissions retain their existing contract. This deployment does not update local Skills or plugins.
