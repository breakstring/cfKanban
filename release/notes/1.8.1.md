# cfKanban 1.8.1

## 简体中文

相对 [1.8.0](https://github.com/breakstring/cfKanban/releases/tag/1.8.0)，本正式版修复 GitHub Actions 的验证中断，并更新持续集成环境。

- 修复 DSH 面板超时测试提前退出的问题，让在线打开、迟到响应及取消后的恢复检查能够完整执行。
- 将官方 GitHub Actions 与项目验证统一到 Node 24，使用固定版本验证发行。
- 固定 Ubuntu 24.04 验证环境，减少 runner 系统自动迁移对发行验证的影响。

## English

Compared with [1.8.0](https://github.com/breakstring/cfKanban/releases/tag/1.8.0), this stable release fixes interrupted GitHub Actions validation and updates the continuous integration environment.

- Fix the DSH panel timeout test exiting early so online opening, late replies, and recovery after cancellation are checked fully.
- Align the official GitHub Actions and project validation on Node 24, using a pinned version for release checks.
- Pin validation to Ubuntu 24.04 to reduce changes caused by automatic runner OS migration.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；实例升级仍须核对真实 ledger/schema。本地更新与实例升级独立；Git 插件与其使用的完整 Skill bundle 须为同一准确版本。更新后重启所属 MCP / 工作台，并在新会话核对 Skills 与 MCP 的实际加载版本。

No migration is added; schema remains 18 and API remains 0.1.0. Instance upgrades still require verification of the actual ledger/schema. Local updates and instance upgrades are independent; a Git plugin and the complete Skill bundle it uses must match the same exact release. Restart the owning MCP / workbench after updating and verify the loaded Skill and MCP versions in a new session.
