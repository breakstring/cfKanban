# cfKanban 0.1.0-alpha.24

Testing prerelease / 测试发行版

## English

This testing prerelease completes the locale-switch recovery pass found through live dogfooding.

Changes:

- retains structured API failures as reactive error state instead of freezing their rendered copy at request time;
- makes an already-visible error immediately follow English or Simplified Chinese locale changes without reloading the page or repeating the request;
- applies the same behavior to local pagination, inventory, copy, relation-scope, Passkey, and Invitation recovery guidance;
- keeps request IDs, Issue identifiers, stable keys, resource fingerprints, and other machine evidence unchanged across language switches;
- keeps unsaved drafts and current view state intact, including CAS conflict recovery and Owner Invitation safety locks;
- adds bidirectional regression coverage and a rendered-browser check for the same request ID in both locales.

The REST API and D1 schema are unchanged from alpha.23. The Service bundle changes because the Web UI and its compiled Static Assets change. The Skill bundle changes only to publish the alpha.24 testing pointer and plugin metadata.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.24
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行补齐了真实 dogfooding 中发现的语言切换与错误恢复体验。

变更：

- 结构化 API 错误不再在请求完成时固化为某一种语言，而是保留为可响应语言变化的错误状态；
- 已经显示的错误会在 English 与简体中文之间立即切换，不需要刷新页面或重新发送请求；
- 本地分页、项目清单、复制、关系范围、通行密钥和邀请恢复提示采用相同机制；
- 切换语言时，请求 ID、事项编号、稳定键、资源指纹和其他机器证据保持不变；
- 未提交草稿和当前页面状态保持不变，包括版本冲突恢复与所有者邀请安全锁；
- 增加双向回归测试，并在真实浏览器渲染中验证同一个请求 ID 能随语言即时切换。

REST API 与 D1 schema 相对 alpha.23 没有变化。Web UI 及其编译后的静态资源发生变化，因此 Service bundle 会更新；Skill bundle 只更新 alpha.24 测试指针与 plugin metadata。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.24
codex plugin add cfkanban-agent-skills@cfkanban
```
