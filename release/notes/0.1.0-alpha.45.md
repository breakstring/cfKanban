# cfKanban 0.1.0-alpha.45

## English

Testing prerelease, not a stable deployment target.

- Restore confirmation now shows the public summary, public roles, and named Issue/Comment/Participant usage and limits for every listed Project that will resume Public Join (CFK-365).
- Bilingual, responsive details replace the unlabeled quota tuple. Missing data is not presented as zero, and business summaries remain escaped plain text.
- Adds actual Vue-rendering regression coverage for both languages, quota values and safe summary handling. Live quota/recovery tests cover atomic completion, child-Comment capacity, policy disable/re-enable recount, and Project isolation.
- No API, permission, schema, migration, domain or resource changes. Publishing does not implicitly update local Skills, host plugin projections or deployed Instances.

测试预发行版，不是稳定部署目标。
