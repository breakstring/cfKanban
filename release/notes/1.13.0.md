# cfKanban 1.13.0

## 简体中文

相对 `1.12.1`，本正式版统一产品版本为 `1.13.0` 并重新构建全部发行工件，业务代码保持一致。升级自 `1.12.0` 的实例可获得以下修复：

- 修复已登录 Web 用户打开 Issue 时关系列表返回 `PLATFORM_UNAVAILABLE` 的问题。
- 保持双向关系列表、游标分页及原有项目可见范围。
- 保留 Session 过期、撤销与来源校验，无需重新创建账号或业务数据。

## English

Compared with `1.12.1`, this stable release sets the product version to `1.13.0` and rebuilds all release artifacts with the same application code. Instances upgrading from `1.12.0` receive these fixes:

- Fixes relation-list `PLATFORM_UNAVAILABLE` errors when signed-in Web users open an Issue.
- Preserves bidirectional relation lists, cursor pagination and existing Project visibility.
- Keeps Session expiry, revocation and source validation without recreating accounts or business data.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 31，API 保持 0.1.0；升级前仍须核对真实 ledger/schema。现有兼容 Skills 可继续使用。本修复已通过本地 Cookie/API 回归和 SQLite 3.54.1 查询对照；真实浏览器验收由维护者在实例升级后执行。

No new migrations; schema remains 31 and API remains 0.1.0. Verify the actual ledger/schema before upgrading. Existing compatible Skills remain usable. Local Cookie/API regressions and SQLite 3.54.1 query comparisons passed; the maintainer will validate the real browser after upgrading the Instance.

实施与验证记录 / Implementation and validation: [CFK-1017](https://cfkanban.dev/app/issues/CFK-1017), [CFK-1022](https://cfkanban.dev/app/issues/CFK-1022).
