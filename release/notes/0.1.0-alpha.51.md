# cfKanban 0.1.0-alpha.51

## English

- Move archived content to its own administration tab after Activity, grouped by workspace with nested projects. Both active and archived workspace groups start collapsed.
- Update confirmed permanent deletions in place without reloading the tree or collapsing other groups.
- Make the full project/workspace name clickable to copy in deletion confirmation, with copy feedback and manual name confirmation retained.
- No schema changes or migrations; this release does not delete business data.

## 简体中文

- 将已归档内容移到操作记录之后的独立标签页，按工作区包含项目的层级组织；常规及归档工作区默认折叠。
- 永久删除确认成功后原地更新对应项，不重新加载列表或收起其他分组。
- 删除确认中的完整项目/工作区名称支持点击复制及反馈，保留手动填名确认。
- 本版不修改 schema、不运行迁移，发布本身不删除业务数据。
