# cfKanban 0.1.0-alpha.30

Testing prerelease / 测试发行版

## English

This testing prerelease completes Owner-side CAS recovery paths found through live two-tab dogfooding.

Changes:

- returns `details.current_version` when a stale Grant write finds `GRANT_REVOKED`;
- returns `details.current_version` when a stale Public Join or resource-limit write finds `PUBLIC_JOIN_DISABLED`;
- routes both exact state codes through the shared Web CAS recovery panel without losing their original recovery hints;
- reads back the latest Grant or Public Join facts while retaining the copyable local draft;
- visibly disables Workspace creation, Project creation, and container rename controls while their write is in flight, while the existing write fence continues to prevent duplicate submission;
- adds Worker integration assertions for both state conflicts and Web coverage for the expanded CAS matrix and busy controls.

The D1 schema and deployment topology are unchanged from alpha.29. Existing instances can upgrade by deploying the alpha.30 Service bundle without a D1 migration. The alpha.30 Skill bundle only advances the canonical testing pointer and remains compatible with the same API range.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.30
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行补齐了真实双标签页 dogfood 中发现的 Owner 侧 CAS 恢复路径。

变更：

- 旧版本 Grant 写入发现 `GRANT_REVOKED` 时返回 `details.current_version`；
- 旧版本 Public Join 或资源限额写入发现 `PUBLIC_JOIN_DISABLED` 时返回 `details.current_version`；
- Web 将这两个精确状态码交给共享 CAS 恢复面板，同时保留原有 recovery hint；
- 读回最新 Grant 或 Public Join 事实，同时保留可复制的本地草稿；
- Workspace 创建、Project 创建和容器改名写入期间明确禁用相关控件，既有 write fence 继续阻止重复提交；
- 增加两类状态冲突的 Worker 集成断言，以及扩展后 CAS 矩阵与 busy 控件的 Web 覆盖。

D1 schema 与部署拓扑相对 alpha.29 均未变化。现有实例可以直接部署 alpha.30 Service bundle，不需要 D1 migration。alpha.30 Skill bundle 只推进 canonical 测试指针，并继续兼容同一 API 范围。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.30
codex plugin add cfkanban-agent-skills@cfkanban
```
