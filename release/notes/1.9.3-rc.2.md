# cfKanban 1.9.3-rc.2

## 简体中文

相对 `1.9.3-rc.1`，本 RC 修正 Composer 事项搜索的协议协商，并说明选择引用入口的实际操作。

- 补齐事项搜索能力声明，让支持该协议的桌面客户端按正确的查询格式调用，避免有效编号被当作非法请求拒绝。
- 双语指引明确先从 `@` 菜单选择 cfKanban 入口、看到名称标签后再输入完整编号，减少全局搜索与事项搜索的混淆。
- 增加无候选时的排查指引，分别核对运行中的 MCP 版本、工件路径、连接与项目权限。

## English

Compared with `1.9.3-rc.1`, this RC corrects Composer Issue search negotiation and explains how to select the mention provider.

- Declares the Issue search capability so compatible desktop clients send the correct query format, avoiding rejection of valid identifiers as invalid requests.
- Bilingual instructions explain selecting cfKanban from the `@` menu before entering a complete identifier after its name chip, reducing confusion between global search and Issue search.
- Adds troubleshooting guidance for missing candidates, checking the running MCP version, artifact path, connection, and Project access separately.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 **19**，API 保持 **0.1.0**。请明确选择 `1.9.3-rc.2` 更新本地组件，核对宿主 MCP 入口指向新版本工件，再重启 MCP/宿主。仅更新 Skills 或插件页面显示的版本不能证明实际 MCP 已切换。本修复可使用提供 `issue_reference` 能力的 `1.9.3-rc.1` Service；无需为这一处本地协议修复再次升级线上服务。

No migration is added; schema remains **19** and the API remains **0.1.0**. Select `1.9.3-rc.2` explicitly for local components, verify that the host's MCP entry points to its artifact, and restart MCP/the host. The version shown for Skills or a plugin does not prove that the running MCP changed. This fix works with the `1.9.3-rc.1` Service advertising `issue_reference`; another online upgrade is not required for this local protocol correction.

协议协商、候选搜索与资源读取已通过隔离验证；用户测试电脑的真实菜单、候选选择及上下文交付仍待验收。首版只支持完整编号与已信任规范链接，不支持标题搜索。

Negotiation, candidate search, and resource reads have passed isolated verification. The menu, candidate selection, and context delivery on the user's test computer still require acceptance. The first version accepts complete identifiers and trusted canonical links, without title search.

实现与验收记录 / Implementation and acceptance: [CFK-601](https://cfkanban.dev/app/issues/CFK-601).
