# cfKanban 1.10.1-rc.3

## 简体中文

相对已公开的 `1.10.1-rc.2`，本 RC 简化管理员的 Cloudflare 连接与设置流程，并完善结果未知时的配置恢复核验。

- 在概览输入一份 API Token，供设置修改与用量采集共用；分别核验各项权限，兼容已有授权。
- 直接在概览调整五类访问频率限制，先查看变更前后值，再应用并核实结果。
- 用量与限额集中展示消耗、提醒及历史设置；重复的连接分页合并到概览，可选读取和技术详情按需展开。
- 应用响应丢失后，完整核对预期配置再确认成功，避免配置不匹配时误解除操作锁。

## English

Compared with published `1.10.1-rc.2`, this RC simplifies the administrator's Cloudflare connection and settings flow and strengthens configuration verification when an outcome is unknown.

- Enter one API Token in Overview for settings changes and usage collection, with each permission verified separately and existing authorization remaining compatible.
- Adjust all five request frequency limits directly in Overview, review before and after values, then apply and verify the result.
- Usage and limits brings consumption, reminders and history settings together; the duplicate connection tab moves into Overview, with optional reads and technical details expanded on demand.
- After a lost apply response, verify the complete expected configuration before confirming success, preventing mismatched configuration from releasing the operation lock.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.1-rc.2` 升级无新增 migration，schema 保持 **26**，API 保持 **0.1.0**；仍须核对实际 ledger/schema 和线上配置。Owner 须自行创建并输入适用 Token；修改配置所需的 Worker Editor 权限包含代码修改与部署权，可选能力取决于真实权限及供应商核验结果。

Upgrading from `1.10.1-rc.2` adds no migrations and keeps schema **26** and API **0.1.0**; the actual ledger/schema and live configuration must still be checked. Owners must create and enter a suitable Token themselves. Worker Editor authorization for configuration changes includes code changes and deployment, and optional capabilities depend on actual permissions and provider verification.

USD 预算金额和通知收件人编辑仍使用 Cloudflare 官方控制台；用量统计不代表最终账单或费用封顶。

Use the official Cloudflare dashboard to edit USD budget amounts and notification recipients. Usage statistics do not represent final invoices or spending caps.
