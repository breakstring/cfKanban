# cfKanban 0.1.0-alpha.34

Testing prerelease / 测试发行版

## English

This testing prerelease keeps the public Web surface self-contained on Cloudflare custom domains.

Changes:

- sends `Cache-Control: no-store, no-transform` on the SPA document, Invitation page, and Browser Launch page;
- prevents Cloudflare Web Analytics from automatically injecting its third-party RUM beacon into cfKanban HTML;
- keeps the existing strict CSP and no-third-party-resource contract instead of allowlisting the injected script;
- leaves JSON, versioned Markdown guides, immutable assets, D1 schema, and deployment topology unchanged.

Existing instances can upgrade by deploying the alpha.34 Service bundle without a D1 migration. Local Skill update and Instance upgrade remain independent.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.34
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行让 Cloudflare 自定义域名上的公开 Web 表面继续保持完全自包含。

变更：

- SPA 文档、Invitation 页面和 Browser Launch 页面统一返回 `Cache-Control: no-store, no-transform`；
- 阻止 Cloudflare Web Analytics 向 cfKanban HTML 自动注入第三方 RUM beacon；
- 继续保持严格 CSP 和“不加载第三方资源”合同，不为被注入脚本放宽白名单；
- JSON、带版本的 Markdown 指南、不可变 assets、D1 schema 与部署拓扑均不变。

现有实例可以直接部署 alpha.34 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是彼此独立的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.34
codex plugin add cfkanban-agent-skills@cfkanban
```
