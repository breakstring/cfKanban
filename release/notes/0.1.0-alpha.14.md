# cfKanban 0.1.0-alpha.14

Testing prerelease / 测试发行版

## English

This testing prerelease improves the first-board workflow after a real-instance rehearsal exposed unnecessary key-casing friction.

Changes:

- accepts user-chosen Workspace and Project keys in either letter case at the Skill interaction layer;
- normalizes Workspace keys to lowercase and Project keys to uppercase before validation, preview, and submission;
- shows the exact canonical immutable keys before writing and never asks the user to retype a valid choice only for casing;
- retains the existing key shapes and stored values, so the Service API, schema, and deployed instances remain compatible;
- adds a regression contract for the English entrypoint and both localized Owner workflow guides.

Real-instance checks performed while preparing this release covered Workspace/Project/Label/Issue creation, idempotent replay, assignment, manual blocking, conflict recovery, relations, completion history, tombstone restore, and relation-derived blocked-state changes.

This changes the Skill bundle and documentation only. An already deployed compatible Service does not need to be upgraded for this correction.

Important limits:

- this is not the stable channel and must be selected explicitly;
- broader Web concurrency, target-scope, pagination, and browser hardening remain release-candidate work;
- host or operating-system permission prompts remain independent of cfKanban's application-level authorization.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.14
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-admin to create my first cfKanban board.
```

## 简体中文

这次测试发行来自真实实例演练：首次创建看板时，用户不应该为了满足 key 的字母大小写再输入一次。

变更：

- Skill 交互层接受任意字母大小写的用户自选 Workspace 与 Project key；
- 在校验、预览和提交前，把 Workspace key 规范为小写、Project key 规范为大写；
- 写入前展示准确的 canonical immutable key，不会仅因大小写要求用户重新输入有效选择；
- 保留既有 key 形状与存储值，因此 Service API、schema 和已部署实例继续兼容；
- 为英文入口与中英文 Owner 工作流补充回归合同。

准备本次发行时，真实实例已经覆盖 Workspace/Project/Label/Issue 创建、幂等重放、指派、人工阻塞、冲突恢复、关系、完成历史、tombstone 恢复，以及由关系推导的阻塞状态变化。

本次只改变 Skill bundle 与文档；已经部署的兼容 Service 无需为此升级。

重要限制：

- 这不是 stable channel，必须由用户明确选择；
- Web 并发、target scope、分页与浏览器加固仍属于 release candidate 工作；
- Agent 宿主或操作系统自己的权限提示仍独立于 cfKanban 应用层授权。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.14
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-admin 创建我的第一个 cfKanban 看板。
```
