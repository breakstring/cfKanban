# cfKanban 1.9.3

## 简体中文

相对正式版 `1.9.2`，本版汇总五个 RC 的改进，让 Codex 中查看、搜索和引用事项更顺畅，并补齐宿主接入指南。

- 明确指定事项编号时，Codex 会话工作台直接打开对应详情；看板和列表优先请求全屏，并提供展开入口。
- `@` 菜单中的 `cfkanban-search` 带搜索用途说明，支持完整编号、部分编号及标题关键词，最多返回十条候选供选择和引用。
- 本地 SQLite 搜索缓存按实例和用户隔离，重开后复用；后台增量同步事项变化和项目权限，配合请求合并、限流与取消减少输入时的等待。
- 中英文 Agent 接入指南说明 Codex、DSH、MCP 与 CLI 的安装和操作，新增全屏、侧栏与搜索配图，网页及公开 Markdown 都能查看原图。
- 修复 GitHub Actions 中中文 HTML 分块解码导致的集成测试失败，恢复发行验证。

## English

Compared with stable `1.9.2`, this release brings together improvements from five RCs for opening, searching, and referencing Issues in Codex, with clearer host integration guides.

- An explicit Issue identifier opens its details directly in the Codex conversation workbench. Boards and lists request fullscreen first and offer an expand control.
- The `cfkanban-search` entry in the `@` menu describes its purpose and accepts complete identifiers, number prefixes, and title keywords, returning up to ten candidates to select and reference.
- A local SQLite search cache is isolated by instance and user and reused after restart. Background incremental synchronization tracks Issue and Project-access changes, with request coalescing, rate limits, and cancellation reducing waits while typing.
- English and Chinese Agent guides explain installation and use with Codex, DSH, MCP, and CLI. New fullscreen, sidebar, and search images link to originals from both HTML and public Markdown.
- Fixes an integration-test failure in GitHub Actions caused by decoding Chinese HTML across output chunk boundaries, restoring release validation.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.2` 升级包含兼容性迁移 `0020_issue_search_index.sql`，schema 从 **19** 升至 **20**，API 保持 **0.1.0**；从 RC5 升级无新增迁移，仍需核对真实 ledger/schema。使用搜索需分别更新本地组件和 Service；本地更新后重连 MCP 或重开宿主。

Upgrading from `1.9.2` includes the backward-compatible migration `0020_issue_search_index.sql`, advancing schema from **19** to **20** while retaining API **0.1.0**. Upgrading from RC5 adds no migration; verify the actual ledger/schema. Search requires updated local components and Service separately; reconnect MCP or restart the host after the local update.

搜索只覆盖编号和标题，不包含正文或评论。首次同步及新获权项目补齐期间可能没有候选，完成后需重新输入查询；已有缓存可能短暂陈旧，选中引用后读取详情仍实时核权。工作台实际呈现位置由宿主决定，跨系统及完整宿主验收边界见相关事项记录。

Search covers identifiers and titles, excluding bodies and Comments. Initial synchronization and newly granted Project backfills may return no candidates; re-enter the query after completion. Existing candidates can briefly be stale, and selected references still read details under live authorization. The host determines workbench placement; see the related records for cross-platform and complete host acceptance scope.
