# cfKanban 0.1.0-alpha.28

Testing prerelease / 测试发行版

## English

This testing prerelease makes long Owner Audit histories easier to scan without hiding their exact machine facts.

Changes:

- keeps each event's stream, type, actor, resource, Project, operation ID/index, authorization source, and event ID visible in a compact fact grid;
- collapses raw payload JSON by default behind a native keyboard-accessible details control;
- wraps long identifiers and bounds expanded payload height so one record cannot widen or dominate the page;
- preserves the existing Project/stream filters and cursor-bound 100-row continuous pagination;
- aligns the Web `EventResource` type with the already-published Event response contract;
- adds source wiring checks plus rendered desktop, narrow-viewport, keyboard, overflow, and pagination validation.

The REST API, D1 schema, and deployment behavior are unchanged from alpha.27. Existing instances can upgrade by deploying the alpha.28 Service bundle without a D1 migration. The alpha.28 Skill bundle only advances the canonical testing pointer and remains compatible with the same API range.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.28
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行改善 Owner 审计长列表的可读性，同时保留准确的机器事实。

变更：

- 用紧凑事实网格展示每条事件的 stream、类型、操作身份、资源、项目、操作 ID/index、授权来源和事件 ID；
- 原始 payload JSON 默认折叠在原生、可用键盘操作的详情控件中；
- 长标识可安全换行，展开后的载荷也有高度上限，单条记录不会撑宽或霸占整个页面；
- 保留既有 Project/stream 筛选与绑定 cursor 的每页 100 条连续分页；
- Web `EventResource` 类型与已经发布的 Event 响应合同对齐；
- 增加源码接线检查，以及桌面、窄屏、键盘、溢出和分页的渲染验证。

REST API、D1 schema 与部署行为相对 alpha.27 均未变化。现有实例可以直接部署 alpha.28 Service bundle，不需要 D1 migration。alpha.28 Skill bundle 只推进 canonical 测试指针，并继续兼容同一 API 范围。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.28
codex plugin add cfkanban-agent-skills@cfkanban
```
