# cfKanban 0.1.0-alpha.57

## English

This testing release adds Owner usage statistics and explicit attachment capacity settings, shared by Web and Agent APIs.

- Read reserved attachment bytes and optional instance-scoped D1/R2 metrics. Missing, unconfigured, refreshing, stale and failed states remain distinct from zero; instance metrics do not imply account-wide remaining allowance.
- Analytics refreshes on demand, with a shared 15-minute successful snapshot and a 60-second attempt cooldown across both refresh modes. Concurrent requests are coalesced. No statistics Cron or background polling is added; existing attachment cleanup remains scheduled.
- The Owner chooses a positive byte limit or explicitly selects unlimited capacity. Deployment neither chooses nor overwrites that application setting, and the application budget is not a Cloudflare billing cap.
- Add the schema 6 statistics-cache migration and schema 7 attachment-settings migration without changing published migrations or losing objects and reservations. Migration from the fixed 1 GiB policy starts unconfigured: new reservations pause until an Owner choice, while existing reservations may finish and existing files remain accessible, deletable, restorable and reclaimable.
- Cloudflare metrics require exact resource configuration and a separately configured read-only `USAGE_ANALYTICS_TOKEN` Worker Secret. Publishing, Skill installation and instance upgrade do not authorize creating credentials, expanding permissions or enabling paid resources. Attachment application usage remains available without analytics credentials.
- Verify local Skill updates and instance upgrades separately. Record a D1 restore point before migration; Worker rollback does not revert D1, and database restore is never automatic.

This remains a prerelease. Live Analytics access and data availability need separate verification after secure credential configuration.

## 简体中文

本次测试发行新增管理员用量统计与 Owner 自主设置附件容量，Web 和 Agent 使用同一 API 与状态投影。

- Owner 管理面板展示附件预留字节，以及可选的本实例 D1/R2 统计；缺失、未配置、刷新中、过期和失败状态不伪装成零值，也不从单实例推算账户剩余额度。
- 用量统计默认启用、按需刷新；实例共享成功快照 15 分钟，两种刷新模式均受 60 秒尝试冷却约束并合并并发请求。不新增统计 Cron、不在后台轮询，既有附件定时回收继续保留。
- Owner 可设置正整数字节容量上限或明确选择不限制。附件容量属于应用设置，部署不代选、不覆盖既有选择；应用预算不是 Cloudflare 账单上限。
- 新增 schema 6 的单行统计缓存迁移与 schema 7 的附件容量设置迁移，保留已发布迁移、对象及预留计数。旧固定 1 GiB 策略迁移后初始为未设置；Owner 明确选择前只暂停新上传预留，已有预留可继续完成，已有文件仍可访问、删除、恢复和回收。
- Cloudflare 统计需准确资源配置和单独安全配置的只读 `USAGE_ANALYTICS_TOKEN` Worker Secret；本发行、技能更新和实例升级均不隐含创建 Token、扩大权限或启用付费资源。未配置时仍可读取附件应用预算。
- 本地技能更新与云端实例升级分别验证；升级前记录 D1 restore point。Worker 回滚不回退 D1，数据库恢复不自动执行。

此版本仍为 prerelease；真实 Analytics 权限与数据可用性须在单独完成统计凭据配置后验证。
