# cfKanban 0.1.0-alpha.5

Testing prerelease / 测试发行版

## English

This testing prerelease fixes a Tool Runtime reuse error discovered immediately after the `0.1.0-alpha.4` deployment rehearsal. The host capability probe reports only PATH-level Wrangler state; it must never hide an already installed compatible Wrangler under `~/.cfkanban/tool-runtime/`.

Changes:

- adds a bounded, non-authoritative `installed_tool_runtime` hint to the capability report;
- marks `capabilities.tools.wrangler` as a PATH-only observation whose release compatibility is not yet determined;
- requires `runtime resolve-wrangler` before every installation decision, using the verified release range across explicit, PATH, and active cfKanban Tool Runtime candidates;
- reuses an existing compatible Tool Runtime and permits an install plan only after the resolver returns unavailable or incompatible;
- retains the task-bound, least-scope Cloudflare authentication plan introduced in `0.1.0-alpha.4`;
- continues to accept Node.js `>=22.12.0 <27` and pins Wrangler to `4.127.1`.

Important limits:

- this is not the stable channel and must be selected explicitly;
- capability receipts are hints only; the resolver must verify the executable and version;
- use a non-production Cloudflare account and review each exact local, authentication, and deployment plan before approval;
- resource cleanup is separate and is never performed automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.5
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这个测试发行版修正了 `0.1.0-alpha.4` 部署演练后立即发现的 Tool Runtime 复用错误。宿主 capability 检查只反映 PATH 中的 Wrangler，绝不能因此漏掉 `~/.cfkanban/tool-runtime/` 下已经安装且兼容的 Wrangler。

变更：

- capability report 增加有界、非权威的 `installed_tool_runtime` 提示；
- 明确标记 `capabilities.tools.wrangler` 只是 PATH 观察，尚未确定是否兼容当前发行版；
- 每次决定安装前都必须调用 `runtime resolve-wrangler`，按 verified release range 检查显式、PATH 与 active cfKanban Tool Runtime candidates；
- 复用任何既有兼容 Tool Runtime；只有 resolver 返回 unavailable 或 incompatible 后才能生成安装计划；
- 保留 `0.1.0-alpha.4` 引入的绑定 task、最小 scopes Cloudflare 认证计划；
- 继续接受 Node.js `>=22.12.0 <27`，Wrangler 固定为 `4.127.1`。

重要限制：

- 这不是稳定发行通道，必须由用户明确选择；
- capability receipt 只作提示；必须由 resolver 校验 executable 与版本；
- 请使用非生产 Cloudflare 账户，并分别核对准确的本地、认证与部署计划后再授权；
- 资源清理是独立操作，绝不会自动执行。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.5
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-deploy 为我部署一套 cfKanban。
```
