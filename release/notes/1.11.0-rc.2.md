# cfKanban 1.11.0-rc.2

## 简体中文

相对 `1.11.0-rc.1`，本 RC 将项目设置中的成员与权限独立为标签，让项目资料维护与人员管理更清楚。

- 「成员与权限」集中管理员、有效成员与权限来源、直接成员授权及项目邀请，便于核对和维护项目访问。
- 「项目管理」聚焦项目名称与说明、状态显示名及归档或恢复，减少资料设置中的人员操作干扰。
- 按所选标签读取对应管理数据，打开项目资料时不再同时加载成员与邀请区域。
- 原项目管理链接继续默认打开「项目管理」；切换标签保留看板与 Owner 列表返回路径，权限范围不扩大，归档项目仍只提供项目管理。

## English

Compared with `1.11.0-rc.1`, this RC gives **Members and permissions** its own Project settings tab, separating Project information from access management.

- **Members and permissions** brings together administrators, effective members and their permission sources, direct memberships, and Project invitations for reviewing and maintaining access.
- **Management** focuses on Project names and notes, status labels, and archive or restore actions, keeping people management separate from Project information.
- Management data loads for the selected tab. Opening Project information no longer loads the member and invitation areas at the same time.
- Existing Project management links still open **Management** by default. Tab changes preserve board and Owner-list return paths, permissions stay within their existing scope, and archived Projects continue to offer only Management.

## 升级与已知限制 / Upgrade and known limitations

从 `1.11.0-rc.1` 升级无新增数据库迁移，schema 保持 **27**，API 保持 **0.1.0**；升级前仍需核对真实 ledger/schema。保留既有身份、资源、配置及数据。本版为预发行，GitHub stable 与 main 不随 RC 推进。源码与本地验收记录见 [CFK-697](https://cfkanban.dev/app/issues/CFK-697)；线上升级结果另行记录，不将本地检查当作线上验收。

Upgrading from `1.11.0-rc.1` adds no database migrations; schema remains **27** and API remains **0.1.0**. Verify the actual ledger and schema before upgrading. Existing identities, resources, configuration and data are preserved. This is a prerelease and does not advance GitHub stable or main. Source and local validation is recorded in [CFK-697](https://cfkanban.dev/app/issues/CFK-697); live upgrade results are recorded separately.
