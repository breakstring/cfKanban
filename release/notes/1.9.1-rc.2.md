# cfKanban 1.9.1-rc.2

## 简体中文

相对正式版 `1.9.0`，本 RC 提供公共 CLI，并改进看板列表的等待反馈与状态识别。

- 在终端或 Agent 中使用公共 CLI 完成日常协作、管理和安全部署计划，以结构化输出对接自动化。
- 不确定的写入可沿原操作核对和恢复；CLI 提供安装、检查和版本回退入口。
- 列表远程加载时明确反馈等待，对已加载内容进行局部排序，并保留展开状态。
- 完整版 Web 与本地工作台共享状态颜色标识，便于识别 Issue 的进展。
- 中英文 CLI 指南覆盖安装、协作、管理、部署和恢复，帮助人类与 Agent 使用同一套命令。

## English

Compared with stable `1.9.0`, this RC adds a public CLI and improves loading feedback and status recognition in board lists.

- Use the public CLI from a terminal or Agent for daily collaboration, administration and safe deployment plans, with structured output for automation.
- Verify and recover uncertain writes using the original operation; dedicated CLI commands support installation, inspection and version rollback.
- Lists show when remote data is loading, sort loaded content locally and preserve expanded groups.
- The full Web app and local workbench share status colors, making Issue progress easier to recognize.
- English and Simplified Chinese CLI guides cover installation, collaboration, administration, deployment and recovery, helping people and Agents use the same commands.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration；schema 保持 `19`，API 保持 `0.1.0`。升级仍须核对真实 migration ledger 与 schema。Linux、Windows 原生和 WSL2 尚无真实宿主实测；真实云端完整流程与完整人工能力矩阵尚未验收，因此本版保持 RC。

There are no new migrations; schema remains `19` and the API remains `0.1.0`. Upgrades still require verification of the actual migration ledger and schema. Linux, native Windows and WSL2 have not been tested on real hosts; full cloud workflows and the complete set of manual capability flows still await acceptance, so this release remains an RC.

本轮实现与发行证据见 [CFK-596](https://cfkanban.dev/app/issues/CFK-596)；待补的完整实测见 [CFK-592](https://cfkanban.dev/app/issues/CFK-592)。

See [CFK-596](https://cfkanban.dev/app/issues/CFK-596) for implementation and release evidence, and [CFK-592](https://cfkanban.dev/app/issues/CFK-592) for the remaining end-to-end validation.
