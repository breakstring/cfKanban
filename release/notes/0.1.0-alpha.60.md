# cfKanban 0.1.0-alpha.60

## English

This testing release fixes Cloudflare usage collection in the deployed Worker runtime.

- Use manual redirect handling supported by workerd and reject non-success responses, preventing analytics credentials from being forwarded to redirected destinations.
- Add an isolated real-workerd regression test for successful collection and redirect refusal.
- Preserve Owner-selected attachment capacity, shared usage caching, safe diagnostics, and migration-readback recovery. Schema remains 7 with no additional migration or paid resources.

This remains a prerelease. Real metrics require a separately authorized read-only Analytics Token; deployment never chooses an attachment capacity limit.

## 简体中文

- 修复用量采集在 Cloudflare Worker 中因不支持 `redirect: error` 而在发出请求前失败的问题；使用 `manual` 并拒绝非成功响应，保持不跟随重定向、不转发统计 Token 的安全边界。
- 增加真实 workerd 的隔离回归验证，覆盖传输选项兼容性和重定向拒绝。
- 保留 alpha.57 的 Owner 用量统计、统一刷新缓存与用户自选附件容量，以及 alpha.58 的迁移读回修复；schema 仍为 7，无新增迁移或付费资源。
