# cfKanban 1.9.4

## 简体中文

相对正式版 `1.9.3`，本版精简接入和使用文档，并改善文档与源码入口，让日常使用更清楚。

- Codex App 和 DeepSeek Harness 指南以技能与自然语言协作为主要入口，侧栏、看板和搜索作为增强能力。
- Codex App 指南保留常用提示词、搜索步骤和实际配图，简化安装、更新与常见问题说明。
- 文档站的命令行栏目标注 CLI；页头新增带图标和文字的 GitHub 入口，与“返回站点”保持清晰间距，窄屏导航菜单也可访问。
- 首页和登录后页脚为文档、GitHub 链接加入一致图标，首页移除“API 合同”链接。
- 移除公开 MCP 接入参考及相关推荐，让接入指南聚焦技能、CLI 和宿主扩展的日常使用。

## English

Compared with stable `1.9.3`, this release simplifies integration and usage guides and improves access to documentation and source code.

- Codex App and DeepSeek Harness guides make Skills and natural-language collaboration the primary entry point, with sidebars, boards and search as additional features.
- The Codex App guide keeps common prompts, search steps and real screenshots while shortening installation, updates and troubleshooting.
- The documentation's command-line section now includes CLI in its title. The header adds a GitHub icon and text with clear spacing from “Back to site”; both links are also available in the narrow-screen navigation menu.
- Homepage and signed-in footers add consistent icons to documentation and GitHub links. The homepage removes the “API contract” link.
- Removes the public MCP connection reference and related recommendations, keeping integration guides focused on everyday use through Skills, CLI and host extensions.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.3` 或 `1.9.4-rc.2` 升级无新增 migration，schema 保持 **20**，API 保持 **0.1.0**，仍需核对实际 ledger/schema。新版页面随 Service 升级提供，本地技能独立更新。已退役的公开 MCP 参考地址返回 404，请使用 [Agent 接入指南](https://cfkanban.dev/docs/zh-CN/integrations/)；现有 API 与 OpenAPI 端点继续可用。

Upgrading from `1.9.3` or `1.9.4-rc.2` adds no migration, retaining schema **20** and API **0.1.0**; verify the actual ledger/schema. Updated pages ship with a Service upgrade, independently of local Skill updates. The retired public MCP reference URLs return 404; use the [Agent integration guides](https://cfkanban.dev/docs/en/integrations/). Existing API and OpenAPI endpoints remain available.
