# cfKanban 0.1.0-alpha.29

Testing prerelease / 测试发行版

## English

This testing prerelease closes a concurrent delete/restore recovery gap found through live two-tab dogfooding.

Changes:

- returns `details.current_version` with `RESOURCE_DELETED` and `RESOURCE_NOT_DELETED` conflicts across Workspace, Project, Issue, Comment, Label, and Relation writes;
- routes those two state conflicts through the same Web CAS recovery panel as `VERSION_CONFLICT`;
- reads back the latest remote facts while retaining a copyable local action draft;
- keeps writes single-shot: no automatic merge, replay, or retry is introduced;
- preserves every existing error code, recovery hint, authorization check, and soft-delete semantic;
- adds Web coverage for all three recoverable CAS codes and Worker integration assertions for containers, Issues, Comments, Labels, and Relations.

The D1 schema and deployment topology are unchanged from alpha.28. Existing instances can upgrade by deploying the alpha.29 Service bundle without a D1 migration. The alpha.29 Skill bundle only advances the canonical testing pointer and remains compatible with the same API range.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.29
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行修复了真实双标签页 dogfood 中发现的并发删除／恢复恢复缺口。

变更：

- Workspace、Project、Issue、Comment、Label 与 Relation 写入返回 `RESOURCE_DELETED` / `RESOURCE_NOT_DELETED` 时补充 `details.current_version`；
- Web 将这两类状态冲突与 `VERSION_CONFLICT` 一样交给共享 CAS 恢复面板处理；
- 读回最新远端事实，同时保留可复制的本地动作草稿；
- 写入仍然只发送一次，不引入自动合并、重放或重试；
- 保留原有错误 code、recovery hint、权限检查与软删除语义；
- 增加三类可恢复 CAS code 的 Web 覆盖，以及容器、Issue、Comment、Label、Relation 的 Worker 集成断言。

D1 schema 与部署拓扑相对 alpha.28 均未变化。现有实例可以直接部署 alpha.29 Service bundle，不需要 D1 migration。alpha.29 Skill bundle 只推进 canonical 测试指针，并继续兼容同一 API 范围。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.29
codex plugin add cfkanban-agent-skills@cfkanban
```
