# cfKanban 0.1.0-alpha.39

Testing prerelease / 测试发行版

## English

This testing prerelease makes deterministic Issue candidate queries usable without requiring an Agent to rediscover mandatory query parameters from OpenAPI.

Changes:

- documents the required `assignment=mine|unassigned|needs_reassignment` choice directly in the daily Skill;
- provides a reusable workspace-qualified Project query template and explains `blocked=exclude|include`;
- requires the Agent to report the Service-resolved candidate policy and Project scope instead of inferring them;
- adds a regression that parses the documented query template and verifies every stable parameter;
- validates the behavior on the live test instance across unassigned, assigned-to-me, and started states;
- changes no API, schema, D1 migration, authentication, or authorization behavior.

The public deployment and join guides are refreshed with the alpha.39 immutable ref. Existing instances need only a Worker/static-assets refresh to expose those new guide pointers; the Skill update and Instance upgrade remain independently planned operations.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.39
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行让确定性 Issue 候选查询可以直接使用，不再要求 Agent 临时从 OpenAPI 重新猜出必填查询参数。

变更：

- 在日常 Skill 中直接说明必填的 `assignment=mine|unassigned|needs_reassignment` 选择；
- 提供可复用的 Workspace-qualified Project 查询模板，并解释 `blocked=exclude|include`；
- 要求 Agent 回显服务端实际解析的候选策略与 Project scope，不能靠调用方猜测；
- 增加会解析文档查询模板并核对全部稳定参数的回归测试；
- 在真实测试实例上验证未分配、分配给我和已开始三种状态变化；
- 不改变 API、schema、D1 migration、认证或授权行为。

公开部署与加入指南同步更新为 alpha.39 的不可变 ref。现有实例只需刷新 Worker/静态资源即可展示这些新指南指针；Skill update 与 Instance upgrade 仍然是分别规划的操作。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.39
codex plugin add cfkanban-agent-skills@cfkanban
```
