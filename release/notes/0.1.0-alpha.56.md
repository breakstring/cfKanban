# cfKanban 0.1.0-alpha.56

## English

- Retain the Web UI, Skills, and optional private R2 attachments introduced in alpha.55.
- Repair the persisted Instance schema version when upgrading existing installations. Alpha.55 added attachment tables but omitted updating the Instance metadata version, causing final deployment verification to reject an otherwise migrated instance.
- Add a new backward-compatible migration without changing published migrations or their checksums. Verify the metadata value during migration readback and add populated-instance upgrade regression coverage.
- Preserve existing private R2 ownership, bindings and hourly cleanup. No additional cloud resources or permissions are required for an existing attachment-enabled instance.

## 简体中文

本次修订保留 alpha.55 的 Web 界面、技能优化与私有 R2 附件能力，修复既有实例升级后的版本标记遗漏。

- alpha.55 已新增附件表，但未同步更新实例的 schema 版本标记，导致最终部署校验失败。
- 新增兼容迁移修正实例标记，保持所有已发布迁移的内容与指纹不变；增加版本数据读回与真实升级回归。
- Schema 升至 5。既有附件桶、权限与每小时清理配置保持连续，不新建额外云资源。
- 升级前记录 D1 restore point；Worker 回滚不回退 D1，数据库恢复仍不自动执行。

本版本仍是 prerelease；本地 Skill 更新与云端实例升级分别验证。
