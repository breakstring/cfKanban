# cfKanban 1.8.0-rc.3

## 简体中文

相对 `1.8.0-rc.2`，本 RC 简化安装和上手文档，并明确 Agent 内部的 MCP 与安全脚本分工。

- 文档按「开始使用」「加入与使用」「部署与管理」组织，成员和 Owner 都能更快找到下一步。
- 安装引导统一技能与 MCP 的配置入口；受支持宿主默认由 Agent 配置 MCP，兼容的现有安装可直接复用。
- 日常协作优先使用已连接且支持当前操作的 MCP，未覆盖能力继续使用安全脚本；写入结果不确定时保留原请求核实。
- 新增本地工作台与线上完整版的能力对照、其他 MCP 客户端的配置参考，并说明 DeepSeek Harness 当前的插件安装路径。

## English

Compared with `1.8.0-rc.2`, this RC simplifies installation and onboarding and clarifies how Agents use MCP and secure scripts.

- Documentation follows Start here, Join & work, and Deploy & manage journeys so members and Owners can find their next step.
- One installation flow covers Skills and MCP. Agents configure MCP by default on supported hosts and reuse compatible existing installations.
- Daily collaboration prefers a connected MCP that supports the operation; secure scripts cover remaining capabilities. Uncertain writes retain their original request for verification.
- New guides compare the local workbench with the full online UI, document configuration for other MCP clients, and explain the current DeepSeek Harness plugin installation path.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；升级仍须核对真实 ledger/schema。更新后使用新会话验证 Skills 与 MCP 加载。DSH 目前仍使用已验证发行包内的本地插件包，尚未提供独立的远程安装工件。

No migration is added; schema remains 18 and API remains 0.1.0. Verify the actual ledger/schema during upgrade, and use a new session to verify Skill and MCP loading. DSH currently uses the local plugin package inside the verified release bundle; a standalone remote installation artifact is not yet available.
