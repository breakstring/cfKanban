# cfKanban 0.1.0-alpha.47

## English

- Fix `invite redeem` recovery so rotation sends the current Principal Credential.
- Keep full recovery usable without an existing Credential, with a safe unauthenticated fallback after an authentication-only rejection.
- Add Skill-level regression coverage for both recovery modes and secret redaction.

## 简体中文

- 修复 `invite redeem` 的 Principal Recovery：`rotation` 会携带当前 Principal Credential 完成身份证明。
- `full_recovery` 仍可在没有旧 Credential 时使用；只有认证类拒绝才会安全降级到无凭据请求。
- 增加两种恢复模式的 Skill 回归测试，并继续校验 secret 不进入输出。
