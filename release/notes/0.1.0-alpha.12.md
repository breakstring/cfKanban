# cfKanban 0.1.0-alpha.12

Testing prerelease / 测试发行版

## English

This testing prerelease adds a safe recovery path for an Owner bootstrap whose Wrangler response failed or became uncertain before D1 committed anything.

Changes:

- adds the allowlisted `owner_bootstrap_readback` action under the existing plan-bound deployment command;
- runs one fixed read-only D1 query with `--command --json` and disables Wrangler disk logs;
- records only bounded row counts for the six tables touched by Owner bootstrap;
- permits one retry of the exact same hash-only SQL only when a newer readback proves every table is empty and the prior attempt did not succeed;
- requires a fresh zero-state readback after every further failed or uncertain attempt;
- keeps any present, partial, malformed, successful, or drifted state on the finalization/stop path and never generates a second Credential;
- retains the alpha.11 exact identity finalization, redacted receipt, simplified Wrangler identity resolution, and pinned account handling.

The ongoing rehearsal can update only its local canonical Skill to this version and continue the unchanged alpha.8 Service plan and journal. This does not upgrade the deployed Service bundle or create a new deployment plan.

Important limits:

- this is not the stable channel and must be selected explicitly;
- use a non-production Cloudflare account and review each exact local, authentication, and deployment plan before approval;
- resource cleanup is separate and is never performed automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.12
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这个测试发行版为 Wrangler 响应失败或不确定、且 D1 尚未提交任何内容的 Owner bootstrap 增加安全恢复路径。

变更：

- 在已有 plan-bound 部署命令中增加 allowlisted `owner_bootstrap_readback` 动作；
- 使用 `--command --json` 执行一条固定的只读 D1 查询，并关闭 Wrangler 磁盘日志；
- 只记录 Owner bootstrap 所触及六张表的有界行数；
- 只有更新的读回证明所有表均为空、且前次尝试未成功时，才允许对准确的同一 hash-only SQL 重试一次；
- 后续每次失败或不确定结果都必须重新取得零状态读回；
- 任何存在、部分、畸形、已成功或漂移状态都继续进入最终化/停止路径，且绝不生成第二份 Credential；
- 保留 alpha.11 的准确身份最终化、脱敏 receipt、简化 Wrangler 身份解析和 account 固定逻辑。

现有演练只需把本地 canonical Skill 更新到本版，即可继续未变化的 alpha.8 Service plan 与原 journal；这不会升级已部署的 Service bundle，也不会生成新部署计划。

重要限制：

- 这不是 stable channel，必须由用户明确选择；
- 请使用非生产 Cloudflare 账户，并分别核对准确的本地、认证与部署计划后再授权；
- 资源清理是独立操作，绝不会自动执行。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.12
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-deploy 为我部署一套 cfKanban。
```
