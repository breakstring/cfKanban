# cfKanban 0.1.0-alpha.23

Testing prerelease / 测试发行版

## English

This testing prerelease refines the public product message and completes the first Simplified Chinese shell-copy pass found through live dogfooding.

Changes:

- replaces the public headline with “Let Agents move work forward. Collaborate from shared facts.” so the Agent is the execution subject and the board is the shared coordination record;
- changes the public deployment instruction from internal distribution jargon to the project's official source in both locales;
- translates product-owned resource names, actions, roles, priorities, relation kinds, access states, recovery guidance, pagination guidance, and Owner controls across the public, Session, Project, Issue, profile, and administration surfaces;
- keeps cfKanban brand names, Project content, user-defined workflow display names, stable protocol keys, IDs, audit event types, and other machine evidence unchanged;
- adds regression coverage for the Agent-first headline, official-source instruction, and complete Public Join risk semantics in natural Chinese.

The REST API and D1 schema are unchanged from alpha.22. The Service bundle changes because the Web UI and its compiled Static Assets change. The Skill bundle changes only to publish the alpha.23 testing pointer and plugin metadata.

Known limit:

- an error already rendered before a locale switch keeps its original language until that view performs a fresh read; fixing that without reloading or losing drafts is tracked separately.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.23
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行根据真实 dogfooding 结果，重新收敛了公开首页的产品表达，并完成第一轮简体中文界面壳层文案清理。

变更：

- 首页口号改为“让 Agent 推进，凭事实协作。”，明确 Agent 是执行主体，看板则提供所有参与者共享的工作协调事实；
- 公开部署话术不再要求用户理解内部分发术语，改为从项目声明的官方来源安装或更新；
- 公共首页、会话、项目、事项、个人资料和所有者管理界面中的资源名称、动作、角色、优先级、关系类型、访问状态、恢复建议和分页提示改为自然中文；
- cfKanban 品牌名、项目内容、用户自定义工作流显示名、稳定协议键、ID、审计事件类型与机器证据保持原样；
- 增加首页 Agent-first 口号、官方来源话术和完整公开加入风险语义的中文回归测试。

REST API 与 D1 schema 相对 alpha.22 没有变化。Web UI 及其编译后的静态资源发生变化，因此 Service bundle 会更新；Skill bundle 只更新 alpha.23 测试指针与 plugin metadata。

已知限制：

- 切换语言前已经呈现的错误会保持原语言，直到当前页面重新读取；后续会在不刷新页面、不丢草稿的前提下单独修复。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.23
codex plugin add cfkanban-agent-skills@cfkanban
```
