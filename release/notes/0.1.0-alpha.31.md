# cfKanban 0.1.0-alpha.31

Testing prerelease / 测试发行版

## English

This testing prerelease hardens the local Credential-state boundary after a live deployment preflight exposed internal metadata through otherwise read-only command output.

Changes:

- makes `state inspect` project current and pending Credential records through an explicit safe-field allowlist;
- makes `credential prepare` return the same safe metadata view while keeping the generated secret and recovery metadata in the private pending slot;
- excludes `token_digest`, `idempotency_key`, and the standalone `token_prefix` field from normal command output;
- retains the safe fingerprint, stable IDs, operation, purpose, state, and timestamps needed for diagnosis and recovery;
- adds regression coverage for both pending and current inspection, plus direct Credential preparation, checking that forbidden field names and values are absent;
- retains the Owner-side CAS recovery and in-flight form locking delivered in alpha.30.

The D1 schema and deployment topology are unchanged from alpha.30. Existing instances can upgrade by deploying the alpha.31 Service bundle without a D1 migration. The local Skill update remains independent from the Instance upgrade.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.31
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行收紧本地 Credential 状态边界：真实部署 preflight 发现，原本只读的命令输出会带出不应进入 Agent 正常上下文的内部元数据。

变更：

- `state inspect` 通过显式安全字段白名单投影 current 与 pending Credential 记录；
- `credential prepare` 返回同一类安全元数据视图，生成的 secret 与恢复元数据仍只保存在私有 pending 槽位；
- 正常命令输出不再包含 `token_digest`、`idempotency_key` 和独立的 `token_prefix` 字段；
- 保留诊断与恢复需要的安全 fingerprint、稳定 ID、operation、purpose、state 和时间字段；
- 增加 pending/current 状态检查与直接 Credential 准备回归，字段名和值都必须从输出中消失；
- 继续包含 alpha.30 已交付的 Owner 侧 CAS 恢复与写入期间表单锁定。

D1 schema 与部署拓扑相对 alpha.30 均未变化。现有实例可以直接部署 alpha.31 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是互不隐含的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.31
codex plugin add cfkanban-agent-skills@cfkanban
```
