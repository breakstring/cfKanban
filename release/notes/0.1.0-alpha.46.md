# cfKanban 0.1.0-alpha.46

## English

Testing prerelease, not a stable deployment target.

- Deployment, joining, and installation bootstrap guides now address the receiving Agent directly, continuing from the supplied task without asking the user to relay another prompt.
- Adds explicit Skill reuse/installation, command discovery, authorization-before-Credential-creation, verification, and handoff checkpoints. Uses Agent rather than Coding Agent throughout these public entrypoints.
- Keeps bilingual guides as UTF-8 plain Markdown and adds regression checks for Agent-directed instructions and authorization ordering.
- No API, permissions, schema, migration, resource or domain changes. Publishing does not implicitly update local Skills, host plugin projections or deployed Instances.

## 简体中文

测试预发行版，不是稳定部署目标。

- 部署、加入和安装引导直接面向接收任务的 Agent，承接原始请求，不再要求用户转述另一段提示词。
- 明确 Skill 复用／安装、命令发现、授权后创建凭据、验证和交付节点；这些公开入口统一使用 Agent，不限定 Coding Agent。
- 双语指南保持 UTF-8 纯 Markdown，增加面向 Agent 的文案与授权顺序回归检查。
- 不修改 API、权限、schema、migration、资源或域名；发布不隐含本地 Skill、宿主 plugin 投影或 Instance 更新。
