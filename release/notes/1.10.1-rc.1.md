# cfKanban 1.10.1-rc.1

## 简体中文

相对已公开的正式版 `1.10.0`，本 RC 减少重复请求和后台数据库工作，并为管理员提供更明确的 Cloudflare 成本保护与用量提醒。

- 匿名登录、计数和标题搜索增加独立限流与并发保护，保留原有权限和写入语义。
- Web、MCP 与 Skills 合并重复读取，后台清理与通知缓存减少反复扫描和索引写入。
- 文档及应用静态资源直接由 Static Assets 提供，保留页面安全响应头与正确的不存在资源处理。
- Owner 可查看 CPU、D1 和 R2 请求用量及可比较额度提醒；统计缺失和未知账期保持明确标识。
- 新增独立可选的域名及免费 WAF 管理流程，先核对归属、Passkey 恢复准备和升级影响。

## English

Compared with published stable `1.10.0`, this RC reduces duplicate requests and background database work, and gives administrators clearer Cloudflare cost protection and usage alerts.

- Anonymous sign-in, counts and title searches gain separate rate and concurrency protection while retaining existing permissions and write semantics.
- Web, MCP and Skills coalesce duplicate reads; background cleanup and notification caching reduce repeated scans and index writes.
- Documentation and application assets are served directly by Static Assets, retaining page security headers and correct missing-resource handling.
- Owners can inspect CPU, D1 and R2 request usage with comparable allowance alerts; missing statistics and unknown billing cycles remain explicit.
- Separate optional domain and Free WAF workflows verify ownership, Passkey recovery readiness and upgrade impact before changes.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.0` 升级包含三项兼容 migration（0022–0024），schema **21→24**，API 保持 **0.1.0**。升级前须核对实际 ledger/schema、D1 恢复点和 Worker CPU/subrequests 设置，保留原身份、资源与可选配置。普通升级不自动开启域名/WAF、变更套餐或更新本机插件/Skills。

Upgrading from `1.10.0` includes three compatible migrations (0022–0024), moving schema **21→24** while keeping API **0.1.0**. Verify the actual ledger/schema, D1 restore point and Worker CPU/subrequests settings before upgrading, preserving existing identities, resources and optional configuration. A normal upgrade does not enable domain/WAF features, change subscriptions or update local plugin/Skills automatically.

限流及并发保护为最佳努力，用量与提醒不是费用封顶或最终账单。标题子串查询、通知冷扫描及补窗仍可能随数据量增长；R2 免费额度仅在明确的 Standard 范围内比较。域名切换影响 Passkey 的 RP ID，必须先准备同一身份的恢复与重新注册路径。GitHub RC 发布不证明线上计费、边缘 WAF 或 P99 已验收。

Rate and concurrency protection is best effort; usage and alerts are neither spending caps nor final invoices. Title substring queries and cold/refill notification scans can still grow with data size; R2 free allowances are compared only within a verified Standard scope. Domain changes affect Passkey RP IDs and require same-identity recovery and re-enrollment preparation. Publishing this RC does not verify live billing, edge WAF behavior or P99 latency.
