# cfKanban 1.12.0-rc.1

## 简体中文

相对正式版 `1.11.0`，本 RC 增加项目里程碑，让阶段目标、事项归属和当前进度可以在 Web 与 Agent 中共同维护。

- 项目可按需创建多个里程碑，维护目标说明、可选日期，以及显式关闭或重新开放；空项目和空里程碑也可使用。
- Issue 可不归属里程碑，也可加入、更换或移出一个同项目目标；父子事项独立选择，关闭目标不会自动改变事项状态。
- 完整 Web 提供里程碑页面、当前进度和关联事项，看板与列表可筛选某个目标或未归属事项。
- 本地及宿主工作台的 Issue 详情可直接调整归属；Agent 和公共 CLI 支持同等的里程碑操作，技能与双语指南同步更新。

## English

Compared with stable `1.11.0`, this RC adds Project milestones so delivery goals, Issue membership and current progress can be maintained through both the Web app and Agents.

- Projects can optionally create several milestones with goal descriptions, optional due dates, and explicit close or reopen actions. Empty Projects and milestones are supported.
- An Issue can remain unassociated or join, change or leave one goal in its own Project. Parents and children choose independently, and closing a goal does not change Issue status.
- The full Web app provides milestone pages, current progress and associated Issues. Boards and lists can filter by a goal or show unassociated Issues.
- Local and host workbenches can change membership directly in Issue details. Agents and the public CLI provide equivalent milestone operations, with updated Skills and bilingual guides.

## 升级与已知限制 / Upgrade and known limitations

从 `1.11.0` 升级新增迁移 `0028_milestones.sql`，schema **27 → 28**，API 保持 **0.1.0**。旧 Issue 和身份保留，已有事项默认不归属里程碑。迁移前须核对真实 ledger/schema 与恢复点；Worker 回滚不会回退 D1，恢复应使用兼容 schema 28 的 Worker。进度按明确归属的事项数量统计，取消单独计数；趋势图另行规划。

Upgrading from `1.11.0` adds `0028_milestones.sql`, moving schema **27 → 28** while API remains **0.1.0**. Existing Issues and identities are retained, with existing Issues unassociated by default. Verify the actual ledger/schema and restore evidence before migration. Worker rollback does not revert D1; recovery should use a Worker compatible with schema 28. Progress counts explicitly associated Issues, with canceled Issues separate; trend charts are planned separately.

本地自动化检查已通过；本 RC 供线上验收，真实浏览器的里程碑选择器键盘与焦点行为尚未验收。实现及后续发布证据见 [CFK-714](https://cfkanban.dev/app/issues/CFK-714) 和 [CFK-716](https://cfkanban.dev/app/issues/CFK-716)。

Local automated checks passed. This RC is for live validation; real-browser keyboard and focus behavior of the milestone picker has not yet been validated. Implementation and subsequent publication evidence are recorded in [CFK-714](https://cfkanban.dev/app/issues/CFK-714) and [CFK-716](https://cfkanban.dev/app/issues/CFK-716).
