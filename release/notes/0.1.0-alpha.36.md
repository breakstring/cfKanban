# cfKanban 0.1.0-alpha.36

Testing prerelease / 测试发行版

## English

This testing prerelease closes the Owner Web container-creation gap found by real browser dogfooding.

Changes:

- lets an authenticated Owner `admin` Browser Session create Workspaces and Projects from the first-party Web UI;
- preserves the fixed instance-wide admin scope, CSRF validation, current-session/source checks, idempotency, and atomic Owner guard;
- keeps Project- and Issue-scoped Browser Sessions outside Owner controls;
- adds an integration regression covering both Workspace and Project creation through the Owner Cookie Session;
- requires no API, schema, or D1 migration change.

Existing instances can upgrade by deploying the alpha.36 Service bundle without a D1 migration. Local Skill update and Instance upgrade remain independent.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.36
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行修复了真实浏览器 dogfooding 发现的 Owner Web 容器创建缺口。

变更：

- 允许已认证的 Owner `admin` Browser Session 从第一方 Web UI 创建 Workspace 与 Project；
- 保留固定的实例级 admin scope、CSRF 校验、当前 Session/来源校验、幂等与原子 Owner guard；
- Project 与 Issue scope 的 Browser Session 仍不能进入 Owner 控制面；
- 新增集成回归，覆盖 Owner Cookie Session 创建 Workspace 和 Project；
- 不改变 API、schema，也不需要 D1 migration。

现有实例可以直接部署 alpha.36 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是彼此独立的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.36
codex plugin add cfkanban-agent-skills@cfkanban
```
