# cfKanban 1.10.1-rc.6

## 简体中文

相对已公开的 `1.10.1-rc.5`，本 RC 补齐域名 WAF 管理，并修正 Cloudflare Token 的保存与恢复。

- Owner 可以在网页检查当前域名的防护、预览计划并确认启用或停用；API、公共 CLI 和 Skills 提供一致流程。
- 展示规则名额、Skip 和 IP Allow 等共存限制，保留手工规则及其顺序，只管理已证明归属的本工具规则。
- 支持旧部署的受控接入、跨设备管理和升级保留；响应丢失后核对原请求，结果未确认时阻止新操作绕过。
- Token 保存不再因部署历史分页或可选能力读取失败而被误判；保存结果与各项能力检查分别显示。

## English

Compared with published `1.10.1-rc.5`, this RC completes domain WAF management and fixes Cloudflare Token saves and recovery.

- Owners can inspect protection for the current domain, review a plan, and confirm enabling or disabling it in Web. The API, public CLI and Skills provide the same workflow.
- See rule capacity and coexistence limits such as Skip and IP Allow. Manual rules and their order are preserved; only proven tool-owned rules are managed.
- Connect existing deployments through a controlled workflow, manage them from another device, and preserve current ownership during upgrades. Lost responses are checked against the original request, and unresolved operations cannot be bypassed.
- Token saves are no longer incorrectly blocked by deployment history pagination or optional capability read failures. Save results and individual capability checks remain separate.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.1-rc.5` 升级需执行保留旧记录的 **0027** migration，schema 从 **26** 升到 **27**，API 保持 **0.1.0**。升级前核对实际 ledger/schema 与恢复点，使用本发行已验证的部署工具以保留必要运行时设置。升级本身不会接管或创建 WAF 规则、修改域名或购买套餐；网页管理旧部署仍需核验目标及准确规则归属。启停需要准确 Zone 的 **Zone WAF Edit** 权限，读取通过不证明可以写入。

Upgrading from `1.10.1-rc.5` requires migration **0027**, which preserves existing records and advances schema **26** to **27** while keeping API **0.1.0**. Verify the actual ledger/schema and restore evidence first, and use this release's verified deployment tools to preserve required runtime settings. The upgrade itself does not adopt or create WAF rules, change domains, or purchase a plan. Managing an existing deployment still requires target and exact rule-ownership verification. Enabling or disabling requires **Zone WAF Edit** for the exact Zone; successful reads do not prove write permission.

本 RC 已完成隔离本地 D1/Worker、模拟 Cloudflare 与中英文桌面/移动界面验证；真实平台权限与规则效果须以获准目标的线上读回为准。

This RC has been validated with isolated local D1/Worker tests, a simulated Cloudflare provider, and Chinese/English desktop and mobile UI checks. Live platform permissions and rule effects still require readback on an authorized target.
