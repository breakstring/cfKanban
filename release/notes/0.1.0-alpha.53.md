# cfKanban 0.1.0-alpha.53

## English

- Include the UUID container migration and fixes from alpha.52.
- Restrict migration column readback to the three application tables whose removed columns are checked. Avoid inspecting D1 internal tables, which reject the dynamic all-table query with SQLITE_AUTH.
- Verified the corrected read-only query against the existing remote D1 schema before publishing. Schema 3 migration remains incompatible with older Workers; preserve business data and obtain a restore point before upgrading.

## 简体中文

- 包含 alpha.52 的 UUID 容器迁移与相关修复。
- 迁移列读回仅查询需要核对已删除列的三个应用表，避免动态枚举 D1 内部表触发 SQLITE_AUTH。
- 发布前已在现有远端 D1 schema 上验证修正后的只读查询。schema 3 迁移仍不兼容旧 Worker；升级保留业务数据并须先记录恢复点。
