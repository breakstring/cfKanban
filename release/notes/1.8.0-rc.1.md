# cfKanban 1.8.0-rc.1

## 简体中文

相对 [1.7.0](https://github.com/breakstring/cfKanban/releases/tag/1.7.0)，此 RC 增加本地任务工作台、MCP 和 DeepSeek Harness 接入，让 Agent 与侧栏中的日常任务操作共用现有 Web 体验。

- **日常 MCP 工具**：通过本地 stdio MCP 查询指定项目，创建、编辑、评论、关联和完成单张任务，沿用现有权限、并发与幂等保护。
- **本地工作台**：默认打开精简 Vue 界面，支持项目切换、看板 / 列表、行内优先级 / 状态 / 负责人修改，以及详情、评论和完成。数据仍来自同一线上实例；可明确选择线上完整版处理管理操作。
- **DeepSeek Harness 插件**：一个预构建包提供四个 Skills、MCP 和可选侧栏；桌面与 Web profile 分别安装。当前工作目录只关联一个项目时自动核验并打开，多项目时明确选择。
- **一致的导航与任务操作**：完整版和工作台共用项目菜单与状态导航；窄屏看板可横向滚动，触底追加更多事项。可复制编号、链接及原始 Markdown，移除重复交接摘要；刷新期间中断的操作仍可按原请求恢复。
- **代理集成指南**：新增与使用、管理、部署平级的文档入口，分别介绍通用 Skills / MCP 和 DSH 插件安装，并说明本地与线上 WebUI 的能力范围。

### 升级与已知限制

没有新增 migration，schema 保持 18，API 保持 0.1.0；升级仍须核对实际 ledger/schema。更新本地插件后需重启所属 MCP / 工作台，新 Codex 任务才能核对新的 Skills 加载。DSH 侧栏首版支持本机单用户 Host；Windows 原生、Linux、WSL 及远程 / 多用户 Host 尚无本轮实机验收。普通安装入口继续指向 stable，此 RC 需明确选择。

## English

Compared with [1.7.0](https://github.com/breakstring/cfKanban/releases/tag/1.7.0), this RC adds a local task workbench, MCP, and DeepSeek Harness integration so Agents and sidebars share the existing Web experience for everyday work.

- **Everyday MCP tools**: Query explicit projects and create, edit, comment on, relate, or complete individual issues over local stdio MCP, with existing authorization, concurrency, and idempotency protection.
- **Local workbench**: The default compact Vue UI supports project switching, board/list, inline priority/status/assignee edits, details, comments, and completion. Data comes from the same online instance; explicitly choose the full online UI for administration.
- **DeepSeek Harness plugin**: One prebuilt package provides four Skills, MCP, and an optional sidebar. Install Desktop and Web profiles separately. A single project associated with the current directory is verified and opened automatically; multiple projects require an explicit choice.
- **Consistent navigation and issue controls**: Full Web and the workbench share project menus and status navigation. Narrow boards scroll sideways and append issues near the bottom. Copy identifiers, links, and original Markdown without duplicate handoff summaries; operations interrupted during reload retain their original recovery request.
- **Agent integration guides**: A new documentation section alongside usage, administration, and deployment covers general Skills / MCP setup, DSH plugin installation, and the local versus online WebUI feature scope.

### Upgrade and known limitations

No migration is added; schema remains 18 and API remains 0.1.0. Upgrades still verify the actual ledger/schema. Restart the owning MCP / workbench after updating files, and use a new Codex task to verify Skill loading. The first DSH sidebar supports a local single-user Host; Windows-native, Linux, WSL, and remote / multi-user Hosts have not been tested on real devices in this run. Normal installation continues to select stable; choose this RC explicitly.
