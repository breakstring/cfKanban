# cfKanban 1.10.0-rc.7

## 简体中文

相对已公开的 `1.10.0-rc.6`，本 RC 让 Owner 升级提示与升级公告都能直接复制给 Agent，并明确本地更新的目标版本。

- Owner 的提示先给出目标版本，要求本地插件和当前站点线上部署都更新到该版本。
- 升级公告提供可复制的 Agent 提示，将本地插件和技能更新到公告中的准确版本。
- 中英文提示保持一致，公告中的本地更新请求不重复升级已经部署的站点。

## English

Compared with published `1.10.0-rc.6`, this RC makes the Owner upgrade prompt and upgrade announcement ready to copy to an Agent, with an explicit version for local updates.

- The Owner prompt names the target version first and asks to update both the local plugin and the current site's deployment to that version.
- Upgrade announcements include a copyable Agent prompt to update the local plugin and Skills to the exact announced version.
- Chinese and English prompts match; the announcement's local update request does not redeploy the already upgraded site.

## 升级与已知限制 / Upgrade and known limitations

从 RC.6 升级无新增 migration，schema 保持 **21**，API 保持 **0.1.0**；仍需核对实际 ledger/schema。新公告措辞用于后续成功升级创建的公告，已有公告正文保持不变。本次发布 GitHub RC，供用户手动升级；未自动更新线上部署或本地插件/技能。

Upgrading from RC.6 adds no migrations and keeps schema **21** and API **0.1.0**; verify the actual ledger/schema. The new announcement wording applies to notices created after future successful upgrades; existing notice bodies remain unchanged. This release publishes the RC on GitHub for manual upgrading, without updating the deployment or local plugin/Skills automatically.
