# cfKanban 0.1.0-alpha.26

Testing prerelease / 测试发行版

## English

This testing prerelease makes Owner audit scope explicit and consistent across the Service, OpenAPI, Web UI, and Admin Skill.

Changes:

- adds optional immutable `project_id` and `stream=domain|security` filters to `GET /api/v1/admin/audit-events`;
- returns normalized `resolved_filters` on every audit page, while omission deliberately means an Instance-wide, both-stream read;
- binds both filters into the opaque cursor scope so a changed Project or stream rejects the old cursor with `CURSOR_SCOPE_MISMATCH`;
- keeps Project-only reads on the existing Project/stream Event index by merging two bounded stream branches, with no D1 migration;
- adds matching Project and stream controls to Owner Web, resets pagination when filters change, and shows stream plus Project scope on each event;
- updates `cfkanban-admin`, the Frozen API/Web/Skill contracts, OpenAPI, and regression coverage to use the same behavior.

The REST API changes additively from alpha.25. The D1 schema is unchanged. Both bundles change: the Admin Skill guidance changes, and the Service/Web implementation plus compiled Static Assets change.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.26
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行让 Owner 审计范围在 Service、OpenAPI、Web 与 Admin Skill 中保持明确一致。

变更：

- `GET /api/v1/admin/audit-events` 新增可选的不可变 `project_id` 与 `stream=domain|security` 筛选；
- 每页都返回规范化的 `resolved_filters`；两项都省略时明确表示读取整个实例的两类事件；
- 两项筛选都会进入不透明 cursor 的 scope，修改项目或事件类型后复用旧 cursor 会返回 `CURSOR_SCOPE_MISMATCH`；
- 仅按项目读取时合并既有 Project/stream Event 索引上的两个有界分支，不新增 D1 migration；
- Owner Web 增加对应的项目与事件类型控件，筛选变化时重置分页，并在每条事件上显示 stream 与项目范围；
- `cfkanban-admin`、Frozen API/Web/Skill 合同、OpenAPI 与回归测试统一为同一行为。

REST API 相对 alpha.25 是加法式变更，D1 schema 不变。两个 bundle 都会变化：Admin Skill 指引变化，Service/Web 实现及其编译后的静态资源也发生变化。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.26
codex plugin add cfkanban-agent-skills@cfkanban
```
