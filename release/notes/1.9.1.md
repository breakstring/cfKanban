# cfKanban 1.9.1

## 简体中文

相对正式版 `1.9.0`，本版新增围绕当前项目工作的公共 CLI，并改善看板列表加载与状态识别。

- 通过统一的 `cfkanban` 入口完成日常协作、管理和按授权计划部署，支持原操作恢复，CLI 随完整 Skills 安装与更新。
- 从仓库根目录、子目录或 worktree 自动解析推荐范围，唯一实例无需重复指定 UUID；多候选可在终端选择，Agent 调用返回结构化候选。
- 按实际任务精简常用帮助，提供中英文指南和按需展开的高级参数；JSON 模式保留完整命令目录与结构化结果。
- 已有实例可沿已可信的自定义域名通过 CLI 升级与续跑，在云端写入前核对计划地址和 Owner 身份。
- Issue 列表远程加载时显示等待反馈，局部排序保留已加载内容与展开状态；完整版看板和工作台使用一致的状态颜色标识。

## English

Compared with stable `1.9.0`, this release adds a public CLI centered on the current Project and improves board list loading and status recognition.

- Use one `cfkanban` entry point for daily collaboration, administration and deployments under an authorized plan, with original-operation recovery; the CLI installs and updates with the complete Skills bundle.
- Resolve recommended scope from the repository root, subdirectories or worktrees without repeating a unique Instance UUID; terminal users can select among candidates, while Agent calls receive structured choices.
- Follow task-focused help and bilingual guides, with advanced options available on demand; JSON mode retains the complete command catalog and structured results.
- Upgrade and resume existing Instances through their trusted custom domains, checking the planned origin and Owner identity before cloud writes.
- See waiting feedback during remote Issue loading, retain loaded content and expanded rows when sorting locally, and recognize consistent status colors across the full board and Workbench.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 19、API 保持 0.1.0；升级仍需核对真实 ledger/schema。CLI 随完整 Skills 更新，Node 要求仍为 >=22.12.0。Linux、Windows 原生和独立 WSL2 的实际验收尚未完成，相关记录保留在 [CFK-592](https://cfkanban.dev/app/issues/CFK-592)。

No new migration; schema remains 19 and API remains 0.1.0. Verify the actual ledger/schema during upgrade. The CLI updates with the complete Skills bundle and still requires Node >=22.12.0. Acceptance on Linux, native Windows and independent WSL2 remains unverified; follow [CFK-592](https://cfkanban.dev/app/issues/CFK-592) for those results.

本版基于已验收的 [1.9.1-rc.4](https://github.com/breakstring/cfKanban/releases/tag/1.9.1-rc.4) 源码；源码验证、`cfkanban.dev` 自定义域名 CLI 升级与回执见 [CFK-598](https://cfkanban.dev/app/issues/CFK-598)，用户已试用部分常用 CLI 命令。

This release is based on the accepted [1.9.1-rc.4](https://github.com/breakstring/cfKanban/releases/tag/1.9.1-rc.4) source. Source validation and the custom-domain CLI upgrade and receipt for `cfkanban.dev` are recorded in [CFK-598](https://cfkanban.dev/app/issues/CFK-598); the user also tried a selection of common CLI commands.
