# cfKanban 1.0.0-rc.2

## English

The second 1.0 release candidate adds participant project switching and a Howto Skill, and improves invitation feedback. It remains a prerelease for cross-system acceptance testing.

- Newly redeemed participant Browser Launch sessions open the requested Project or Issue and allow switching among currently authorized Projects. Every request still checks the current Project Grant and role. Revoked or archived Projects disappear from the selection; switching never grants access.
- Existing fixed-scope sessions retain their scope. Reopen through your Agent to obtain a new session with project switching. Owner admin sessions and Owner Project/Issue sessions retain their existing scope behavior. Session lifetime, source-Credential revocation, and CSRF protections remain unchanged.
- Show copying, success, and failure feedback on “Copy for Agent” buttons. After invitation details have been saved successfully, “I saved it · Done” closes the invitation flow instead of returning to the creation dialog.
- Add `cfkanban-howto`, a read-only onboarding guide covering daily collaboration, Owner administration, and deployment in that order. The plugin now includes this guide plus the existing three operational Skills.
- Pin installation, deployment, joining guides, and plugin metadata to this immutable RC release.
- Preserve API version 0.1.0 and schema 7. This release adds no migration, Cloudflare resource, subscription, or change to existing Grants and Public Join policies.

Windows/WSL, additional browsers, physical-device Passkey, fresh installation, and interrupted-upgrade acceptance remain part of RC testing. Local Skills/plugin updates and deployed Service upgrades remain separate operations.

## 简体中文

第二个 1.0 候选版本，新增参与者项目切换和 Howto 入门技能，并改善邀请流程反馈；仍为跨系统验收用的预发行版。

- 参与者新兑换的 Browser Launch 会话先打开指定项目或 Issue，并可切换当前已授权项目。每次请求继续校验目标项目的实时 Grant 和角色；已撤权或归档项目不会出现在选择列表，切换本身不授予权限。
- 已有固定范围会话保持原范围，通过 Agent 重新打开即可获得支持切换的新会话。Owner 管理会话以及 Owner 的 Project/Issue 会话保留原有范围行为。会话时长、源 Credential 撤销和 CSRF 防护不变。
- “复制给智能体”按钮展示复制中、成功与失败反馈；成功确认保存邀请信息后，“我已保存，完成”直接关闭邀请流程，不再返回创建弹窗。
- 新增只读教学技能 `cfkanban-howto`，依次介绍日常协作、Owner 管理和部署维护；插件包含此指南及原有三个操作技能。
- 安装、部署、加入指南及插件元数据统一固定到本次不可变 RC 版本。
- API 版本保持 0.1.0、schema 保持 7；不增加迁移、Cloudflare 资源或订阅，也不修改已有 Grants 和公开加入策略。

Windows/WSL、其他浏览器、实体设备 Passkey、全新安装和升级中断恢复仍属于 RC 验收范围。本地技能/插件更新与线上 Service 升级保持为独立操作。
