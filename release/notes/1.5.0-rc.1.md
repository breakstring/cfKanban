# cfKanban 1.5.0-rc.1

## 简体中文

- 所有已登录网页统一采用 Nuxt UI 组件，调整看板、Issue 详情、工作列表、项目选择、个人设置及管理页面的按钮、表单、弹窗和菜单，并补齐桌面与移动端布局、焦点管理和键盘交互。
- 个人设置新增暖橙、静蓝两种主题。主题按 Principal 保存在服务端，Web 与 Agent 可读取和修改；现有及新建用户默认暖橙。切换主题保持相同布局，保存失败保留未提交草稿，迟到的会话响应不会覆盖已确认的新主题。
- 账户菜单集中显示姓名、身份和账户操作，语言切换保留独立入口；会话到期时间与适用时的首选域名链接移至页脚。看板使用统一的“项目设置”入口，按当前权限提供管理、标签、活动和已删除页面，并在返回同一项目时保留筛选条件。
- 加固会话重新验证和项目切换的竞态处理，避免旧请求覆盖新会话。会话仍从创建时起固定有效 8 小时，刷新页面、切换项目及操作不会延长到期时间；自动续期属于后续 CFK-529，不包含在本次发行中。
- `PATCH /api/v1/me` 支持携带 `expected_version` 修改姓名、主题或两者，并可使用 `Idempotency-Key` 安全重试原请求。保留现有仅修改姓名的请求兼容性；CAS、当前权限检查及原子审计继续由服务端执行。同步中英文公开文档和 Agent 操作示例。

本次新增向后兼容的 D1 migration `0014_principal_theme.sql`，将 schema 从 13 升至 14，为 Principal 增加默认 `orange` 的主题字段，不删除既有数据。API 兼容版本保持 `0.1.0`，发行 manifest 继续使用 schema 2。使用兼容本发行的 Skills，按固定发行清单完成迁移及 Worker 升级；Owner 恢复工具已支持 schema 14。Skills 更新与实例升级仍是独立操作，Worker 回滚不会回退 D1 schema。

本轮本地检查通过 569 项测试和 140 项 D1 集成测试，并完成 Web/Worker 构建及 46 页双语文档检查。浏览器验收覆盖 14 个页面在 1440、800、390 像素宽度下的布局，以及 Owner、管理员、writer、reader 的项目设置导航、主题保存和关键 Issue 操作；最终响应式检查未发现页面横向溢出或浏览器错误。证据随 CFK-528 记录；这些检查不代表线上升级验收或新会话已加载更新后的 Skills。

已知限制：当前主 JavaScript 包约 871 kB，gzip 后约 259 kB，仍触发 Vite 的大包提示；慢网络下的首次加载需要继续观察。此 RC 不推进 main、stable 或 GitHub Latest。

## English

- All signed-in pages now use Nuxt UI components, with updated buttons, forms, dialogs, and menus across boards, Issue details, work lists, project selection, personal settings, and management pages. The update also improves desktop/mobile layouts, focus management, and keyboard interactions.
- Personal settings offer Warm orange and Calm blue themes stored on the server for each Principal. Both Web and Agent clients can read and update the preference; existing and new users default to orange. Themes share the same layout. Failed saves retain unsaved drafts, and late session responses cannot overwrite a confirmed newer theme.
- The account menu groups the user's name, role, and account actions, while language switching remains separately accessible. Session expiry and the preferred-origin link, when applicable, move to the footer. A single Project settings entry on the board exposes Management, Labels, Activity, and Deleted pages according to current permissions and preserves filters when returning to the same project.
- Session revalidation and project switching handle races so older requests cannot overwrite a newer session. Sessions still expire exactly eight hours after creation; page refreshes, project switches, and activity do not extend expiry. Automatic renewal is tracked separately in CFK-529 and is outside this release.
- `PATCH /api/v1/me` accepts `expected_version` with a name, theme, or both, and supports `Idempotency-Key` for safe retries of the original request. Existing name-only requests remain compatible. The server continues to enforce CAS, current authorization, and atomic audit records. Bilingual public documentation and Agent examples reflect the updated flows.

This release adds the backward-compatible D1 migration `0014_principal_theme.sql`, moving schema 13 to 14 and adding a Principal theme field defaulting to `orange`, without deleting existing data. The API compatibility version remains `0.1.0`, and release manifests continue to use schema 2. Use compatible Skills and the pinned release manifest to apply the migration and upgrade the Worker. Owner recovery tooling supports schema 14. Skills updates and instance upgrades remain separate operations; rolling back the Worker does not roll back the D1 schema.

Local checks passed 569 tests and 140 D1 integration tests, Web/Worker builds, and checks for 46 bilingual documentation pages. Browser validation covered 14 pages at widths of 1440, 800, and 390 pixels, plus project settings navigation for Owner, administrator, writer, and reader roles, theme persistence, and key Issue operations. The final responsive checks found no page-level horizontal overflow or browser errors. Evidence accompanies CFK-528; these checks do not establish online upgrade acceptance or loading of updated Skills in a fresh conversation.

Known limitation: the main JavaScript bundle is approximately 871 kB, or 259 kB gzipped, and still triggers Vite's large-chunk warning. Initial loading on slow networks needs further observation. This RC does not advance main, stable, or GitHub Latest.
