# 1.4.1-rc.1

## 简体中文

- 安装与更新面向支持 Skills 的 Agent，先识别宿主：Git 来源可跟随只承载正式发行的默认 main，目录型宿主安装完整已验证 bundle。Codex 命令仅为示例，普通安装省略固定版本 ref；显式历史版与 RC 仍固定准确发行。
- 版本发现继续固定单次操作的 manifest、版本与工件摘要；默认发现的 `marketplace.ref` 为 `null`，安装后仍核对宿主来源、内容和加载状态。
- 同步双语安装、加入与更新指南，说明已有固定 tag 来源的手动迁移，以及按宿主复用现有入口/目录投影的本地开发验证方式。
- 开发在 feat/fix 等专门分支进行，项目主目录即可；RC 验收和正式工件公开校验后，main 才推进到正式提交。
- 无 D1 migration；API 兼容版本仍为 `0.1.0`，schema 仍为 13。此 RC 不推进 main 或 GitHub Latest，也不隐含技能或实例自动更新。

## English

- Installation and updates identify the Skills-capable Agent host first. Git-backed hosts can follow the default main branch containing published stable releases; directory-based hosts install the complete verified bundle. Codex commands are examples, with no version ref for ordinary installation. Explicit historical and RC selections retain an exact release.
- Release discovery continues to pin the manifest, version, and artifact digests for each operation. Default discovery returns `marketplace.ref: null`; installation still verifies host source, content, and loading.
- Bilingual installation, joining, and update guides explain manual migration from pinned Git sources and local development through the host's existing entry or directory projection.
- Development uses dedicated feature/fix branches, optionally in the existing project directory. Main advances to the stable commit after RC acceptance and verification of the published stable artifacts.
- No D1 migration; the API compatibility version remains `0.1.0` and schema remains 13. This RC does not advance main or GitHub Latest or automatically update local Skills or instances.
