# 1.9.1-rc.4

## 简体中文

相对 1.9.1-rc.3，修复公共 CLI 对已有实例自定义域名的升级与续跑支持。

- 已有实例沿用当前可信域名，`cfkanban.dev` 等自定义域名可通过 CLI 完成升级和回执。
- 在云端写入前核对计划域名与 Owner 身份，提前检出漂移。
- 认证读回绑定当前可信地址，拒绝重定向和 origin version 回退；文档、帮助与技能指南同步说明。

## English

Compared with 1.9.1-rc.3, fix public CLI upgrades and resumes for existing Instances using custom domains.

- Preserve the current trusted origin so custom-domain Instances such as `cfkanban.dev` can complete CLI upgrades and receipts.
- Check the planned origin and Owner identity before cloud writes to detect drift early.
- Bind authenticated readback to the current trusted address and reject redirects or origin-version rollback, with matching docs, help and Skill guidance.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 19、API 保持 0.1.0，升级仍核验真实 ledger/schema。先更新本地 Skills/CLI 到本版本，再用 CLI 升级自定义域名实例。本 RC 不推进 stable/main；其他操作系统和当前聊天的宿主热加载不由本地测试替代。

No new migration; schema remains 19 and API remains 0.1.0. Verify the actual ledger/schema during upgrade. Update local Skills/CLI to this version before upgrading a custom-domain Instance through the CLI. This RC does not advance stable/main; local tests do not replace other-OS acceptance or prove hot loading in the current chat.

验证与发行记录 / Validation and release record: [CFK-598](https://cfkanban.dev/app/issues/CFK-598).
