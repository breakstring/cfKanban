# cfKanban 1.8.0-rc.4

## 简体中文

相对 `1.8.0-rc.3`，本 RC 润色中英文使用文档，让用户更容易直接向 Agent 表达需求。

- 明确 Agent first 的使用方式：大多数日常协作无需打开界面，想亲自查看或操作时再选择本地轻量工作台或线上完整版。
- 简化安装、协作和维护示例，移除多余的内部操作要求，同时保留权限、恢复和破坏性操作的必要条件。
- 澄清 Passkey 登记：让 Agent 打开普通线上页面即可，无需在话术中声明登记用途或申请管理入口。
- 同步 howto 技能的讲解原则，避免将示例话术当作固定口令。

## English

Compared with `1.8.0-rc.3`, this RC polishes the Chinese and English documentation so users can express their goals directly to their Agents.

- Clarify the Agent first workflow: most daily collaboration needs no UI; choose the lightweight local workbench or full online app when you want to view or act yourself.
- Simplify setup, collaboration, and maintenance examples while retaining necessary permission, recovery, and destructive-operation requirements.
- Clarify Passkey registration: an ordinary online page opened by your Agent is sufficient, without a special registration prompt or management entry.
- Align the howto Skill so it treats example prompts as illustrations, not fixed commands.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；升级仍须核对真实 ledger/schema。Passkey 首次和补充登记仍需 Agent 打开的线上会话，并由用户完成浏览器或系统确认。技能更新后需在新会话验证加载。

No migration is added; schema remains 18 and API remains 0.1.0. Verify the actual ledger/schema during upgrade. First and additional Passkey registrations still require an Agent-opened online session and user confirmation in the browser or operating system. Verify updated Skill loading in a new session.
