# cfKanban 0.1.0-alpha.17

Testing prerelease / 测试发行版

## English

This testing prerelease makes Invite and Public Join command results stable across new and existing Principal modes. A real second-run invitation test found that new-Principal redemption returned `{ operation, credential }`, while current-Principal redemption returned the raw operation directly.

Changes:

- returns `{ operation, credential }` from both `invite redeem` and `public-join redeem` for every identity mode;
- reports the reused local Credential as `current` even when the remote domain operation fails, while preserving the structured failure under `operation`;
- keeps current Credential and one-shot Invite values redacted from every returned field;
- adds a regression covering both current-Principal command paths and their secret-safe shape;
- retains alpha.16's safe recovery of Service-assigned Credential IDs and exact deployment Owner bootstrap binding.

The correction changes only the Skill bundle and release documentation. An already deployed compatible Service does not need to be upgraded.

Important limits:

- this is not the stable channel and must be selected explicitly;
- use this version instead of alpha.16 when one harness or Agent must handle both first and repeated joins;
- broader Web concurrency, target-scope, pagination, and browser hardening remain release-candidate work;
- host or operating-system permission prompts remain independent of cfKanban's application-level authorization.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.17
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-admin to create my first cfKanban board.
```

## 简体中文

这次测试发行统一 Invite 与 Public Join 在新建和复用 Principal 时的命令结果。真实的第二次邀请测试发现：新建 Principal 返回 `{ operation, credential }`，复用 current Principal 却直接返回原始 operation。

变更：

- `invite redeem` 与 `public-join redeem` 的所有身份模式统一返回 `{ operation, credential }`；
- 复用身份时，即使远端领域操作失败，本地既有 Credential 仍准确报告为 `current`，结构化失败保留在 `operation`；
- 返回结果继续清除 current Credential 与一次性 Invite 值；
- 新增两条 current-Principal 命令路径及其 secret-safe 结构回归；
- 保留 alpha.16 对 Service 分配 Credential ID 的安全恢复，以及部署 Owner bootstrap 的精确 ID 绑定。

本次修正只改变 Skill bundle 与发行文档；已经部署的兼容 Service 无需升级。

重要限制：

- 这不是 stable channel，必须由用户明确选择；
- 同一 harness 或 Agent 需要同时处理首次和重复加入时，应使用本版本取代 alpha.16；
- Web 并发、target scope、分页与浏览器加固仍属于 release candidate 工作；
- Agent 宿主或操作系统自己的权限提示仍独立于 cfKanban 应用层授权。

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.17
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text

```
