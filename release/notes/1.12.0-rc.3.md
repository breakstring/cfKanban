# cfKanban 1.12.0-rc.3

## 简体中文

相对 `1.12.0-rc.2`，本 RC 优化项目工具栏分组，并统一事项详情的里程碑下拉样式。

- 宽屏工具栏左侧切换视图、中间搜索项目、右侧筛选事项，三组之间保留清晰间距。
- 工具栏宽度不足时有序分行，搜索和筛选不会互相挤压。
- 里程碑选择改为文字后置下拉箭头，与状态、优先级和负责人属性保持一致，并保留键盘操作和焦点反馈。

## English

Compared with `1.12.0-rc.2`, this RC improves Project toolbar grouping and makes the milestone dropdown consistent with other Issue properties.

- Wide toolbars align view switches left, Project search in the center and Issue filters right, with clear spacing between groups.
- Groups move to separate rows when toolbar space is limited, keeping search and filters from crowding each other.
- Milestones use a trailing dropdown arrow consistent with status, priority and assignee properties, retaining keyboard and focus behavior.

## 升级与已知限制 / Upgrade and known limitations

相对 `1.12.0-rc.2` 无新增 migration，API 保持 **0.1.0**、schema 保持 **28**；升级仍须核对实际 ledger/schema。本轮不包含本地技能插件更新。实现与验收证据见 [CFK-719](https://cfkanban.dev/app/issues/CFK-719)。

There are no new migrations relative to `1.12.0-rc.2`; API remains **0.1.0** and schema remains **28**. Verify the actual ledger/schema before upgrading. This operation does not update local Skill plugins. Implementation and validation evidence are recorded in [CFK-719](https://cfkanban.dev/app/issues/CFK-719).
