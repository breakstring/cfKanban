# cfKanban 0.1.0-alpha.21

Testing prerelease / 测试发行版

## English

This testing prerelease completes the Browser recovery and operational UX pass found through live dogfooding.

Changes:

- serves `/`, `/app`, and SPA deep links with `Cache-Control: no-store` and `Referrer-Policy: no-referrer`, while fingerprinted assets remain directly served with immutable caching;
- shows the non-secret Session expiry in authenticated pages and presents a different preferred origin as a hint without automatic redirect;
- preserves a selectable, readonly Agent instruction when clipboard access is rejected;
- uses one locale storage key across the SPA and standalone Invitation page;
- renders Project-specific status display names in the Issue detail selector while keeping stable status keys on the wire;
- adds deterministic expiry, locale, clipboard, security-header, scope, recovery, and display-name regression coverage.

The REST API and D1 schema are unchanged from alpha.20. The Service bundle changes because the Worker routing, Web UI, and Static Assets headers change.

Important limits:

- this is not the stable channel and must be selected explicitly;
- Skill update and Instance upgrade remain separate plans;
- a preferred-origin hint never sends the current Session to the other origin automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.21
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行补齐了真实 dogfooding 中发现的 Browser 恢复与运维体验。

变更：

- `/`、`/app` 与 SPA 深层链接固定返回 `Cache-Control: no-store` 与 `Referrer-Policy: no-referrer`，指纹资源继续由 Static Assets 直出并使用 immutable 缓存；
- 已认证页面显示非敏感的 Session 到期时间；当 preferred origin 不同时只给出提示，不自动跳转；
- 剪贴板权限被拒绝时，保留可选中的只读 Agent 话术；
- SPA 与独立 Invitation 页使用同一个 locale 存储 key；
- Issue 详情状态选择器显示 Project 自定义名称，wire 上仍使用稳定 status key；
- 补充到期、语言、剪贴板、安全响应头、scope、恢复与显示名的确定性回归覆盖。

REST API 与 D1 schema 相对 alpha.20 没有变化。由于 Worker 路由、Web UI 与 Static Assets 响应头变化，Service bundle 会更新。

重要限制：

- 这不是 stable channel，必须由用户明确选择；
- Skill update 与 Instance upgrade 仍是两份独立计划；
- preferred-origin 提示绝不会自动把当前 Session 发往另一个 origin。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.21
codex plugin add cfkanban-agent-skills@cfkanban
```
