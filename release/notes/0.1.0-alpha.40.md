# cfKanban 0.1.0-alpha.40

Testing prerelease / 测试发行版

## English

This testing prerelease makes Owner Audit interpretation explicit: an Event's resource identity and its historical authorization evidence are related but distinct facts.

Changes:

- tells `cfkanban-admin` to identify a resource lifecycle through `subject.type` and `subject.id`;
- explains that `grant_id` can reference the Project Grant that authorized a participant's Issue, Comment, Label, or Relation write;
- prevents Agents from selecting Grant lifecycle Events by `grant_id` alone;
- adds the same distinction to the bilingual Owner workflow guide and the Frozen API/Schema contract;
- exposes the semantics in the generated OpenAPI descriptions and protects them with contract tests;
- extends the real-instance harness with writer → reader → revoke → regrant verification, including assignment availability, deterministic reassignment candidates, hidden-resource behavior, denied-write immutability, stable Grant identity, and exact Audit history;
- changes no runtime authorization rule, D1 schema, migration, or resource mutation behavior.

The public deployment and join guides are refreshed with the alpha.40 immutable ref. Existing instances need only a Worker/OpenAPI/static-assets refresh; the Skill update and Instance upgrade remain independently planned operations.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.40
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行把 Owner Audit 的解释讲清楚：Event 的资源身份与当时的授权证据彼此相关，但不是同一件事。

变更：

- 要求 `cfkanban-admin` 使用 `subject.type` 与 `subject.id` 识别资源生命周期；
- 解释 `grant_id` 可以引用参与者写 Issue、Comment、Label 或 Relation 时使用的 Project Grant；
- 避免 Agent 只按 `grant_id` 选择 Grant 生命周期 Event；
- 在中英文 Owner 工作流指南和 Frozen API/Schema 合同中同步这一语义；
- 通过生成的 OpenAPI 字段说明公开该语义，并用合同测试保护；
- 扩展真实实例测试，覆盖 writer → reader → revoke → regrant，以及 assignment 可用性、确定性重新分配候选、资源隐藏、拒绝写入不落库、Grant 行身份稳定和准确 Audit 历史；
- 不改变运行时授权规则、D1 schema、migration 或资源写入行为。

公开部署与加入指南同步更新为 alpha.40 的不可变 ref。现有实例只需刷新 Worker/OpenAPI/静态资源；Skill update 与 Instance upgrade 仍然是分别规划的操作。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.40
codex plugin add cfkanban-agent-skills@cfkanban
```
