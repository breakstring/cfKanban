# cfKanban 1.9.2

## 简体中文

相对正式版 `1.9.1`，本版新增 Codex App 原生工作台，并统一项目切换、窄窗口看板和语言偏好体验。本版沿用已完成 Codex App 原生验收的 `1.9.2-rc.1` 功能。

- 从 Codex App 侧边栏或当前对话打开 cfKanban 工作台，直接查看、创建和编辑事项，分配负责人、添加评论或记录完成结果。
- 全局入口与仓库入口分别记住上次项目；没有有效记录时，在已验证连接中直接打开可访问项目。项目菜单按工作区分组，可分页切换当前实例内所有有权限的项目。
- 看板五列随工作台宽度调整，卡片属性不会被内容撑出边界；较窄面板保留横向滚动，Codex、DSH 和本地浏览器使用同一布局。
- 完整版 Web 与本地工作台优先使用本人已保存的语言偏好，未设置时跟随宿主或浏览器首选语言；中文显示简体中文，其他语言默认英文。默认状态、产物类型与公共提示同步切换，业务原文保留。
- Web、文档、favicon、Codex 与 DSH 使用统一的看板线条标志，彩色位置使用 cfKanban 橙色，侧边栏图标在小尺寸下更清晰。

## English

Compared with stable `1.9.1`, this release adds a native Codex App workbench and aligns project switching, narrow-window boards, and language preferences. This stable release retains the functionality validated in the native Codex App during `1.9.2-rc.1` acceptance.

- Open the cfKanban workbench from the Codex App sidebar or the current conversation to view, create, and edit issues, assign people, add comments, or record completion.
- Global and repository entrypoints remember their last projects separately. Without a valid saved choice, a verified connection opens an accessible project directly. The project menu groups workspaces and supports paginated switching across all accessible projects in the current instance.
- The five board columns adapt to the workbench width, and card properties stay inside their boundaries. Narrow panels retain horizontal scrolling, with the same layout across Codex, DSH, and the local browser.
- The full Web UI and local workbenches prefer the current account's saved language, falling back to the host or browser's preferred language when unset. Chinese locales use Simplified Chinese; other languages default to English. Default statuses, artifact types, and public messages switch together while business content stays unchanged.
- The Web UI, documentation, favicon, Codex, and DSH share a simple board-outline mark. Colored surfaces use cfKanban orange, and small sidebar icons are clearer.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.1` 升级无新增 migration，schema 保持 **19**、API 保持 **0.1.0**，仍需核对实际 ledger/schema。实例升级与本机 Skills/插件更新分别执行；先处理原视图中尚未确定的写入，更新插件后关闭旧工作台并重启 MCP/宿主，再重新打开。当前正在运行的宿主与旧视图不会因磁盘上的文件更新而自动加载新版本。

Upgrading from `1.9.1` adds no migration: schema remains **19** and the API remains **0.1.0**. Verify the actual ledger/schema. Instance upgrades and local Skills/plugin updates remain separate. Resolve uncertain writes in their original views before updating, then close old workbenches, restart MCP/the host, and reopen them. Updating files on disk does not automatically reload the running host or its existing views.

Codex 原生入口要求当前宿主支持官方 Plugin Extensions；多个尚未确定的实例连接仍需选择连接。本版尚未提供业务 deep links 或 Composer At-Mentions。[CFK-602](https://cfkanban.dev/app/issues/CFK-602) 的 Fullscreen 优化仍未实施。自定义状态名称若恰好等于对应默认英文名，也按默认显示值本地化；其他自定义名称保留原文。

Native Codex entrypoints require a current host supporting official Plugin Extensions; multiple unresolved instance connections still require a connection choice. Business deep links and Composer At-Mentions are not included. The Fullscreen improvements tracked in [CFK-602](https://cfkanban.dev/app/issues/CFK-602) remain unimplemented. Custom status names that exactly match their default English names are also displayed as localized defaults; other custom names remain unchanged.

实现与验收记录 / Implementation and acceptance record: [CFK-600](https://cfkanban.dev/app/issues/CFK-600).
