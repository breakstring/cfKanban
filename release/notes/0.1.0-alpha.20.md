# cfKanban 0.1.0-alpha.20

Testing prerelease / 测试发行版

## English

This testing prerelease fixes the Worker deployment readback used by existing-Instance upgrades.

Changes:

- uses `wrangler deployments status --json` for the authoritative current production deployment;
- no longer selects the first item from `wrangler deployments list`, whose history order placed an older deployment first in live testing;
- requires one current deployment object with exactly one version receiving 100 percent of traffic;
- rejects deployment-history arrays instead of guessing which historical entry is current;
- adds regression coverage for both upgrade finalization and exact-name Worker preflight.

The Service API and D1 schema are unchanged from alpha.19. This release was triggered by the live alpha.8-to-alpha.19 upgrade: deployment produced a new Worker version, while the alpha.19 readback incorrectly selected the prior historical version and correctly prevented finalization.

Important limits:

- this is not the stable channel and must be selected explicitly;
- Skill update and Instance upgrade remain separate plans;
- D1 restore remains outside the executable Skill surface and requires separate authorization.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.20
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行修复既有 Instance 升级所使用的 Worker deployment 读回。

变更：

- 使用 `wrangler deployments status --json` 获取权威的当前生产 deployment；
- 不再从 `wrangler deployments list` 的第一个元素取值；真实测试中，该历史列表把旧 deployment 放在前面；
- 要求读回结果是单个当前 deployment，且只能有一个获得 100% 流量的版本；
- 对 deployment 历史数组直接停止，不猜测哪个历史项才是当前状态；
- 为升级最终化和 Worker 准确名称 preflight 增加回归覆盖。

Service API 与 D1 schema 相对 alpha.19 没有变化。本版本来自一次真实的 alpha.8 → alpha.19 升级：Worker 已经发布出新版本，但 alpha.19 读回错误选中了旧历史版本，并按设计阻止了最终化。

重要限制：

- 这不是 stable channel，必须由用户明确选择；
- Skill update 与 Instance upgrade 仍是两份独立计划；
- D1 restore 仍不在 Skill 的可执行表面内，并需要独立授权。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.20
codex plugin add cfkanban-agent-skills@cfkanban
```
