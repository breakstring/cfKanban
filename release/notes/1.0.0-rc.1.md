# cfKanban 1.0.0-rc.1

## English

The first 1.0 release candidate is intended for cross-system acceptance testing. It is a prerelease, not a stable release.

- Show Public Join enabled/disabled badges in the Owner project list, with an explicit unknown state if the status is unavailable. Policy changes refresh the list from the Service.
- Correct the size and alignment of Public Join and Principal Recovery confirmation checkboxes on desktop and narrow screens while retaining a clickable label.
- Pin installation, deployment and joining guides to this immutable RC release.
- Preserve API version 0.1.0 and schema 7. This release adds no migration, Cloudflare resource, permission, subscription, or public-access policy change.

Source validation and local browser checks do not replace Windows/WSL, additional browsers, physical-device Passkey, fresh installation, or interrupted-upgrade acceptance. Those checks remain part of RC testing. Attachment uploads still require the Owner to choose an application storage limit or explicitly select unlimited capacity.

## 简体中文

首个 1.0 候选版本，用于跨系统验收；仍为预发行版，不代表稳定版已发布。

- 在 Owner 项目列表展示公开加入已开启/已关闭标识；缺少状态时明确显示未知，修改策略后重新读取服务端状态。
- 修复公开加入及身份恢复确认复选框的尺寸与排列，在桌面和窄屏保持正常大小并保留整行标签点击能力。
- 安装、部署和加入指南统一固定到本次不可变 RC 版本。
- API 版本保持 0.1.0、schema 保持 7；不增加迁移、Cloudflare 资源、权限或订阅，也不修改已有公开加入策略。

源码自动验证与本地浏览器验证不能代替 Windows/WSL、其他浏览器、实体设备 Passkey、全新安装和升级中断恢复验收；这些仍属于 RC 测试范围。附件上传仍需 Owner 自行选择应用容量上限或明确选择不限制。
