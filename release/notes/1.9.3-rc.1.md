# cfKanban 1.9.3-rc.1

## 简体中文

相对正式版 `1.9.2`，本 RC 改善 Codex 中打开与查看事项的体验，并整理 Agent 接入文档，供真实宿主升级后验收。

- 明确指定事项编号时，Codex 对话工作台直接加载对应详情、描述与评论，省去从看板中再次查找；身份、权限或项目不匹配时返回明确错误。
- 支持宿主官方 Composer At-Mentions 的精确事项搜索与引用，采用有界的轻量读取；完整编号或可信实例的事项 URL 可以作为查询。
- Codex 工作台优先请求 Fullscreen，并提供展开入口；宿主不支持时保留内联视图，用户退出后不会自动再次展开。
- 双语文档集中说明 Codex、DSH、MCP 与 CLI 的入口、安装和更新步骤，帮助区分插件更新与实例升级。
- 修复 GitHub Actions 中中文 HTML 在输出分块边界被误解码而导致的集成测试失败。

## English

Compared with stable `1.9.2`, this RC improves opening and viewing issues in Codex and organizes Agent integration documentation for acceptance after updating a real host.

- When an issue identifier is explicitly supplied, the Codex conversation workbench loads its detail, description, and comments directly. Identity, permission, or project mismatches return explicit errors.
- Adds exact issue search and references for hosts supporting official Composer At-Mentions, using bounded lightweight reads. Queries accept a complete identifier or an issue URL from a trusted instance.
- The Codex workbench requests Fullscreen and offers an expand control. Hosts without support retain the inline view, and leaving Fullscreen does not trigger another automatic expansion.
- Bilingual documentation brings together Codex, DSH, MCP, and CLI entrypoints, installation, and update steps, distinguishing plugin updates from instance upgrades.
- Fixes an integration test failure in GitHub Actions caused by decoding Chinese HTML across output chunk boundaries.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.2` 升级无新增 migration，schema 保持 **19**、API 保持 **0.1.0**，仍需核对实际 ledger/schema。请明确选择 `1.9.3-rc.1`，默认 stable 仍为 `1.9.2`。本机 Skills/插件更新与实例升级分别执行；更新插件后关闭旧视图、重启 MCP/宿主，再打开新工作台。

Upgrading from `1.9.2` adds no migration: schema remains **19** and the API remains **0.1.0**. Verify the actual ledger/schema. Select `1.9.3-rc.1` explicitly; the default stable channel remains `1.9.2`. Update local Skills/plugins separately from the instance, then close old views, restart MCP/the host, and reopen the workbench.

事项详情直达与 Fullscreen 的源码和隔离测试已完成；真实 Codex 客户端展示仍待升级后验证。宿主决定内联、Fullscreen 或侧面板的呈现位置。At-Mentions 另要求宿主支持相关协议，且实例已升级到提供 `issue_reference` 能力的 Service；旧实例返回能力不支持，不进行全量搜索或静默降级。本 RC 发布不代表现有实例已升级。

Direct issue opening and Fullscreen have been verified in source and isolated tests; presentation in the real Codex client still awaits validation after updating. The host controls inline, Fullscreen, or side-panel placement. At-Mentions also requires host protocol support and an instance upgraded to a Service advertising `issue_reference`. Older instances return an unsupported-capability error without broad search or silent fallback. Publishing this RC does not upgrade existing instances.
