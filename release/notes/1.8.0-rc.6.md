# cfKanban 1.8.0-rc.6

## 简体中文

相对 `1.8.0-rc.5`，本 RC 让 Agent 能直接在 DeepSeek Harness 的侧栏打开指定项目或 Issue。

- 直接说“在 cfKanban 侧边栏打开 CFK-551”，即可打开并定位详情；已有工作台会复用，也支持返回指定项目。
- 通用技能优先使用宿主提供的工作台入口，明确要求浏览器或线上完整版时仍遵循用户选择，无需另外安装 DSH 专用技能。
- 只有当前会话的工作台实际显示目标页面后才报告打开成功；会话变化、身份不符或未完成的写入会阻止跳转并给出明确结果。

## English

Compared with `1.8.0-rc.5`, this RC lets Agents open a specific Project or Issue directly in the DeepSeek Harness sidebar.

- Ask “Open CFK-551 in the cfKanban sidebar” to show its details. Existing workbench tabs are reused, and Agents can also open a specific Project.
- The shared Skill prefers an available host workbench while respecting explicit requests for a browser or the full online app. No separate DSH Skill is needed.
- Opening is confirmed only after the current session displays the requested page. Session changes, identity mismatches, and pending writes stop navigation with an explicit result.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；升级仍须核对真实 ledger/schema。侧栏导航需要更新 DSH 插件，并在前台打开对应会话；后台或无界面的 Agent 不会控制其他会话的侧栏。更新技能后，在新会话核对实际加载版本。

No migration is added; schema remains 18 and API remains 0.1.0. Verify the actual ledger/schema during upgrade. Sidebar navigation requires the updated DSH plugin and the corresponding foreground session; background or headless Agents do not control another session’s sidebar. Verify the loaded Skill version in a new session after updating.
