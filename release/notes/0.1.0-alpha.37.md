# cfKanban 0.1.0-alpha.37

Testing prerelease / 测试发行版

## English

This testing prerelease fixes modern-browser validation for Workspace and Project keys found by the Owner Web lifecycle E2E.

Changes:

- escapes the literal hyphen in both key input patterns so HTML `pattern` remains valid under the Unicode Sets (`v`) regular-expression mode;
- restores native form validation without changing the canonical Workspace or Project key contract;
- adds a regression that compiles every first-party Web `pattern` attribute with the same `v` flag used by modern browsers;
- retains alpha.36's Owner admin Browser Session support for creating Workspaces and Projects;
- requires no API, schema, or D1 migration change.

Existing instances can upgrade by deploying the alpha.37 Service bundle without a D1 migration. Local Skill update and Instance upgrade remain independent.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.37
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行修复了 Owner Web 生命周期 E2E 在现代浏览器中发现的 Workspace 与 Project key 校验问题。

变更：

- 转义两个 key 输入 pattern 中的字面连字符，使 HTML `pattern` 在 Unicode Sets（`v`）正则模式下保持有效；
- 恢复浏览器原生表单校验，不改变 Workspace 或 Project key 的 canonical 合同；
- 新增回归，使用现代浏览器同款 `v` 标志编译第一方 Web 的每个 `pattern` 属性；
- 保留 alpha.36 对 Owner admin Browser Session 创建 Workspace 与 Project 的支持；
- 不改变 API、schema，也不需要 D1 migration。

现有实例可以直接部署 alpha.37 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是彼此独立的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.37
codex plugin add cfkanban-agent-skills@cfkanban
```
