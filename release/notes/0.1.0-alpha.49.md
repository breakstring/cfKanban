# cfKanban 0.1.0-alpha.49

## English

- Use compact Workspace/Project groups and consistent Archive/Restore actions; remove explanatory clutter and the ambiguous project search field.
- Add Owner-only permanent deletion of archived Projects and archived empty Workspaces, with an impact preview and exact-name confirmation. Purge is atomic and idempotent, clears related content, history and Project sessions, and preserves reserved keys and monotonically increasing Issue numbers.
- Add non-destructive schema migration `0002_container_purge.sql`. The migration does not purge existing data. Apply and verify it before deploying this Worker; older Workers do not understand purged records.
- Include the previous Skill improvements for trusted-instance selection and authenticated browser launch. Local Skill updates remain separate from Instance upgrades.

## 简体中文

- 工作区与项目采用紧凑父子分组，统一归档/恢复用语，移除重复说明和范围含糊的项目搜索框。
- 增加 Owner 专属的已归档项目、已归档空工作区永久删除：先预览影响，再准确名称确认。操作原子且幂等，清理相关内容、历史和项目会话，保留不可复用 key 与单调事项编号。
- 新增非破坏性迁移 `0002_container_purge.sql`，迁移本身不清理既有数据。部署新 Worker 前须完成迁移及读回；旧 Worker 不理解永久删除记录。
- 包含此前的可信实例选择与浏览器自动登录 Skill 优化。更新本地 Skill 与升级线上实例仍是两个独立动作。
