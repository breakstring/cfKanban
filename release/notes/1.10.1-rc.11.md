# cfKanban 1.10.1-rc.11

## 简体中文

相对 `1.10.1-rc.10`，本 RC 修正 Cloudflare 配置保存请求中被错误码 `10057` 拒绝的绑定保留方式。

- 保存用量及访问设置时，以现有绑定的原名称和类型保留未修改项。
- 保留静态资源、数据库、附件存储、Secret 与五组访问频率绑定，不读取或重新提交 Secret 值。
- 保存后的核验仍比较冻结版本与当前版本的完整绑定指纹；缺失、类型或资源值漂移继续保留待核验状态。
- 新增公开 `/llms.txt` 入口，集中链接双语使用手册和安装指南，便于 Agent 查阅网站能力与操作边界。

## English

Compared with `1.10.1-rc.10`, this RC corrects binding preservation in Cloudflare configuration requests rejected with error code `10057`.

- Usage and access settings retain unchanged bindings by their existing names and original types.
- Static assets, the database, attachment storage, Secrets, and all five rate-limit bindings are preserved without reading or resubmitting Secret values.
- Save verification still compares the complete binding fingerprints of the frozen and current versions. Missing bindings, type changes, or resource drift remain awaiting verification.
- A public `/llms.txt` entry links the bilingual manuals and installation guides so agents can discover the site's capabilities and operation boundaries.

## 升级与已知限制 / Upgrade and known limitations

相对 `1.10.1-rc.10` 无新增 migration，schema 保持 **27**，API 保持 **0.1.0**。沿用已有 Owner、凭据和 Observability 配置；本 RC 仍需在实例升级后执行真实配置保存验收。

No migration is added relative to `1.10.1-rc.10`: schema remains **27** and API remains **0.1.0**. Existing Owner identity, credentials, and Observability settings are retained. This RC still requires a real configuration-save check after the instance upgrade.
