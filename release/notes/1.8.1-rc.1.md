# cfKanban 1.8.1-rc.1

## 简体中文

相对 `1.8.0`，本 RC 修复 GitHub Actions 的验证中断，并更新持续集成环境。

- 修复 DSH 面板超时测试提前退出的问题，让在线打开、迟到响应及取消后的恢复检查能够完整执行。
- 将官方 GitHub Actions 与项目验证统一到 Node 24，使用固定版本验证发行。
- 固定 Ubuntu 24.04 验证环境，减少 runner 系统自动迁移对发行验证的影响。

## English

Compared with `1.8.0`, this RC fixes interrupted GitHub Actions validation and updates the continuous integration environment.

- Fix the DSH panel timeout test exiting early so online opening, late replies, and recovery after cancellation are checked fully.
- Align the official GitHub Actions and project validation on Node 24, using a pinned version for release checks.
- Pin validation to Ubuntu 24.04 to reduce changes caused by automatic runner OS migration.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；实例升级仍须核对真实 ledger/schema。本 RC 用于验证 CI 修复；实例部署和 Agent 宿主加载不属于本次 GitHub 发行验证。

No migration is added; schema remains 18 and API remains 0.1.0. Instance upgrades still require verification of the actual ledger/schema. This RC validates the CI fixes; instance deployment and Agent host loading are outside this GitHub release verification.

验证记录 / Verification record: [CFK-565](https://cfkanban.dev/app/issues/CFK-565).
