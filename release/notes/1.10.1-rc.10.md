# cfKanban 1.10.1-rc.10

## 简体中文

相对 `1.10.1-rc.9`，本 RC 为 Cloudflare 配置保存失败增加安全日志，帮助定位线上拒绝原因。

- 配置请求被 Cloudflare 拒绝时，Worker 日志记录操作类型、HTTP 状态和数字错误码。
- 日志只包含固定术语标签，不记录原始错误正文、请求、绑定值或凭据。
- 诊断读取限制为 64 KiB；正文解析失败或超时不改变已有失败与待核验判定。
- 实例升级完整保留 Dashboard 中的 Observability 配置，并在部署前后核验日志与追踪设置。

## English

Compared with `1.10.1-rc.9`, this RC adds safe diagnostics for failed Cloudflare configuration saves to identify production rejection causes.

- When Cloudflare rejects a configuration request, Worker logs record its operation, HTTP status, and numeric error codes.
- Logs contain only fixed diagnostic tags, excluding raw error bodies, requests, binding values, and credentials.
- Diagnostic reads are limited to 64 KiB. Parsing failures and timeouts preserve existing failed and awaiting-verification classifications.
- Instance upgrades preserve the complete Observability configuration from the Dashboard and verify logging and tracing settings before and after deployment.

## 升级与已知限制 / Upgrade and known limitations

相对 `1.10.1-rc.9` 无新增 migration，schema 保持 **27**，API 保持 **0.1.0**。本 RC 增加排障证据，配置保存的线上拒绝原因仍在排查，尚未确认修复。日志需要实例开启 Cloudflare Observability。

No migration is added relative to `1.10.1-rc.9`: schema remains **27** and API remains **0.1.0**. This RC provides diagnostic evidence; the production rejection of configuration saves is still under investigation and is not yet confirmed fixed. Logs require Cloudflare Observability to be enabled on the instance.
