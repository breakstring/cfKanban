# cfKanban 1.8.0

## 简体中文

相对 [1.7.0](https://github.com/breakstring/cfKanban/releases/tag/1.7.0)，本正式版新增本地 MCP、轻量工作台与 DeepSeek Harness 接入，让日常任务协作更自然地融入 Agent 和聊天侧栏。

- **直接让 Agent 处理任务**：通过本地 MCP 查询项目、创建和编辑任务、添加评论、关联事项及记录完成证据，沿用现有权限、并发和幂等保护；未覆盖的能力继续使用安全脚本。
- **随时打开轻量工作台**：在浏览器中切换项目、查看看板或列表，快捷修改状态、优先级和负责人，处理详情、评论与完成；任务仍来自同一线上实例，账户和管理功能使用线上完整版。
- **在 DSH 聊天旁查看任务**：一个插件提供四个 Skills、MCP 和可选侧栏。直接要求打开指定项目或 Issue 即可定位并复用工作台，只有当前会话实际显示目标后才报告成功。
- **一致的详情与复制体验**：本地工作台和线上完整版共用详情布局与常用控件，改善窄屏阅读；统一复制编号和链接的菜单，支持复制描述与评论的原始 Markdown，并保留失败后的草稿与恢复入口。
- **更顺畅的安装与上手**：统一引导 Skills 和受支持宿主的 MCP 配置，复用兼容安装；中英文指南按加入、协作和管理目标组织，说明何时使用 Agent、本地工作台或线上完整版。

## English

Compared with [1.7.0](https://github.com/breakstring/cfKanban/releases/tag/1.7.0), this stable release adds local MCP, a lightweight workbench, and DeepSeek Harness integration to bring everyday task collaboration into Agents and chat sidebars.

- **Let your Agent handle tasks**: Use local MCP to query projects, create and edit issues, add comments, relate issues, and record completion evidence, with existing authorization, concurrency, and idempotency protection. Secure scripts continue to cover remaining capabilities.
- **Open a lightweight workbench**: Switch projects, browse boards or lists, change status, priority, and assignee, and handle details, comments, and completion in your browser. Tasks come from the same online instance; account and administration features remain in the full online app.
- **View tasks beside DSH chat**: One plugin provides four Skills, MCP, and an optional sidebar. Ask to open a specific Project or Issue to navigate and reuse the workbench; success is reported only after the current session displays the target.
- **Consistent details and copying**: The local workbench and full online app share detail layouts and common controls for clearer reading on narrow screens. Copy Issue identifiers or links from one menu, copy original Markdown from descriptions and comments, and retain drafts and recovery after failures.
- **Simpler setup and onboarding**: One guided flow configures Skills and MCP on supported hosts while reusing compatible installations. Chinese and English guides follow joining, collaboration, and administration goals and explain when to use an Agent, the local workbench, or the full online app.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；升级仍须核对真实 ledger/schema。本地更新与实例升级独立；Git 插件与其使用的完整 Skill bundle 须为同一准确版本。更新后重启所属 MCP / 工作台，并在新会话核对 Skills 与 MCP 的实际加载版本。

DSH 兼容基线为 `0.2.0-rc.2`，Desktop 与 Web profile 需分别安装或更新。侧栏仅支持本机单用户 Host，导航要求对应会话处于前台。本地工作台仍需连接线上实例；浏览器标签复用依赖宿主的标签控制能力，普通系统打开器可能保留单独的检查标签。

No migration is added; schema remains 18 and API remains 0.1.0. Verify the actual ledger/schema during upgrade. Local updates and instance upgrades are independent; a Git plugin and the complete Skill bundle it uses must match the same exact release. Restart the owning MCP / workbench after updating and verify the loaded Skill and MCP versions in a new session.

The DSH compatibility baseline is `0.2.0-rc.2`; install or update Desktop and Web profiles separately. The sidebar supports a local single-user Host, and navigation requires the corresponding foreground session. The local workbench still needs the online instance. Browser tab reuse depends on host tab controls; an ordinary system opener may leave a separate connectivity-check tab.
