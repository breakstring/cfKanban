# cfKanban 0.1.0-alpha.38

Testing prerelease / 测试发行版

## English

This testing prerelease improves five-column Board navigation on narrow touch and keyboard viewports.

Changes:

- keeps horizontal overflow inside a named, focusable Board region instead of making the whole page the scroll surface;
- adds a concise localized cue that all five columns continue sideways and that each writable card has a non-drag status menu;
- adds proximity scroll snapping while preserving the fixed 248px practical column minimum;
- gives the mobile status menu a 44px touch target;
- records the interaction rule in the frozen visual design contract and adds a source regression for its focus, overflow, copy, and touch-target requirements;
- retains alpha.37's modern-browser key validation and alpha.36's Owner admin Browser Session support;
- requires no API, schema, or D1 migration change.

Existing instances can upgrade by deploying the alpha.38 Service bundle without a D1 migration. Local Skill update and Instance upgrade remain independent.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.38
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行改善了五列看板在窄屏触控与键盘视口里的导航体验。

变更：

- 把横向溢出收进有名称、可聚焦的看板区域，不再让整个页面承担横向滚动；
- 增加简短双语提示，明确五列还会向侧面延伸，并指出每张可写卡片都有无需拖拽的状态菜单；
- 在保持每列 248px 实用最小宽度的同时增加接近式滚动吸附；
- 把移动端状态菜单提高到 44px 触控目标；
- 将该交互规则写入冻结视觉设计合同，并补充针对焦点、溢出、文案与触控目标的源码回归；
- 保留 alpha.37 的现代浏览器 key 校验修复和 alpha.36 的 Owner admin Browser Session 支持；
- 不改变 API、schema，也不需要 D1 migration。

现有实例可以直接部署 alpha.38 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是彼此独立的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.38
codex plugin add cfkanban-agent-skills@cfkanban
```
