# cfKanban 1.12.0-rc.2

## 简体中文

相对 `1.12.0-rc.1`，本 RC 统一项目视图布局，并让事项详情中的里程碑归属调整更方便。

- 看板和列表将状态与其他筛选集中在右侧，左侧保留看板、列表和里程碑切换。
- 里程碑页面采用全宽项目布局，统一标题和工具栏，列表操作在窄屏下自然换行。
- 事项详情右侧可直接加入、更换或退出里程碑，选择后即时保存，无需打开编辑表单。
- 快捷修改保留未保存的正文和独立归属草稿；保存未确认或发生冲突时，可以安全核实原操作。

## English

Compared with `1.12.0-rc.1`, this RC unifies Project view layouts and makes milestone membership easier to change in Issue details.

- Boards and lists group status with the other filters on the right, while Board, List and Milestones stay on the left.
- Milestones use the full-width Project layout with consistent headings and toolbars; row actions wrap on narrow screens.
- Issue properties directly support joining, changing or leaving a milestone, with immediate saving and no need to open the edit form.
- Quick changes retain unsaved descriptions and independent membership drafts. Unconfirmed saves and conflicts can be verified safely.

## 升级与已知限制 / Upgrade and known limitations

相对 `1.12.0-rc.1` 无新增 migration，API 保持 **0.1.0**、schema 保持 **28**；升级仍须核对实际 ledger/schema。里程碑选择器的真实浏览器视觉、键盘和焦点验收仍需在线完成。本地验证及实现证据见 [CFK-717](https://cfkanban.dev/app/issues/CFK-717)。

There are no new migrations relative to `1.12.0-rc.1`; API remains **0.1.0** and schema remains **28**. Verify the actual ledger/schema before upgrading. Live browser validation of the milestone picker's appearance, keyboard and focus behavior is still pending. Local validation and implementation evidence are recorded in [CFK-717](https://cfkanban.dev/app/issues/CFK-717).
