# cfKanban 1.10.0

## 简体中文

相对正式版 `1.9.4`，本版汇集 1.10 系列 RC 的项目搜索、Owner 版本管理和升级公告改进，让查找事项与交给 Agent 更新更直接。

- 项目搜索可按标题或编号快捷匹配最多十个已加载事项；按 Enter 搜索整个当前项目，支持编号前缀，输入时不发送请求。
- Owner「版本与更新」显示当前实例、最新正式版及最多三份近期预发行，按发布时间倒序展示并链接官方发行说明。
- Owner 可复制一句升级请求给 Agent：先指定目标版本，再将本地插件与当前站点部署都升级到该版本；默认最新正式版，预发行须明确选择。
- Owner 可开启升级成功后的双语公告，默认关闭；正式版及 RC 向前升级并读回确认后，每个发行最多公告一次，并提供更新本地插件和技能到准确版本的可复制请求。
- 项目公开加入状态以名称旁的紧凑图标展示，保留开启、关闭及未知状态的双语悬停和键盘说明。

## English

Compared with stable `1.9.4`, this release brings together the 1.10 RC improvements to Project search, Owner version management and upgrade announcements, making Issue lookup and Agent update requests more direct.

- Project search matches titles or numbers from up to ten loaded Issues. Press Enter to search the entire current Project, including number prefixes, without requests while typing.
- Owners gain **Versions & updates**, showing the current Instance, latest stable release and up to three recent prereleases, ordered newest first and linked to official release notes.
- Owners can copy one upgrade request to their Agent, naming the target first and requesting that both the local plugin and current site's deployment use that version. Stable is the default; prereleases require an explicit choice.
- Owners can enable bilingual announcements after verified forward stable or RC upgrades. Disabled by default, they announce each release at most once and include a copyable request to update the local plugin and Skills to the exact version.
- Compact Public Join icons appear beside Project names, retaining bilingual hover and keyboard descriptions for enabled, disabled and unknown states.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.4` 升级新增 `0021_instance_upgrade_notifications.sql`，schema 从 **20** 升至 **21**，API 保持 **0.1.0**；迁移为向后兼容的新增结构，仍须核验实际 ledger/schema 和恢复点。从已验收的 `1.10.0-rc.7` 升级无新增 migration，本次正式化仅收敛版本和发行说明。

快捷匹配仅覆盖已加载事项，完整项目搜索需明确提交。自动升级公告默认关闭，既有公告正文不改写；本地更新和实例升级仍分别执行。本次发布正式渠道，不自动更新线上实例或本地插件/技能。

Upgrading from `1.9.4` adds `0021_instance_upgrade_notifications.sql`, moving schema **20 → 21** while retaining API **0.1.0**. The migration is a backward-compatible addition; verify the actual ledger/schema and restore point. Upgrading from validated `1.10.0-rc.7` adds no migrations; this stable promotion changes only version metadata and release notes.

Shortcuts cover loaded Issues only; full Project search requires submission. Automatic upgrade announcements start disabled and leave existing notice bodies unchanged. Local updates and Instance upgrades remain separate operations. Publishing this stable channel does not update the online Instance or local plugin/Skills automatically.
