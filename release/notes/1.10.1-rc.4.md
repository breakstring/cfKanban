# cfKanban 1.10.1-rc.4

## 简体中文

相对已公开的 `1.10.1-rc.3`，本 RC 将 Cloudflare 连接 Token 的权限指引整理为明确的必需与可选列表。

- 逐项查看权限范围、Cloudflare 选择路径和用途，按指引为同一个 Token 添加所需权限。
- 显示当前 Worker、目标账户和域名的限定范围，明确 Editor 包含代码及部署权，可选读取无需 Edit。
- 中英文页面与公开指南保持一致，手机窄屏下也能清楚阅读完整权限列表。

## English

Compared with published `1.10.1-rc.3`, this RC organizes Cloudflare connection Token guidance into clear required and optional permission lists.

- Check each permission's scope, Cloudflare selection path and purpose, then add the needed permissions to one Token.
- See the current Worker, target account and domain scope, with Editor's code and deployment authority disclosed and no Edit required for optional reads.
- Follow consistent English and Simplified Chinese guidance in the application and public documentation, with readable permission lists on narrow mobile screens.

## 升级与已知限制 / Upgrade and known limitations

从 `1.10.1-rc.3` 升级无新增 migration，schema 保持 **26**，API 保持 **0.1.0**；仍须核对实际 ledger/schema 和线上配置。此更新只改进权限说明，Owner 仍需自行创建并输入 Token；可选读取能力以实际权限及供应商兼容性核验为准。

Upgrading from `1.10.1-rc.3` adds no migrations and keeps schema **26** and API **0.1.0**; the actual ledger/schema and live configuration must still be checked. This update improves permission guidance only. Owners still create and enter their Token, and optional reads depend on verified permissions and provider compatibility.
