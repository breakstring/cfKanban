# cfKanban 0.1.0-alpha.59

## English

This testing release preserves alpha.58 usage statistics, Owner-selected attachment capacity, and migration recovery, and adds bounded diagnostics for failed Cloudflare analytics collection.

- Failed upstream calls emit only fixed diagnostic fields: dataset, HTTP status, numeric provider codes, and an allowlisted transport exception category. Tokens, headers, query variables, raw response bodies, and exception messages are never logged.
- Error responses use bounded reads; malformed or oversized bodies do not replace the original HTTP failure classification.
- Public usage responses, shared cache/cooldown, Owner authorization, and attachment policies are unchanged. No new telemetry service or background polling is enabled.
- Schema remains 7. The alpha.57 migration-readback recovery fix is included; no additional migration is required after schema 7.

This remains a prerelease. Cloudflare metrics still require a separately authorized read-only Analytics Token; deployment never chooses an attachment capacity limit.

## 简体中文

本测试发行保留 alpha.58 的用量统计、自主附件容量与迁移恢复能力，为 Cloudflare 采集失败增加有界且脱敏的诊断。

- 失败只记录固定字段：数据集、HTTP 状态、数字供应商错误码及白名单内的传输异常类型；不记录 Token、请求头、查询变量、原始响应正文或异常消息。
- 错误响应有读取大小上限，异常或超大正文不覆盖原始 HTTP 失败分类。
- 公共 API、共享缓存与冷却、Owner 权限及附件策略保持不变；不启用新的遥测服务或后台轮询。
- schema 仍为 7，包含 alpha.57 迁移读回恢复修复；已处于 schema 7 的实例没有新增 migration。

此版本仍为 prerelease。真实统计仍需单独授权的只读 Analytics Token，部署不代选附件容量。
