# cfKanban 1.9.3-rc.5

## 简体中文

相对 `1.9.3-rc.4`，本 RC 用四张真实客户端截图完善 Codex App 和 DeepSeek Harness 的双语接入指南。

- Codex App 页面展示全屏看板、会话旁详情和搜索候选，按使用场景说明如何打开工作台与引用事项。
- DeepSeek Harness 页面加入插件侧栏截图，集中说明安装、打开事项和切换项目。
- 配图带中英文说明与替代文字，可打开原图查看细节；网页和公开 Markdown 的图片链接均随 Service 工件发布。

## English

Compared with `1.9.3-rc.4`, this RC improves the bilingual Codex App and DeepSeek Harness integration guides with four real-client screenshots.

- The Codex App guide shows the fullscreen board, conversation-side details, and search candidates, explaining workbench opening and Issue references by use case.
- The DeepSeek Harness guide adds a plugin-sidebar screenshot and focuses on installation, opening Issues, and switching Projects.
- Images include localized captions and alternative text, with links to full-size views; both HTML and public Markdown image paths ship in the Service artifact.

## 升级与已知限制 / Upgrade and known limitations

相对 RC4 无新增 migration，schema 保持 **20**，API 保持 **0.1.0**；升级 Service 前仍须核对真实 ledger/schema。部署本版 Service 后可直接查看新的线上文档，无需为阅读指南更新本地插件。截图展示用户提供的中文客户端布局，实际入口和布局可能随宿主版本不同。

There are no new migrations relative to RC4; schema remains **20** and API remains **0.1.0**. Service upgrades still require actual ledger/schema checks. Deploy this Service version to publish the updated online guides; reading them does not require a local plugin update. The supplied screenshots show Chinese client layouts; available entries and layouts can vary by host version.
