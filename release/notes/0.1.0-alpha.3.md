# cfKanban 0.1.0-alpha.3

Testing prerelease / 测试发行版

## English

This testing prerelease keeps the Node.js 26 support introduced in `0.1.0-alpha.2` and corrects the canonical first-install workflow discovered during a clean deployment rehearsal.

Changes:

- requires the verified Skill bundle to be installed under `~/.cfkanban/skill-releases/` before a canonical first deployment;
- treats a Codex marketplace/plugin cache only as a host discovery projection, never as a substitute for the canonical installation;
- presents the canonical Skill installation and isolated Wrangler Tool Runtime plans together when both are needed;
- runs the bundled help command from the installed canonical path and reads back the active Skill receipt before Cloudflare account checks;
- continues to accept Node.js `>=22.12.0 <27` and pins Wrangler to `4.127.1`.

Important limits:

- this is not the stable channel and must be selected explicitly;
- use a non-production Cloudflare account and review the exact plans before approving local or cloud writes;
- resource cleanup is separate and is never performed automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.3
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这个测试发行版保留 `0.1.0-alpha.2` 引入的 Node.js 26 支持，并修正了在干净环境部署演练中发现的 canonical 首次安装流程缺陷。

变更：

- canonical 首次部署前，必须把已验证的 Skill bundle 安装到 `~/.cfkanban/skill-releases/`；
- Codex marketplace/plugin cache 只作为宿主发现投影，绝不能替代 canonical 安装；
- canonical Skill 与隔离 Wrangler Tool Runtime 都缺失时，会一起展示两份安装计划；
- Cloudflare 账户检查前，从 canonical installed path 运行 bundled help，并读回 active Skill receipt；
- 继续接受 Node.js `>=22.12.0 <27`，Wrangler 固定为 `4.127.1`。

重要限制：

- 这不是稳定发行通道，必须由用户明确选择；
- 请使用非生产 Cloudflare 账户，并在授权本地或云端写入前核对准确计划；
- 资源清理是独立操作，绝不会自动执行。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.3
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-deploy 为我部署一套 cfKanban。
```
