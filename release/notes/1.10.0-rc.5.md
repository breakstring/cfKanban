# cfKanban 1.10.0-rc.5

## 简体中文

相对已公开的 `1.10.0-rc.4`，本 RC 简化 Owner 交给 Agent 的升级请求。

- 升级提示压缩为一句话：使用 `cfkanban-deploy` 技能先更新本地 cfKanban 插件，再升级此站点的线上部署；技能仍落实各自的更新与授权流程。
- 默认目标为最新正式版，另可明确选择已发现的准确预发行版本，不自动选择 RC。
- 复制区更紧凑，便于查看并复制请求；复制只生成文本，不执行更新。

## English

Compared with published `1.10.0-rc.4`, this RC simplifies the Owner's upgrade request to their Agent.

- A single sentence asks the `cfkanban-deploy` skill to update the local cfKanban plugin first, then upgrade this site's online deployment. The skill retains each update and authorization workflow.
- The target defaults to the latest stable release, with discovered prereleases available by exact version; RCs are never selected automatically.
- A compact prompt area makes the request easier to review and copy. Copying produces text without applying either update.

## 升级与已知限制 / Upgrade and known limitations

从 RC.4 升级无新增 migration，schema 保持 **21**，API 保持 **0.1.0**；仍需核对实际 ledger/schema。所选版本仅指定线上部署目标，本地插件更新目标由技能处理。提示中的站点地址取自浏览器当前 origin，不进行 IP 或 DNS 探测。

Upgrading from RC.4 adds no migrations and keeps schema **21** and API **0.1.0**; verify the actual ledger/schema. The selected version specifies the deployment target; the skill handles the local plugin update target. The site address in the prompt comes from the browser's current origin, without IP or DNS probing.
