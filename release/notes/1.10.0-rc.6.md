# cfKanban 1.10.0-rc.6

## 简体中文

相对已公开的 `1.10.0-rc.5`，本 RC 将 Owner「版本与更新」中的近期预发行列表缩短至最多三份，继续按发行发布时间倒序展示最新条目。

- 近期预发行列表最多三条，便于快速查看最新版本。
- Web、公共 CLI 和 Agent 查询使用同一个三条上限。
- 给 Agent 的升级提示下拉菜单也只提供这些准确预发行目标。

## English

Compared with published `1.10.0-rc.5`, this RC limits recent prereleases in the Owner's **Versions & updates** page to three entries, retaining newest-first publication order.

- Recent prereleases show at most three entries for a shorter view of the newest releases.
- Web, public CLI, and Agent queries share the same three-entry limit.
- The Agent upgrade prompt's selector offers those exact prerelease targets.

## 升级与验收 / Upgrade and verification

从 RC.5 升级无新增 migration，schema 保持 **21**，API 保持 **0.1.0**；仍需核对实际 ledger/schema。本次仅发布 GitHub RC，供用户手动升级并验收升级通知，不自动部署实例或更新本地插件/技能。

Upgrading from RC.5 adds no migrations and keeps schema **21** and API **0.1.0**; verify the actual ledger/schema. This release only publishes the RC on GitHub for the user to upgrade manually and verify upgrade notifications. It does not automatically deploy an instance or update the local plugin/Skills.
