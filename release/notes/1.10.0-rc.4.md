# cfKanban 1.10.0-rc.4

## 简体中文

相对已公开的 `1.10.0-rc.2`，本 RC 优化版本管理和搜索布局，并改用 GitHub 公开网页发现发行。

- 版本发现无需 GitHub token、不请求 REST API：正式版读取官方 Latest 跳转，预发行按 GitHub 原生标记识别并按发布时间排序，避开匿名 REST API 配额。
- Owner 版本页面增加导航、分隔线和按钮周围的留白，说明文字更易阅读。
- 本地技能与实例升级说明合并为“交给 Agent 升级”，提供可复制的简短双语提示和准确目标选择；两项操作仍分别确认计划。
- 项目搜索框恢复自然的左对齐和内边距，保留快捷匹配及 Enter 搜索行为。

## English

Compared with published `1.10.0-rc.2`, this RC improves version management and search layout, and discovers releases from public GitHub pages.

- Release discovery needs no GitHub token or REST API request: stable follows the official Latest redirect, while prereleases use GitHub's native badge and publication order, avoiding anonymous REST API quotas.
- More space around navigation, separators and actions makes the Owner version page easier to read.
- Local Skill and Instance upgrade guidance is combined under “Ask your Agent to upgrade”, with short bilingual prompts and an exact target choice. Each operation still confirms its own plan.
- Project search restores natural left alignment and padding while preserving quick matches and Enter search.

## 升级与已知限制 / Upgrade and known limitations

从 RC.2 升级无新增 migration，schema 保持 **21**，API 保持 **0.1.0**；仍需核对实际 ledger/schema。发行列表只读第一页，最多检查二十项并展示五份预发行。发布时间不证明升级方向或兼容性。网页也可能访问受限或改变结构，此时保留旧信息或明确查询失败。

Upgrading from RC.2 adds no migrations and keeps schema **21** and API **0.1.0**; verify the actual ledger/schema. Discovery reads only the first releases page, inspecting at most twenty entries and showing five prereleases. Publication time does not establish upgrade direction or compatibility. Webpage access limits or structure changes retain expired information or report a failed check.

本次只发布 GitHub 工件；`cfkanban.dev` 保留 RC.2，尚未使用新网页查询，本机技能未更新。RC.3 仅保留已推送的准备 tag，未创建 GitHub Release，其布局改进已包含在 RC.4。

This release publishes GitHub artifacts only. `cfkanban.dev` stays on RC.2 and still uses the earlier discovery method; local Skills are not updated. RC.3 remains a pushed preparation tag without a GitHub Release, and its layout improvements are included in RC.4.
