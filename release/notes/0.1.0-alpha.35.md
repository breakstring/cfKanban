# cfKanban 0.1.0-alpha.35

Testing prerelease / 测试发行版

## English

This testing prerelease gives cfKanban a compact visual identity without adding a third-party runtime dependency.

Changes:

- adds an original transparent mark: a vivid-orange task card moving out of a warm-ink Kanban board;
- uses the same mark for the browser favicon, Apple touch icon, public wordmark, authenticated header, and footer;
- keeps the adjacent `cfKanban` wordmark as live text and marks repeated images as decorative for assistive technology;
- fingerprints the local PNG with the existing Static Assets build and keeps the strict CSP/no-third-party-resource contract;
- retains alpha.34's `no-transform` protection against Cloudflare RUM injection.

Existing instances can upgrade by deploying the alpha.35 Service bundle without a D1 migration. Local Skill update and Instance upgrade remain independent.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.35
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行给 cfKanban 补上一套小而完整的视觉身份，不增加任何第三方运行时依赖。

变更：

- 新增原创透明标志：一张明快橙色任务卡从 warm-ink 看板里自己冲出去；
- 浏览器 favicon、Apple touch icon、公开首页 wordmark、已认证 header 与页脚复用同一标志；
- 邻接的 `cfKanban` 仍是实时文字，重复图形对辅助技术标记为装饰；
- 本地 PNG 进入既有 Static Assets 指纹构建，继续保持严格 CSP 与“不加载第三方资源”合同；
- 保留 alpha.34 阻止 Cloudflare RUM 注入的 `no-transform` 防护。

现有实例可以直接部署 alpha.35 Service bundle，不需要 D1 migration。本地 Skill update 与 Instance upgrade 仍是彼此独立的两个平面。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.35
codex plugin add cfkanban-agent-skills@cfkanban
```
