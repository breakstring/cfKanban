# cfKanban 1.9.4-rc.2

## 简体中文

相对 `1.9.4-rc.1`，本 RC 改善文档页头与站点页脚的链接呈现，让常用入口更清楚、更容易辨认。

- 文档页头的 GitHub 图标旁显示文字，与“返回站点”保持清晰间距；窄屏导航菜单也提供这两个入口。
- 首页和登录后的页脚为 GitHub、文档链接加入一致的图标，保留当前语言的文档入口和新标签页提示。
- 首页页脚移除“API 合同”链接，聚焦日常使用的文档与源码入口。

## English

Compared with `1.9.4-rc.1`, this RC improves links in the documentation header and site footers, making common destinations easier to recognize.

- The documentation header shows GitHub text beside its icon, with clear spacing from “Back to site”; both links are also available in the narrow-screen navigation menu.
- Homepage and signed-in footers add consistent icons to GitHub and documentation links, preserving the current documentation language and new-tab cues.
- Removes the “API contract” link from the homepage footer to focus on everyday documentation and source-code access.

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.4-rc.1` 升级无新增 migration，schema 保持 **20**，API 保持 **0.1.0**，仍需核对实际 ledger/schema。新版界面随 Service 升级提供；发布 RC 不会自动升级已部署实例或本地技能。“API 合同”入口的移除不影响现有 API 与 OpenAPI 端点。

Upgrading from `1.9.4-rc.1` adds no migration, retaining schema **20** and API **0.1.0**; verify the actual ledger/schema. Updated pages ship with a Service upgrade; publishing this RC does not automatically upgrade deployed instances or local Skills. Removing the “API contract” link leaves the API and OpenAPI endpoints available.
