# cfKanban 0.1.0-alpha.1

Testing prerelease / 测试发行版

## English

This is cfKanban's first public testing prerelease. It exists so maintainers and early testers can verify installation, immutable bundle checks, and a real Cloudflare test deployment from another machine.

Included:

- the complete Codex plugin with `cfkanban`, `cfkanban-admin`, and `cfkanban-deploy`;
- one immutable Skill bundle and one immutable Service deployment bundle;
- a prerelease pointer and manifest with SHA-256 digests;
- the Worker, D1 migrations, OpenAPI contract, and bundled bilingual Web assets.

Important limits:

- this is not the stable channel and must be selected explicitly;
- it has not completed final multi-environment deployment acceptance;
- use a non-production Cloudflare account and review the exact plan before approving real cloud writes;
- resource cleanup is separate and is never performed automatically.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.1
codex plugin add cfkanban-agent-skills@cfkanban
```

Start a new Codex task and say:

```text
Use $cfkanban-deploy to deploy cfKanban for me.
```

## 简体中文

这是 cfKanban 的第一个公开测试发行版，用于让维护者和早期测试者从另一台机器验证 Skill 安装、不可变 bundle 校验和真实 Cloudflare 测试部署。

包含内容：

- 完整 Codex plugin，包含 `cfkanban`、`cfkanban-admin` 与 `cfkanban-deploy`；
- 一个不可变 Skill bundle 和一个不可变 Service deployment bundle；
- 带 SHA-256 digest 的 prerelease pointer 与 manifest；
- Worker、D1 migrations、OpenAPI 合同和内置中英双语 Web assets。

重要限制：

- 这不是稳定发行通道，必须由用户明确选择；
- 尚未完成最终的多环境部署验收；
- 请使用非生产 Cloudflare 账户，并在授权真实云端写入前核对准确计划；
- 资源清理是独立操作，绝不会自动执行。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.1
codex plugin add cfkanban-agent-skills@cfkanban
```

新建 Codex 任务后只需要说：

```text
请使用 $cfkanban-deploy 为我部署一套 cfKanban。
```
