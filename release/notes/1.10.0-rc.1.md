# cfKanban 1.10.0-rc.1

## 简体中文

相对正式版 `1.9.4`，本 RC 改善项目搜索，并让 Owner 更容易检查和管理版本更新。

- 输入标题或编号即可看到已加载事项的快捷匹配；Enter 明确搜索当前项目，支持编号前缀，输入阶段不增加网络请求（[CFK-624](https://cfkanban.dev/app/issues/CFK-624)）。
- Owner 管理中心新增版本与更新入口，展示当前实例版本、最新正式版和近期预发行，并分别提供本地技能与实例升级指引（[CFK-619](https://cfkanban.dev/app/issues/CFK-619)）。
- Owner 可开启升级成功后的双语版本公告；默认关闭，仅正式版及 RC 向前升级并成功读回后通知，支持去重和失败恢复（[CFK-620](https://cfkanban.dev/app/issues/CFK-620)）。
- 项目公开加入状态改为名称同行的紧凑图标，保留中英文悬停和键盘状态说明（[CFK-625](https://cfkanban.dev/app/issues/CFK-625)）。

## English

Compared with stable `1.9.4`, this RC improves Project search and helps Owners check and manage version updates.

- Typing a title or number shows quick matches from loaded Issues. Enter explicitly searches the current Project, including number prefixes, without adding network requests while typing ([CFK-624](https://cfkanban.dev/app/issues/CFK-624)).
- Owner administration adds Versions & updates, showing the current Instance version, latest stable release and recent prereleases, with separate guidance for local Skills and Instance upgrades ([CFK-619](https://cfkanban.dev/app/issues/CFK-619)).
- Owners can enable bilingual upgrade announcements. The setting defaults to off and only announces verified forward stable or RC upgrades, with deduplication and failure recovery ([CFK-620](https://cfkanban.dev/app/issues/CFK-620)).
- Compact Public Join icons sit beside Project names, retaining English / Simplified Chinese hover and keyboard descriptions ([CFK-625](https://cfkanban.dev/app/issues/CFK-625)).

## 升级与已知限制 / Upgrade and known limitations

从 `1.9.4` 升级需执行新增 `0021_instance_upgrade_notifications.sql`，schema **20 → 21**，API 保持 **0.1.0**。迁移向后兼容，新增通知开关默认关闭；仍须验证实际 ledger/schema 和恢复点。本地技能与实例升级独立。旧 `q` 查询保持兼容，新搜索使用可选 `q_mode=typed`。

Upgrading from `1.9.4` requires the new `0021_instance_upgrade_notifications.sql`, moving schema **20 → 21** while retaining API **0.1.0**. The migration is backward compatible and the new notification setting defaults to off; verify the actual ledger/schema and restore point. Local Skill updates remain independent of Instance upgrades. Legacy `q` queries stay compatible; the new search uses optional `q_mode=typed`.

本地隔离测试与桌面/移动浏览器验收已完成；原生操作系统 IME、真实辅助技术播报及线上 D1 计费性能未实测。[发行、部署及本机更新证据](https://cfkanban.dev/app/issues/CFK-626)。

Isolated tests and desktop/mobile browser checks are complete. Native OS IME, real assistive-technology announcements and live D1 billing performance have not been measured. [Release, deployment and local-update evidence](https://cfkanban.dev/app/issues/CFK-626).
