# cfKanban 1.10.0-rc.3

## 简体中文

相对 `1.10.0-rc.2`，本 RC 优化 Owner 版本管理页面和项目搜索框的布局。

- 版本页面的导航、内容分隔线和操作按钮周围增加留白，说明文字更易阅读。
- 本地技能与实例升级说明合并为“交给 Agent 升级”，Owner 可以直接复制双语提示，并选择准确发行版本；两项操作仍各自展示计划并等待确认。
- 项目搜索框恢复自然的左对齐和内边距，保留快捷匹配及 Enter 搜索行为。

## English

Compared with `1.10.0-rc.2`, this RC improves the layout of Owner version management and Project search.

- More space around navigation, separators and actions makes the version page easier to read.
- Local Skill and Instance upgrade guidance is combined under “Ask your Agent to upgrade”. Owners can copy bilingual prompts and choose an exact release; each operation still presents its own plan for confirmation.
- Project search restores natural left alignment and padding while preserving quick matches and Enter search.

## 升级与已知限制 / Upgrade and known limitations

从 RC.2 升级无新增 migration，schema 保持 **21**，API 保持 **0.1.0**。仍需核对实际 ledger/schema。GitHub 匿名 API 限流可能暂时阻止版本列表刷新；本 RC 未改变查询来源或加入凭据。此发行仅发布 GitHub 工件，`cfkanban.dev` 保留 RC.2，供检查版本发现；本机技能未更新。

Upgrading from RC.2 adds no migrations and keeps schema **21** and API **0.1.0**. Verify the actual ledger/schema. GitHub anonymous API rate limits may temporarily prevent release-list refreshes; this RC does not change the query source or add credentials. This release publishes GitHub artifacts only, leaving `cfkanban.dev` on RC.2 for update-discovery checks. Local Skills are not updated.

Full source validation and isolated English / Simplified Chinese desktop/mobile checks cover layout, release selection and copying. These results do not mean the new interface is deployed online.
