# cfKanban 1.8.0-rc.5

## 简体中文

相对 `1.8.0-rc.4`，本 RC 统一本地工作台与线上完整版的 Issue 详情体验，让窄屏查看和日常操作更顺畅。

- 两端共用以完整版为基线的标题、正文、属性栏和评论组件，统一字体、间距和窄屏布局。
- 本地详情可直接调整状态、优先级和负责人；完成事项使用确认弹窗，保留失败后的草稿与恢复入口。
- 将复制编号和复制链接合并为一个菜单；描述与评论保留 Markdown 复制，评论操作统一右对齐。
- 浏览器具备标签页控制能力时，引导 Agent 在已验证的探测标签页中打开工作台，减少额外标签页。

## English

Compared with `1.8.0-rc.4`, this RC aligns Issue details in the local workbench with the full online app for clearer reading and smoother everyday actions on narrow screens.

- Share title, content, property, and comment components based on the full app, with consistent typography, spacing, and responsive layouts.
- Change status, priority, and assignee directly in local Issue details; completion uses a confirmation dialog and preserves drafts and recovery after failures.
- Combine copying the Issue ID and link in one menu; retain Markdown copying for descriptions and comments, with comment actions aligned to the right.
- Guide Agents with browser tab controls to open the workbench in the verified probe tab, reducing extra tabs.

## 升级与已知限制 / Upgrade and known limitations

无新增 migration，schema 保持 18、API 保持 0.1.0；升级仍须核对真实 ledger/schema。标签页复用依赖宿主提供标签页控制能力，普通系统浏览器打开器仍可能产生额外标签页；本轮未完成 DSH 单标签页实机验收。更新本机技能后，在新会话核对加载版本。

No migration is added; schema remains 18 and API remains 0.1.0. Verify the actual ledger/schema during upgrade. Tab reuse requires host tab controls; ordinary system browser openers may still create an extra tab. Single-tab behavior in DSH has not been verified in this iteration. Verify the updated Skill version in a new session.
