# cfKanban 1.4.0-rc.2

## 简体中文

- OpenAPI `info.version` 自动跟随产品发行；独立的 `contracts/service-api.json` 与 `x-cfkanban-service-version` 继续表达 API 兼容版本，避免初始化时将产品版本写入数据库。
- 已登录网页共用简洁页脚，提供当前语言的站内文档、GitHub 与产品版本。文档在新标签页打开，保留当前工作页和会话范围；显示版本不增加 API 请求。
- Howto 可按问题读取同实例双语文档、引用实际来源并核对 Service 发行版本；缺页、缺译文、网络失败或版本不匹配时明确回退，讲解不触发业务操作或升级。

新发行清单使用 manifest schema 2，pointer 仍为 schema 1。先更新到支持此格式的 Skills 及宿主插件，再处理新的 Service 工件；旧技能正常发现/校验时会拒绝该清单，不得绕过验证。新部署技能继续兼容历史 manifest 和 Service bundle。API 仍为 `0.1.0`、schema 仍为 `13`，本次版本元数据调整不需要新的 D1 migration。

本地完整验收通过 663 项测试，并完成 15 项桌面/移动端网页检查及 Howto 文档引用验证。具体证据记录于 CFK-504、CFK-505、CFK-506；这些本地检查不代表线上部署或新会话插件加载。此 RC 不推进 GitHub Latest。

## English

- OpenAPI `info.version` follows the product release. The independent `contracts/service-api.json` declaration and `x-cfkanban-service-version` retain API compatibility semantics, preventing product versions from entering the database's API version field during bootstrap.
- Signed-in pages share a compact footer with localized instance documentation, GitHub, and the product version. Documentation opens in a new tab, preserving the working page and session scope; displaying the version adds no API requests.
- Howto can read relevant bilingual documentation from the selected instance, cite sources, and check the Service release. Missing pages or translations, network failures, and version mismatches produce an explicit fallback; teaching triggers no business operations or upgrades.

New release manifests use schema 2; pointers remain schema 1. Update to compatible Skills and host plugins before operating on new Service artifacts. Older Skills reject the new manifest during normal discovery/verification; do not bypass that check. The new deployment Skills still support historical manifests and Service bundles. API remains `0.1.0` and schema remains `13`; this version metadata change requires no additional D1 migration.

Local validation passed 663 tests, 15 desktop/mobile browser checks, and Howto documentation citation checks. Evidence is recorded in CFK-504, CFK-505, and CFK-506; these local checks do not establish deployment or plugin loading in a fresh conversation. This RC does not advance GitHub Latest.
