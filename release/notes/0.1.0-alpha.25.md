# cfKanban 0.1.0-alpha.25

Testing prerelease / 测试发行版

## English

This testing prerelease unifies error recovery across the Agent Skill and Web surfaces, and gives the public home page a lighter Agent-first voice.

Changes:

- changes the public promise to “Let Agents do the work. Skip the guesswork.” and explains that Agents advance work while people can understand or take over from the shared board;
- accepts a Service error in the Skill transport only when its complete envelope, HTTP status, request ID, source, retry flag, and Retry-After semantics agree;
- gives the Skill and Web transports one regression-locked decision matrix for Cloudflare 1027, outer 429, unverified JSON/HTML failures, and network failures;
- emits a fresh local correlation ID for client-normalized failures, retains a Cloudflare Ray ID separately, and explicitly marks them as non-API responses;
- shows a concise localized recovery action first in the Web UI, with stable code/category/source/recovery/retry/request facts available in an expandable diagnostic section;
- carries verified Session and Grant failures into the corresponding page recovery events so their request evidence is not discarded;
- documents actionable Agent recovery for version conflicts, Project quota, rate limits, platform quota/failure, authentication, and authorization;
- verifies a live `VERSION_CONFLICT` readback and rendered English/Simplified Chinese error state without relying on server or provider prose.

The REST API and D1 schema are unchanged from alpha.24. Both bundles change: the Skill runtime and guidance change, and the Web UI plus compiled Static Assets change.

Install the tagged plugin:

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.25
codex plugin add cfkanban-agent-skills@cfkanban
```

## 简体中文

这次测试发行统一了 Agent Skill 与 Web 的错误恢复行为，也让公开首页的 Agent-first 表达轻松了一点。

变更：

- 首页口号改为“活儿让 Agent 干，进度不用猜。”，并说明 Agent 负责推进，人可以从共享看板随时看懂或接手；
- Skill transport 只有在完整错误 envelope、HTTP 状态、请求 ID、来源、重试标志与 Retry-After 语义全部一致时，才信任 Service 错误；
- Skill 与 Web transport 使用同一套受回归测试约束的 Cloudflare 1027、外层 429、不可验证 JSON/HTML 与网络失败决策矩阵；
- 客户端归一化错误生成新的本地关联 ID，另行保留 Cloudflare Ray ID，并明确标注它不是 API 响应；
- Web 先显示简短、本地化、可执行的恢复动作，再在可展开的诊断区保留稳定 code/category/source/recovery/retry/request 事实；
- 已验证的 Session 与 Grant 失败会进入对应页面恢复事件，不再丢掉请求证据；
- 文档补充版本冲突、项目限额、应用限流、平台额度/故障、身份认证与权限拒绝的 Agent 恢复动作；
- 使用线上 `VERSION_CONFLICT` 读回和真实中英文页面渲染完成验证，不依赖服务端或供应商自然语言。

REST API 与 D1 schema 相对 alpha.24 没有变化。两个 bundle 都会变化：Skill runtime 与指引发生变化，Web UI 及其编译后的静态资源也发生变化。

安装带 tag 的 plugin：

```text
codex plugin marketplace add https://github.com/breakstring/cfKanban.git --ref 0.1.0-alpha.25
codex plugin add cfkanban-agent-skills@cfkanban
```
