# cfKanban 1.12.0-rc.4

## 简体中文

RC4 在 RC3 基础上补齐公开发现入口，帮助 Agent 和爬虫读取本站已有的 API、Skills 与公开文档。

- 提供标准 API Catalog，并在首页响应中链接现有 OpenAPI 和双语文档。
- 发布四项 Skills 的发现索引与带完整依赖的独立归档，版本固定、下载摘要可核验；安装仍沿用官方完整发行和来源校验。
- 提供真实 robots.txt 和公开页面 sitemap，默认只允许首页及双语文档，私有页面保持禁止爬取。

本次无新增数据库迁移，API 兼容版本仍为 0.1.0、schema 仍为 28。Skills Discovery 采用 Draft v0.2.0，仅增加发现入口；索引反映实例当前发行，首次安装仍推荐官方 stable，使用 RC 须明确选择。Cloudflare Managed robots / Bot / 训练政策由 Owner 单独决定，普通升级不修改这些开关。本次部署不包含本机 Skill/plugin 更新。

范围与验收：[CFK-720](https://cfkanban.dev/app/issues/CFK-720)、[CFK-721](https://cfkanban.dev/app/issues/CFK-721)、[CFK-725](https://cfkanban.dev/app/issues/CFK-725)。

## English

RC4 adds public discovery entrypoints on top of RC3 so Agents and crawlers can find the API, Skills, and public documentation already provided by this instance.

- Publish a standard API catalog and homepage links to the existing OpenAPI and bilingual documentation.
- Provide a four-Skill discovery index and separate archives with complete dependencies, fixed versions, and verifiable download digests; installation retains the official complete release and source checks.
- Serve real robots.txt and a public-page sitemap, allowing only the homepage and bilingual documentation by default while private pages remain disallowed.

No new database migrations; API compatibility remains 0.1.0 and schema remains 28. Skills Discovery uses Draft v0.2.0 as a discovery layer. Its index describes the instance's current release; first installations still default to official stable, while an RC requires explicit selection. The Owner separately chooses Cloudflare Managed robots, Bot, and training policies; ordinary upgrades do not change those switches. This deployment does not update local Skills or plugins.

Scope and verification: [CFK-720](https://cfkanban.dev/app/issues/CFK-720), [CFK-721](https://cfkanban.dev/app/issues/CFK-721), [CFK-725](https://cfkanban.dev/app/issues/CFK-725).
