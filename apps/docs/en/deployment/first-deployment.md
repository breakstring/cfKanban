# First deployment

Create a cfKanban site in your own Cloudflare account. Joining an existing project does not require deployment.

## Ask your Agent

```text
Use the official installation guide to deploy a cfKanban site for me with the latest stable release:
https://github.com/breakstring/cfKanban/releases/latest/download/install.md
My Owner display name is <your name>.
Check readiness and explain the resources, costs, and permission changes. Wait for my confirmation before proceeding.
```

You can also use the deployment prompt generated by a cfKanban site's homepage. Both entry points include Skill setup: the Agent reuses a compatible installation or installs what is missing through the guide. You do not need a separate installation first.

You need an Agent that supports Skills, an environment with persistent private storage, and control of a Cloudflare account. If tools or sign-in are missing, the Agent explains the next step. See [Prepare for deployment](./setup.md) for prerequisites.

## Review the deployment plan

The default configuration uses one Cloudflare Worker, one D1 database, and a `workers.dev` address, including the Web UI and docs. Attachment storage and custom domains are separate choices.

Before execution, check:

- The Cloudflare account, version, and resource names.
- The Owner name and the address you will use afterward.
- What needs installing and any potential costs or new permissions.

The default basic configuration is not a cost guarantee. Actual quotas and charges depend on your Cloudflare account. For an existing instance, use [Connect an existing deployment](./attach.md) instead of initializing again.

## After deployment

The Agent provides the site address and verifies availability and your Owner identity. Credentials stay in private local storage; you do not need to paste them into chat. If interrupted, keep the maintenance records and use [Interruptions and recovery](./recovery.md).

Next, create your first board:

```text
Use $cfkanban-admin to create an “Everyday work” project in the “Team” workspace.
Create the workspace first if it does not exist, then open my first board.
```

Then [create tasks](../usage/issues.md) or [invite members](../administration/members.md). Cloudflare sign-in may need your browser interaction; the cfKanban Web UI does not provide a deployment button.
