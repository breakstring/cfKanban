# Agent 接入概览

无论加入团队还是部署自己的站点，都使用同一套 cfKanban 技能。安装后，直接向 Agent 描述任务即可；Codex App 和 DeepSeek Harness 的扩展提供看板、侧栏等增强体验，需要亲自浏览时再打开。

## 先看你是否需要单独安装

| 你现在要做的事 | 下一步 |
| --- | --- |
| 接受邀请 | 把管理员发来的**完整邀请消息**交给 Agent；[加入流程](../usage/access.md)会复用或按需安装技能 |
| 加入公开项目 | 复制站点首页为项目生成的 Agent 提示词，按引导继续 |
| 部署自己的实例 | 直接走[首次部署](../deployment/first-deployment.md)，技能准备是其中一步 |
| 接入新 Agent，或先准备当前 Agent | 选择下面的宿主安装方式 |
| 只使用已经能登录的线上网页 | 无需安装本地组件；首次身份建立和 Passkey 登记见[加入与登录](../usage/access.md) |

按需安装由 Agent 执行，涉及本机变化时会说明；仅打开邀请或部署网页不会自动安装软件。已有可信且兼容的技能会被复用，不会因为加入项目就自动更新。

## 选择当前 Agent

- **Codex App 桌面客户端** → [Codex App](./codex-app.md)，先通过技能协作，再按需使用工作台和任务搜索。
- **其他支持本地 Skills 的 Agent** → [通用 Agent](./general.md)，由 Agent 核验当前宿主的安装与连接能力。
- **DeepSeek Harness 桌面版或 Web 版** → [DeepSeek Harness](./deepseek-harness.md)，接入技能，并按需使用插件侧栏。

## 安装和连接交给 Agent

Agent 会准备技能和当前宿主支持的连接，检查是否可用；需要界面确认或重开会话时，会告诉你具体步骤，无需手写配置文件。安装接入不会自动加入项目或授予权限。

技能是日常使用的主要入口。宿主支持时，安装也会准备工作台等扩展能力；没有这些界面时，仍可以通过技能协作。你也可以明确要求只安装技能。

已安装旧版或只有技能时，可以让 Agent [检查或补齐接入](./general.md)。默认安装正式版，验收测试版时请明确版本。

准备好后，继续[加入与登录](../usage/access.md)。已经加入的用户可以开始[处理任务](../usage/index.md)，想亲自浏览时再[打开看板](./webui.md)。安装接入不会授予项目权限；已有 Owner 换电脑使用时走[设备接入](../administration/devices.md)。
