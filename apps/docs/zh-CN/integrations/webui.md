# 打开看板

::: tip 大多数时候，直接让 Agent 做就好
cfKanban 是一个 **Agent first** 的 Kanban 系统。查找任务、记录需求、修改状态、分配负责人、添加评论或完成任务，通常都可以直接告诉 Agent，无需打开任何界面。

当你想亲自看看进度、浏览详情或动手操作时，再按需要选择**本地轻量工作台**或**线上完整版**。
:::

两种界面访问同一实例的任务，遵循相同的业务权限。本地工作台适合在 Agent 旁查看和处理任务；线上完整版提供完整功能入口，包括账户与管理功能。本地工作台也需要连接线上实例，并非离线副本。

| | 本地工作台 / DSH 侧栏 | 线上完整版 |
| --- | --- | --- |
| 适合什么时候用 | 在 Agent 旁查看和推进任务 | 浏览完整应用，管理账户与团队 |
| 日常任务 | 项目切换、看板与列表、优先级/状态/负责人快捷编辑、详情、单事项标签、评论和完成 | 支持这些日常操作，也提供完整功能入口 |
| 工作区、成员、权限及自定义设置 | 让 Agent 打开对应管理入口 | 按现有权限和会话范围操作 |
| 如何打开 | 让 Agent 打开；DSH 可要求侧栏或点击 logo | 让 Agent 明确打开线上模式，或使用已登记的 Passkey 登录站点 |
| 本机要求 | 已安装对应本地组件；DSH 插件已包含 | 普通浏览器；使用 Agent 登录时需要可用的本地身份 |

完整版项目页面提供「看板 / 列表」切换，列表按状态分组并支持逐级展开子事项。切换视图保留已加载分页；打开事项或项目设置后返回，可保留列表视图和筛选条件。

## 打开本地工作台

```text
请打开 DemoProject 的看板。
```

也可以指定任务：

```text
请在本地工作台打开 CFK-123。
```

Agent 优先使用当前宿主已可用的工作台，例如 DSH 侧栏；否则在浏览器中打开本地工作台，按需启动服务。在 Codex App 中，可用时优先使用应用内浏览器。你也可以明确指定浏览器或线上完整版。

DSH 已启用兼容插件时，可以直接说：

```text
在侧边栏打开 CFK-123。
```

Agent 会定位请求的项目或事项，并确认页面已经打开。明确要求侧栏而当前宿主无法打开时，会说明限制，不改开浏览器。打开失败或结果不确定时，会先说明情况，不换入口重复打开。

在浏览器打开时，可能先短暂显示连通性检查页。宿主支持浏览器标签控制时，Agent 会沿用该标签打开工作台；仅能调用系统浏览器打开器时，可能保留单独的检查标签。

[目录关联](../usage/profile.md)可以让工作台自动打开当前代码项目对应的看板；多个匹配项目仍需选择。看板可横向滚动查看所有状态列；接近底部时继续加载任务。详情和评论旁的小按钮可复制 Markdown；详情右上角的「复制」菜单可选择任务编号或线上完整链接。本地工作台复制的也是线上任务链接，适合分享或交给 Agent。

本地工作台提供语言切换，并使用账号已保存的主题。事项属性中的「添加标签」可以搜索项目已有标签并选择添加，标签旁的移除按钮可解除一个关联；这些操作需要编辑权限。新建和管理标签请使用完整版。

浏览器工作台在闲置或睡眠后继续使用原本地会话，前提是服务仍在运行，最长到服务启动后的 8 小时。再次操作仍会核验当前身份和项目权限。到达上限或服务关闭后，让 Agent 重新打开；未确定写入保留原请求与幂等键供核实，重新打开不会自动再次提交。

## 打开线上完整版

```text
请打开 DemoProject 的线上看板。
```

本地工作台和 DSH 侧栏右上角也有「打开完整线上看板」图标，悬浮可见说明。它使用当前身份打开对应项目或任务，通常无需再次登录。需要管理功能时，让 Agent 打开对应管理页面。

在 Agent 打开的线上页面中，你也可以通过右上角账户菜单 →「个人设置」→「登记通行密钥」登记 Passkey，之后直接从站点首页登录。**不需要在打开网页的话术里特意提到 Passkey**；登记时按浏览器或系统提示确认即可。首次和补充登记都需要 Agent 打开的线上会话，具体步骤见[加入与登录](../usage/access.md)。

线上会话仍有效时，首页右上角的按钮显示「进入工作台」。点击 logo 回到首页后，可从这里直接返回，无需再验证 Passkey。

工作区和项目管理员使用[项目管理入口](../administration/index.md)，Owner 的实例级功能见[部署与管理](../deployment/index.md)。

两种界面都需要网络访问线上实例。关闭本地页面不会退出线上网页；更新本地组件后，按 Agent 提示重启工作台或 DSH，才能使用新版本。
