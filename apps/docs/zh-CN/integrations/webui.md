# 打开看板

cfKanban 有本地工作台和线上完整版两种界面。**它们访问同一实例的任务，使用相同权限；本地工作台不是离线副本。** 日常处理任务优先使用本地工作台，需要账户或管理功能时打开线上完整版。

| | 本地工作台 / DSH 侧栏 | 线上完整版 |
| --- | --- | --- |
| 适合什么时候用 | 在 Agent 旁查看和推进任务 | 浏览完整应用，管理账户与团队 |
| 日常任务 | 项目切换、看板与列表、优先级/状态/负责人快捷编辑、详情、评论和完成 | 支持这些日常操作，也提供完整功能入口 |
| 工作区、成员、权限及自定义设置 | 让 Agent 打开对应管理入口 | 在权限和当前会话范围允许的范围内操作 |
| 如何打开 | 让 Agent 打开；DSH 点击 logo | 让 Agent 明确打开线上模式，或使用已登记的 Passkey 登录站点 |
| 本机要求 | 已安装对应本地组件；DSH 插件已包含 | 普通浏览器；使用 Agent 登录时需要可用的本地身份 |

## 打开本地工作台

```text
请打开 DemoProject 的本地工作台，使用我当前的 cfKanban 身份。
```

也可以指定任务：

```text
请在本地工作台打开 CFK-123。
```

Agent 默认用本地模式打开项目或任务，按需启动服务。在 Codex App 中，可用时优先在应用内浏览器打开；你也可以明确指定浏览器。在 DSH 中，使用聊天旁的侧栏即可。启动失败时，Agent 会说明原因，不会擅自换成线上模式。

[目录关联](../usage/profile.md)可以让工作台自动打开当前代码项目对应的看板；多个匹配项目仍需选择。看板可横向滚动查看所有状态列；接近底部时继续加载任务。详情和评论可复制 Markdown，也可复制任务编号或链接交给 Agent。

## 打开线上完整版

```text
请打开 DemoProject 的线上完整版看板。
```

本地工作台和 DSH 侧栏右上角也有「打开完整线上看板」图标，悬浮可见说明。它使用当前身份打开对应项目或 Issue，通常无需再次登录。需要管理功能时，让 Agent 打开对应管理入口，取得匹配的管理会话。

需要登记 Passkey 时，明确说：

```text
请打开线上完整版网页，我要为当前身份登记 Passkey。
```

登记后可以直接从站点首页登录；具体步骤见[加入与登录](../usage/access.md)。工作区和项目管理员使用[项目管理入口](../administration/index.md)，Owner 的实例级功能见[部署与管理](../deployment/index.md)。

两种界面都需要网络访问线上实例。关闭本地页面不会退出线上网页；更新本地组件后，按 Agent 提示重启工作台或 DSH，才能使用新版本。
