# 通用

本页适用于能够发现 Skills、运行本地 stdio MCP 或打开浏览器的宿主。[DeepSeek Harness](./deepseek-harness.md)另有专用插件指南。其他宿主沿用自身支持的发现和刷新方式；能复用常规 Skills 或 MCP，不等于已有 cfKanban 专用适配器。

## 安装技能

```text
请为当前 Agent 宿主安装 cfKanban 官方正式版 Skills。
说明本地安装影响，保留已有 cfKanban 身份，并核对四个技能能否加载。
不要部署或升级实例。
```

Agent 先识别当前宿主及其支持的安装方式，阅读官方[安装引导](https://github.com/breakstring/cfKanban/releases/latest/download/install.zh-CN.md)，从 [canonical stable pointer](https://github.com/breakstring/cfKanban/releases/latest/download/stable.json)发现目标，固定不可变 manifest 与准确发行版本，在安装前核验发布者、允许的工件来源与 SHA-256 摘要。只检查可用性不代表授权安装；没有可校验的正式发行时说明结果，不用源码 checkout 或插件缓存替代。

安装完整 bundle，保留四个 Skills、共享 `packages/skill-runtime` 与相对目录。只复制一个 `SKILL.md` 或单个技能目录不完整。包含本地集成的发行还会提供预构建 `mcp/`、`local-runtime/`、匹配的自包含 Vue 页面与 `dsh/`。它使用已有兼容 Node.js，本身不包含或安装 Node.js。

| 宿主能力 | 安装与核验 |
| --- | --- |
| 能发现本地 Skill 目录 | 按宿主支持的布局安装完整已校验 bundle，核对引用资源及实际技能路径。 |
| 支持兼容 Git plugin 或 marketplace | 使用已公开正式发行的默认 `main` 来源，核对 commit 与所选发行 tag、安装文件与已校验 bundle 一致。 |
| 支持 plugin 的 Codex | 仓库是插件来源；普通正式版安装跟随 `main`，省略 `--ref`。本次安装固定摘要与已保存更新来源分别核对。 |
| 支持本地 stdio MCP | 按宿主文档添加固定预构建入口，见下文。 |
| DeepSeek Harness 桌面或 Web | 在目标 profile 安装[已校验 DSH 压缩包](./deepseek-harness.md)。 |

`main` 落后所选发行或安装期间发生变化时，说明不一致并重新检查，不静默选择开发分支或其他 tag。宿主没有兼容发现布局时应说明限制，不能用不完整复制替代。

核对 `cfkanban-howto`、`cfkanban`、`cfkanban-admin`、`cfkanban-deploy` 均可加载，包含引用资源。第一个只读讲解能力，后三个分别负责日常协作、应用管理与安装/部署。从每个实际操作技能目录运行 `node scripts/cfkanban-tool.mjs help` 核对命令表面。部分宿主安装后需要新会话；应核验新会话实际加载的版本。

## 连接已有身份和项目范围

安装 Skills 不会加入项目。邀请或 Public Join 见[加入与登录](../usage/access.md)；Owner 为新电脑接入身份见[Owner 设备](../administration/devices.md)。集成使用实际 OS 用户和执行环境私有 `.cfkanban/`，不接受聊天、命令参数、环境变量、MCP 配置或浏览器存储中的凭据。

通过[目录关联](../usage/profile.md)用 `.cfkanban-scope.json` 推荐准确实例/项目范围。该文件是非秘密过滤，不授予权限。本地视图核对真实工作目录、可信实例、实时身份与项目权限：单个有效目标可自动绑定，多个目标必须明确选择；文件缺失或非法时保留手动入口，不静默查询所有项目。

## 本地 MCP 与工作台

这些入口要求已公开所选发行包含匹配预构建工件，以及 Node `>=22.12.0`。源码测试不证明它们已公开可用。

配置已核验 Node 可执行文件的绝对路径，把固定服务入口作为独立参数：

```json
{
  "command": "/absolute/path/to/node",
  "args": ["/absolute/path/to/verified-bundle/mcp/server.mjs"]
}
```

这只是一个服务入口示例，不是所有宿主通用的配置文件。使用宿主支持的 MCP 格式，带空格路径仍作为独立参数。启动不编译源码或在线下载依赖。本地 MCP 提供有界日常工具，加入、恢复、管理、部署和敏感浏览器交付继续走 Skills。此集成不提供远程 Worker MCP 或 OAuth。

```text
请用 cfKanban MCP 核验我在 <实例> 的身份，再列出项目 <UUID> 的未完成任务。
显示返回的 Principal 和实际查询范围，先不要修改任务。
```

写入前核对实例、身份和范围。每次写入只执行一个原子操作，使用稳定幂等键；需要 CAS 时使用当前版本。权限与审计仍由 Service 强制落实。

打开本地工作台时，给 Agent 真实工作目录与准确目标：

```text
请用 $cfkanban 在本地模式打开 <实例> 的项目 <UUID>，使用 <工作目录绝对路径> 发现项目范围。
只打开视图，不修改任务。
```

Skill 的 `web open` 默认以本地模式打开项目或 Issue，按需启动本地服务，展示与 DSH 侧栏共用的 Vue 任务视图。要打开完整实例 Web UI 或管理页，明确选择线上模式：

```text
请用 $cfkanban 在我指定的浏览器中，以线上模式打开 <实例> 的 CFK-123。
```

本地模式不接受管理目标；Node 缺失、bundle 不完整或启动失败时也不静默切换线上。可信上下文确认 Codex App 且 IAB 可用时，Agent 先核验同环境回环可达，再优先使用 IAB；用户明确指定浏览器时遵循选择。其他受支持浏览器走已核验交付路径。长期凭据和一次性启动能力不会复制进视图或回复。

前端资源在本机，任务读写仍访问可信线上 Service。可以切换项目，使用看板/列表、详情、手动刷新，以及权限允许的优先级、状态、负责人、评论和完成控件。看板和列表接近底部时追加下一页，并保留手动加载；状态数量表示已加载事项，“+”表示还有下一页。达到容量时筛选或打开完整看板。把 CFK 编号或 Issue URL 交给 Agent，由它读取当前任务；正文与评论可复制原始 Markdown，剪贴板失败时提供纯文本手动复制。

## 更新本地技能

```text
请用 $cfkanban-deploy 检查本地技能与 <实例地址> 的兼容正式版更新，先不要修改。
```

```text
请用 $cfkanban-deploy 将本地 cfKanban 技能和当前宿主入口更新到最新兼容正式版。
保留可恢复的旧安装及私有身份，不要升级线上实例。
```

检查只报告可用版本。明确更新时核验兼容性和发布者连续性，说明本地变化与回退，实际更新宿主入口并核验加载。最新 Skills 不兼容旧实例时复用兼容安装，或明确选择兼容历史版；升级服务器仍是独立[部署操作](../deployment/updates.md)。

明确版本优先；可信对话中明确承接、用于验收的准确 RC 也可选中。泛泛提过 RC 或当前开发分支不代表选中它；其他情况使用最新正式版。安装版本与摘要为本次核验固定，宿主长期正式版更新来源另外检查。RC 临时验收复用既有宿主入口，并保留或恢复该来源；宿主无法将 RC 安装与来源分离时，说明下次原生正式版更新前需要切回。

### 将固定旧 tag 的 Git 来源切回默认分支

```text
请把已有 cfKanban Git 安装来源从固定 tag 切到默认正式版分支，并更新宿主入口。
先说明保存的来源与变更，保留身份和部署记录，不升级实例。
```

只有固定 tag 的 Git 安装需要这次来源切换。从复制的 Codex 命令删除 `--ref` 不会修改既有注册。使用宿主支持的来源切换方式，核验保存来源、实际安装文件与所选发行；本地目录安装继续使用已校验 bundle 更新。

分别报告 canonical active receipt、宿主投影与当前会话实际加载的版本，更新一个不能证明三个都变了。更新后停止并重启 MCP 与所属 `web open` 进程，再核验运行版本；替换文件不会更新运行中的进程，关闭浏览器标签也不代表本地服务停止。

## 恢复或移除集成

冲突时先读取最新状态；超时或中断的写入可能已经提交。保留原参数和幂等键，先读回，必要重试使用同一请求。身份改变时重新选择核验；不确定操作保留原视图和恢复入口，不新建替代写入或线上打开。

通过宿主终端或进程控制停止本地服务。移除宿主 Skill/MCP 配置只停用该接入，保留 `.cfkanban/`、身份、部署记录与任务历史。Windows 原生、WSL、容器、SSH 和远程 Host 使用独立执行环境的 home；应在目标环境走接入流程，不通过复制秘密绕过沙盒或网络限制。
