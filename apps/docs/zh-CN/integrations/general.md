# 通用 Agent

适用于 Codex、Claude Code 等支持加载本地 Skills 的 Agent。使用 [DeepSeek Harness](./deepseek-harness.md)时，优先安装它的专用插件。

如果你正在接受邀请或首次部署，直接继续那个引导，**不必先执行下面的独立安装**。

## 让 Agent 安装

把这段话交给要使用 cfKanban 的 Agent：

```text
请阅读 cfKanban 官方安装引导：
https://github.com/breakstring/cfKanban/releases/latest/download/install.zh-CN.md
为当前 Agent 安装 cfKanban，保留已有身份，完成后检查接入是否可用。
不要部署或升级线上实例。
```

Agent 会选择当前宿主支持的安装方式，复用兼容工具并核验安装来源。默认安装包括本地组件，以及宿主支持的 MCP 连接；无需你另提一次启用请求。如果需要补充 Node.js 或重开会话，会说明你要做什么。不同 Agent 的技能目录和刷新方式可能不同，不用自行复制文件。

安装后应能使用四个技能：`cfkanban-howto` 讲解用法，`cfkanban` 处理任务，`cfkanban-admin` 管理应用，`cfkanban-deploy` 安装、更新与部署。它们不会自动授予业务权限；新成员继续[加入与登录](../usage/access.md)。

### 已从 Codex 插件市场安装

Codex 的 Git 插件提供技能指引，但不附带预构建的本地工作台。如果尚未准备本地组件，把这段话交给 Agent：

```text
我已安装 cfKanban 插件。请检查并补齐当前版本的本地接入，
保留我的身份和项目关联，然后打开当前项目的工作台。
```

只使用线上完整版网页时，无需补齐本地页面。其他宿主是否有原生插件入口，以其支持情况为准；不要套用 Codex 的安装命令。

## 安装完成后应看到什么

- 四个技能可以加载。
- 支持 MCP 的宿主已连接 cfKanban，Agent 验证过工具可用；DSH 插件无需重复添加。
- 本地组件已就绪，可以让 Agent [打开工作台](./webui.md)。实际访问项目仍需要身份与权限。

配置由 Agent 完成，你不需要填写路径、凭据或 JSON。某些宿主需要你确认设置或重新打开会话，Agent 会给出具体步骤。宿主不支持 MCP、组件缺失或运行条件不满足时，安装结果会列出未完成项；技能仍可用于受支持的操作。

已安装过的用户可以让 Agent 补齐或检查连接：

```text
请检查现有 cfKanban 接入，补齐同版本本地组件，配置并验证当前宿主支持的 MCP。
保留已有身份与其他 MCP 配置，告诉我是否需要重新打开会话。
```

只有连接其他程序或需要自行配置时，才需要阅读 [MCP 接入参考](./mcp.md)。

## 开始工作与后续更新

已有身份时，让 Agent [打开看板](./webui.md)即可。本地工作台适合日常任务；账户设置和管理功能使用线上完整版。经常在同一代码目录工作，可以[关联项目](../usage/profile.md)，减少重复选择。

以后需要更新时：

```text
请将本地 cfKanban 技能和当前 Agent 入口更新到兼容的最新正式版，
保留身份和项目关联，不升级线上实例。完成后告诉我哪些会话或本地服务需要重启。
```

本地更新与[实例升级](../deployment/updates.md)分开进行。新电脑、WSL、容器或远程环境有各自的安装与身份，不要直接复制凭据。移除宿主接入不会删除线上任务。
