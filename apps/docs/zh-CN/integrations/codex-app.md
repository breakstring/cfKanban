# Codex App

在 Codex App 中，**技能是使用 cfKanban 的主要方式**：直接告诉 Agent 你想做什么。扩展提供看板、任务详情和 `@` 搜索，让你也能在会话旁亲自浏览。

## 安装与检查

首次安装，将[通用安装指南](./general.md)中的提示词交给 Codex。已经安装时，可以让 Agent 检查：

```text
我已在 Codex App 安装 cfKanban，请检查技能和本地接入是否就绪，
保留我的身份和项目关联，并告诉我是否需要重开 Codex。
```

新成员还需要[加入项目](../usage/access.md)。

## 用技能日常协作

安装后，直接用自然语言给 Agent 下达请求，例如：

```text
查看当前项目中分配给我的未完成任务，按优先级列出。
读取 CFK-123，说明目标和当前进展。
把 CFK-123 的优先级改为高，并添加评论说明原因。
```

四个技能分别负责使用指导、任务协作、管理，以及安装与部署，见[通用 Agent 指南](./general.md)。创建和编辑任务、评论及完成记录等日常操作都可以交给 Agent，具体用法见[处理任务](../usage/index.md)。

## 用扩展浏览和引用任务

扩展在技能之外提供界面增强；客户端支持时，你可以打开工作台亲自浏览或操作，也可以从输入区选择任务引用。

### 打开看板与任务详情

从客户端的 cfKanban 入口打开工作台，或对 Agent 说：

```text
打开 cfKanban 看板。
打开 CFK-123 的详情。
```

*完整看板，点击图片可查看原图。*

[![Codex App 的会话侧面板显示 CFK-600 详情，与聊天并排](../../assets/integrations/codex-app-sidebar.png)](../../assets/integrations/codex-app-sidebar.png)

*任务详情与会话并排，点击图片可查看原图。*

点击顶部项目名称切换项目，在看板与列表之间切换，点击任务查看详情。工作台的显示位置由客户端决定，可用时点击「展开工作台」放大。需要浏览器页面时，可以说「在浏览器中打开 cfKanban 看板」。

### 在会话中引用任务

1. 在输入区输入 `@`，**点击选择 `cfkanban-search`**。
2. 在出现的名称标签后输入完整编号 `CFK-123`、部分编号 `CFK-12` / `12`，或标题关键字，例如「插件搜索」。
3. 点击匹配的任务，再补充「总结这个任务」等请求并发送。

[![选中 cfkanban-search 后输入标题片段“看板”，候选列表显示任务编号、标题和所属项目](../../assets/integrations/codex-search.png)](../../assets/integrations/codex-search.png)

*先选择搜索入口，再输入编号或标题；点击图片可查看原图。*

部分编号至少两位数字，标题关键字至少两个字符；不搜索正文或评论。候选列表显示任务编号、标题及所属项目，选中后可让 Agent 读取任务内容。

请先点击选择入口，直接手打整串 `@cfkanban-search CFK-123` 可能仍停留在全局搜索。也可以直接发送「请读取 CFK-123 并总结」，无需使用搜索或工作台。

## 更新与常见问题

需要更新时，可以对 Agent 说：

```text
请将这台电脑上的 cfKanban 技能和插件更新到最新正式版，
保留我的身份和项目关联，并告诉我是否需要重开 Codex。
```

本地更新与[线上实例升级](../deployment/updates.md)分别进行；更新插件不会自动升级线上服务。

- **搜索没有结果？** 检查输入长度。首次使用需要准备任务列表，稍后重新输入；仍无结果时，让 Agent 检查连接和项目权限。
- **没有工作台入口，或更新后界面仍旧？** 让 Agent 检查本地安装和客户端支持情况。技能仍是协作入口，界面问题可按提示重连或重开 Codex。

在工作台修改任务时，如果结果不确定，先在原页面点击「恢复」并确认结果，再关闭页面或重启。
