# Codex App

在 Codex App 中，你可以用 cfKanban 查看完整看板、在会话旁打开任务详情，也可以从 `@` 菜单查找任务并交给 Agent 讨论。原生工作台需要支持 [Plugin Extensions](https://developers.openai.com/plugins/build/extensions) 的桌面客户端，使用当前电脑的 cfKanban 身份，访问与线上网页相同的任务和权限。

::: info 核对实际安装版本
工作台需要完整的本地组件，编号／标题搜索还需要服务端支持搜索索引同步。请核对实际使用电脑上的运行组件。更新本地插件不会升级线上实例，截图和源码检查也不替代安装与更新核验。安装测试版时，在请求中写明准确版本。
:::

## 安装与检查

首次准备当前 Agent 时，按[接入概览](./index.md)选择共同安装流程；接受邀请或首次部署可以在各自引导中按需准备。已从 Codex 的 Git 插件或 marketplace 安装过时，可以说：

```text
我已在 Codex App 安装 cfKanban 插件。请检查并补齐当前版本的本地接入，
保留身份、项目关联和其他连接，核对原生工作台是否可用，告诉我需要重开的会话或应用。
不要部署或升级线上实例。
```

Git 插件中的技能和完整发行包中的本地组件分别核验。只加载了技能不证明原生工作台已就绪；Agent 会检查实际组件、连接和入口，列出尚需完成的操作。无需向配置中填写 cfKanban 凭据。安装不授予项目权限；新成员继续[加入与登录](../usage/access.md)。

## 选择工作台入口

| 入口 | 怎么打开 | 项目如何选择 |
| --- | --- | --- |
| 全局工作台 | 从客户端全局导航的 cfKanban 入口打开 | 重新核验上次全局项目，否则在当前身份下打开可访问的默认项目 |
| 会话工作台 | 在会话面板选择 cfKanban，或让 Agent 打开 | 优先使用明确请求的项目或任务；有可信仓库上下文时，再使用该仓库的上次项目或已核验推荐 |

请求 Agent 打开当前会话的工作台：

```text
在当前对话旁边打开 cfKanban 工作台，并核对当前身份与项目。
```

要直接打开某个任务，提供完整编号：

```text
在 Codex 工作台打开 CFK-123 的详情，核对页面显示的编号和所属项目。
```

[![Codex App 的会话侧面板显示 CFK-600 详情，与聊天并排](../../assets/integrations/codex-app-sidebar.png)](../../assets/integrations/codex-app-sidebar.png)

*任务详情与当前会话并排，点击图片可查看原图。打开后核对工作台显示的编号和项目。*

Agent 解析准确实例与项目，核对身份和权限后打开所请求的任务。无权或目标不符时显示具体错误，不改开其他任务或看板。也可以直接指定项目。打开页面不会修改任务；工具调用成功不等于请求的页面已显示，请核对实际编号和项目。

看板与列表在客户端支持时优先全屏展示；最终布局由客户端决定，也可能先以内联形式出现。可用时，点击「展开工作台」进入更大的视图，退出后保留当前项目与页面。会话侧面板是客户端布局，不是独立的显示模式。手动打开不证明已识别仓库上下文，指定任务也不会强制某种布局。

需要普通浏览器或线上完整版时，明确告诉 Agent，步骤见[打开看板](./webui.md)。原生工作台的打开请求不会自动安装插件。

## 切换项目与再次打开

点击当前项目的选择器，可按工作区浏览当前已核验实例中所有有权访问的项目；还有项目时继续翻页。选择成功后才切换看板，选择失败保留当前项目。仓库推荐只帮助初始选择，不限制你切换到其他有权项目。

- **全局入口**独立记住本机最后成功选择的项目，与会话和仓库选择分开。
- **Agent 带可信仓库上下文打开的会话入口**记住该仓库最后成功选择的项目，包括你在界面中切换到的其他有权项目。同一工作树的子目录共用选择，不同 worktree 分开。
- **没有仓库上下文的会话入口**不读取全局记忆。只有一个已核验本地连接时打开可访问默认项目；多个未明确的连接需要先选择。

每次重开都会核对身份、项目所属工作区和访问权限。项目记忆只保存项目；要重开详情，请再次明确任务。它不会修改[目录关联](../usage/profile.md)或 CLI 默认选择，不授予新权限，也不恢复筛选、草稿或此前写入。明确项目或保存的目录默认失效时显示具体错误，不静默换项目。

## 在会话中引用任务

本地组件与目标实例都需要支持任务引用读取。当客户端实际提供 cfKanban 的引用入口时：

1. 在输入区输入 `@`，**点击选择 `cfkanban-search`**，其说明是按编号或标题搜索 cfKanban 任务；部分客户端菜单可能将它归在插件显示名称下。
2. 确认出现入口名称标签，再输入 `CFK-123`、部分编号 `CFK-12` / `12`、标题片段，例如「插件搜索」，或粘贴已连接可信实例的规范任务链接。
3. 点击返回的事项候选，再补充「总结这个事项」等请求并发送。

[![选中 cfkanban-search 后输入标题片段“看板”，候选列表显示任务编号、标题和所属项目](../../assets/integrations/codex-search.png)](../../assets/integrations/codex-search.png)

*先选择入口，再输入标题片段，即可选择匹配任务并加入引用；点击图片可查看原图。*

直接键入整串 `@cfkanban-search CFK-123` 不会自动选择该入口，仍可能停在全局搜索。任务搜索入口与 **Sources** 或设置中可能出现的 `cfkanban-mcp` 连接名称用途不同。

完整编号优先；部分编号至少两位数字，标题片段至少两个字符。最多返回十个带编号、标题、工作区和项目的候选，标题匹配不区分英文大小写；不搜索正文或评论。

候选来自本机持久缓存，每次输入无需等待网络更新或核权。新电脑只有一个本地连接时，MCP 初始化后开始后台准备索引。未完成时客户端可能显示无候选；完成后请重新输入查询，已打开的候选列表不会自动刷新，重开则复用已有索引。

使用搜索期间，后台每 30 秒检查变化；连续 5 分钟未搜索时停止，再次搜索时恢复。本机修改标题等索引字段后也会后台刷新。多个连接需要先用可信任务链接明确实例。

每次同步检查可访问项目。新获权项目先补齐已有任务，再继续增量更新；补齐期间搜索暂不返回候选。撤权项目在同步确认后清理。刚改名、删除或撤权的任务可能短暂留在列表中；读取选中的引用时会实时核权，无权或已删除时拒绝读取。不同实例和用户各自保存缓存，活跃缓存文件不要放到网盘同步。

选中的引用让 Agent 按当前权限读取任务主要字段与正文，超长内容会标明截断；评论、关系及更多详情按需要继续读取。引用不会创建任务、修改状态、开始执行或增加授权。多个实例中的编号无法唯一定位时，需要准确的可信任务链接；不会跨所有实例搜索。

客户端没有显示引用入口时，直接把编号交给 Agent：

```text
请读取 CFK-123，说明当前状态、目标和需要我确认的事项。
```

在工作台中也可以复制编号、线上链接或原始 Markdown 交给 Agent。工作台不会自动发送聊天消息，当前不提供定位业务任务的 Codex deep link。

## 日常操作与恢复

工作台支持看板与列表、详情、按权限创建和编辑任务、修改优先级/状态/负责人/标签、评论及完成记录。账户、成员和 Owner 管理仍使用[线上管理页面](../administration/index.md)。语言和主题优先采用账号设置；没有语言偏好时采用宿主或浏览器语言，中文使用简体中文。

写入结果不确定时，先在原页面使用**恢复**。恢复完成前保留原页面及所属 MCP 进程；新入口、关闭重开或记住项目都不能证明原写入失败，也不会恢复或自动重放原操作。

## 安装与更新常见问题

**技能可用，但没有 cfKanban 工作台入口？** 让 Agent 检查当前客户端是否支持对应 Extensions、本地完整组件是否就绪及 MCP 是否连接。不支持原生界面的客户端仍可使用已发现的业务工具或技能；按需要选择浏览器工作台，不凭客户端名称推断支持。

**已经选择引用入口，却没有事项候选？** 先确认输入达到编号或标题的长度要求，首次同步尚未完成时稍后重新输入查询；再让 Agent 核对实际 MCP 版本、连接、后台同步错误及项目权限。Skills 或插件页面的版本不证明 MCP 已加载同一版本；更新后还需核对宿主 MCP 入口指向的新工件路径，并重新连接。

**界面打开了，却没有项目？** 先核对身份、连接和[项目权限](../usage/access.md)。多个连接需要选择；安装组件不会自动加入项目。

**编号引用提示能力不支持？** `MCP_ISSUE_REFERENCE_UNSUPPORTED` 表示目标实例未提供引用读取能力，不是“没有匹配任务”。本地更新不会自动升级实例；让 Agent 核对两端版本，实例升级另行按[升级流程](../deployment/updates.md)处理。

**搜索索引提示能力不支持？** `MCP_SEARCH_INDEX_UNSUPPORTED` 表示服务端未提供索引同步，旧实例不能支持新组件的本地标题搜索。需要分别核对本地组件和实例版本；更新本地插件不会自动更新线上服务。

**为什么重新打开后没有恢复原任务或草稿？** 项目记忆只用于再次选择项目；要打开当前任务详情，请再次提供完整编号。每次新入口建立独立视图，原筛选、草稿和待核实写入不会转移。此前结果未知时先核对原操作。

**更新后界面仍旧？** 先处理原视图未确定写入，再让 Agent 更新本地安装，关闭旧工作台、重启所属 MCP，并重新从入口打开。只刷新旧视图不能证明使用了新组件。

```text
请更新 Codex App 的本地 cfKanban 安装到兼容的最新正式版，保留身份和项目关联。
先核对工作台中是否有未确定的操作，更新后验证运行版本并说明需要重启的连接。
不要升级线上实例。
```

**初始化失败或连接失效？** 将界面显示的错误代码告知 Agent，请其核对运行版本、连接和客户端；不要把初始化错误当作“尚未加入”。原写入结果已明确时可以关闭重开；结果未知时先核对。具体代码、stdio 配置和工作台协议见 [MCP 接入参考](./mcp.md#工作台协议参考)。

停用或移除宿主接入不会删除线上任务；本地更新与[实例升级](../deployment/updates.md)分开。
