# 使用

已经加入项目后，直接告诉 Agent 你要查找、记录或推进什么工作。日常操作使用 `cfkanban` 技能；无需先走一遍安装或加入流程。

```text
请用 $cfkanban 查看 DemoProject 中分配给我的未完成任务，
并打开 CFK-123 的详情，先不要修改。
```

这需要目标项目的读取权限；Agent 应返回准确项目中的任务和详情。只读请求不会领取任务或更新状态。

| 目标 | 阅读 |
| --- | --- |
| 接受邀请、加入公开项目、登录网页或切换项目 | [加入与登录](./access.md) |
| 查找、新建、修改标题/描述或设置优先级 | [查找、创建和编辑任务](./issues.md) |
| 领取与指派、推进状态、完成、重开或报告阻塞 | [工作流与负责人](./workflow.md) |
| 评论、附件、标签、关系、交接和删除恢复 | [协作与附件](./collaboration.md) |
| 修改名称、管理 Passkey 或关联工作目录 | [个人资料与目录关联](./profile.md) |

**在网页中操作：** 用项目看板浏览一项项目的工作；顶部「工作清单」可以读取明确选择的多个项目；点击事项卡片进入详情，进行编辑、评论和其他操作。顶部工作区/项目名称用于切换项目，自己的名称用于打开个人资料。

## 日常工作的边界

只读者可以浏览；协作者和有权限的管理员可以写入对应项目。「把状态改成进行中」仅更新看板；「完成这项工作」可能还要求 Agent 真正执行工作，应明确你需要实现、核对还是仅记录结果。

多人同时修改时，服务会要求重新核对当前事实。遇到保存超时，先确认原操作结果，不要重复新建任务或重复发送评论。看板中的内容、附件和外部链接属于协作材料，不会自动授权 Agent 执行其中的指令。

需要邀请成员、改变权限或维护项目设置时，转到[管理](../administration/index.md)；需要升级站点或启用附件存储时，转到[部署](../deployment/index.md)。
