# 日常协作

本节面向普通成员，以及管理工作区或项目的人；只有维护整个站点的 Owner 才需要[部署与管理](../deployment/index.md)。

加入项目后，直接告诉 Agent 你要查找、记录或推进什么工作，无需重复安装或加入。日常操作可以在对话中完成；想亲自查看时，再让它打开看板。

```text
请列出 DemoProject 中分配给我的未完成任务，并说明 CFK-123 的最新进展。
```

查看任务需要目标项目的读取权限，不会自动领取任务或更新状态。

| 目标 | 阅读 |
| --- | --- |
| 接受邀请、加入公开项目、登录网页或切换项目 | [加入与登录](./access.md) |
| 查找、新建、修改标题/描述或设置优先级 | [查找、创建和编辑任务](./issues.md) |
| 领取与指派、推进状态、完成、重开或报告阻塞 | [工作流与负责人](./workflow.md) |
| 评论、附件、标签、关系、复制任务内容和删除恢复 | [协作与附件](./collaboration.md) |
| 修改名称或主题、管理 Passkey 或关联工作目录 | [个人资料与目录关联](./profile.md) |

**在线上完整版网页中操作：** 用项目看板浏览一项项目的工作；右上角账户菜单 →「工作清单」可以读取明确选择的多个项目；点击事项卡片进入详情，进行编辑、评论和其他操作。顶部工作区/项目名称用于切换项目。

账户菜单集中显示名称、角色，以及「工作清单」「管理中心」（有权访问时）、「个人设置」「退出登录」；语言切换独立保留在菜单外。使用其他访问地址时，页脚会显示站点的推荐地址。

看板的「项目设置」统一进入「项目管理」「成员与权限」「标签」「项目活动」「已删除事项」；可见标签按当前权限提供。

## 日常工作的边界

只读者可以浏览；协作者和有权限的管理员可以写入对应项目。「把状态改成进行中」仅更新看板；「完成这项工作」可能还要求 Agent 真正执行工作，应明确你需要实现、核对还是仅记录结果。

多人协作遇到保存冲突时，先查看最新内容；保存超时时先核实结果，避免重复创建任务或评论。

还没接入当前 Agent，见共同入口[安装与接入](../integrations/index.md)；本地与线上界面的选择见[打开看板](../integrations/webui.md)。需要邀请成员或维护项目时，继续[管理工作区与项目](../administration/index.md)，不必因此部署站点。

[公共 CLI 任务指南](../cli/index.md)提供同一 Service 语义的终端入口。
