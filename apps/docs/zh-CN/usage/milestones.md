# 项目里程碑

里程碑把一组 Issue 组织为同一个阶段交付目标，例如「附件能力交付」。一个项目可以没有里程碑，也可以有多个；里程碑可以先创建，再逐步加入事项。

## 创建与维护

在网页项目页进入「里程碑」，查看目标日期、总数、已完成、未完成和已取消事项。有写入权限时可以创建或编辑名称、目标说明、可选目标日期，以及显式关闭或重新开放里程碑。只读参与者可以查看。

Issue 全部完成不会自动关闭里程碑；关闭也不会自动完成、取消或移出 Issue。目标日期可留空，关闭后仍可显式调整事项归属。

```text
请在当前项目创建「附件能力交付」里程碑，目标日期为 2026-11-30，说明为「完成附件上传和读取验收」。
```

## 设置 Issue 归属

创建 Issue 时选择「里程碑」，可以保留「不归属里程碑」。已有事项可直接在详情右侧的「里程碑」属性中加入、更换或移出，选择后立即保存，无需进入「编辑事项」。一个 Issue 同一时刻最多属于一个同项目里程碑；变更保留历史，父子事项各自选择，不自动继承。

```text
把 CFK-123 加入当前项目的「附件能力交付」里程碑；先核对准确目标和事项版本。
```

```text
将 CFK-123 移出里程碑，保留它的状态和其他内容。
```

看板或列表可按一个里程碑筛选，也可以只查看不归属任何里程碑的事项。里程碑列表和选择器提供「加载更多」，无需一次读取全部事项。

在本地浏览器工作台或宿主工作台打开 Issue 后，可在详情属性区使用「里程碑」加入、更换或退出目标；只读参与者查看当前归属。选择器包含已关闭里程碑并提供「加载更多」，当前目标在对应候选页尚未加载时仍会显示。归属在写入确认后更新，操作待恢复时须先核实结果再修改。创建和维护里程碑可使用完整版 Web 或 Agent/CLI。旧 Service 尚未支持里程碑时，普通 Issue 详情仍可使用，该控件会隐藏。

## 进度口径

每个明确归属且未删除的 Issue 计一件。已取消单独显示，不计入已完成；未完成包含待规划、待办和进行中。父子事项都加入时分别计数，不递归纳入未明确加入的子孙。这是事项数量，不是工时估算。

项目归档期间暂停内容访问，恢复后可继续使用；永久删除项目会按既有清理合同清除其里程碑和历史。本版提供进度数字与关联事项，趋势图单独规划。

## 终端与 API

公共 CLI 提供 `milestone list`、`milestone show`、`milestone create`、`milestone update`，参数与当前实例、项目上下文按既有规则解析。使用 `milestone update --status-key closed` 关闭，`--status-key open` 重新开放，并提供读取到的 `--expected-version`。

Issue 创建或更新使用 `--milestone-id <UUID>`；`issue update --milestone-id null` 明确移出。Issue 列表、计数和候选使用 `--milestone <UUID>`，或 `--milestone none` 只看未归属事项。

MCP 提供同等的里程碑读取、创建和修改能力，并支持可选 Issue 归属。API 写入沿当前项目权限、CAS 和创建幂等合同；冲突保留草稿，响应未知保留原请求并核实，不重复创建。
