# 查找、创建和编辑任务

任务在网页中称为「事项」（Issue），使用 `CFK-123` 这样的编号引用。同一实例内编号不会重复；跨实例协作时，同时说明站点。

## 查找已有工作

```text
请用 $cfkanban 查看 DemoProject 项目中分配给我、尚未完成或取消的任务，列出编号、状态和优先级。
```

```text
在 DemoProject 项目查找标题含“登录”的任务；先列出结果，不修改内容。
```

需要目标项目的读取权限。Agent 应说明实际查询的项目范围，并返回匹配任务；搜索覆盖标题与编号，不承诺搜索评论或附件全文。多个项目同名时，需要先核对所属工作区。

**在网页中操作：** 打开项目看板，在搜索框输入标题或编号并点击「搜索」。各状态列独立加载，列头数量是已加载数量；滚动列或点击「加载更多」继续查看。

跨项目查找时，点击顶部「工作清单」，明确选择 1–20 个项目，选「全部事项」或「我的任务」，设置状态、负责人或标题/编号筛选，再点击「查看工作」。修改筛选后需要再次查询；初次打开不会自动读取全部项目。

## 创建一个任务

```text
请用 $cfkanban 在 DemoProject 项目创建“修复移动端登录错误”，
描述为：在小屏手机上提交登录表单后出现错误，请复现并修复。
放入 Backlog，优先级设为高，创建后告诉我任务编号。
```

需要该项目的协作者（writer）权限，或该范围的管理员/Owner 权限。创建结果是一项任务及其稳定编号；不会因为创建任务而自动执行描述中的工作。

**在网页中操作：** 项目看板 →「新建事项」→ 填写标题、描述、状态和优先级 →「保存」。描述支持 Markdown。创建时不能直接选「已完成」；实际完成后使用[完成操作](./workflow.md)。

## 编辑标题和描述

```text
把 CFK-123 的标题改为“修复移动端登录超时”，
并在描述末尾补充复现条件：网络切换后首次登录。保留其他内容。
```

需要写入权限。Agent 应只修改指定内容，并核对保存后的结果。将任务内容交给 Agent 执行是另一个请求，例如「请修复 CFK-123 描述的问题」；更新描述本身不会完成开发工作。

**在网页中操作：** 点击任务卡片 →「编辑事项」→ 修改标题或描述 →「保存」。文本不会在输入时自动保存。

## 设置或清除优先级

```text
把 CFK-123 的优先级设为紧急，保留状态和负责人。
```

```text
清除 CFK-123 的优先级。
```

优先级可选「无、低、中、高、紧急」。需要写入权限；调整优先级不改变任务状态或负责人。

**在网页中操作：** 使用看板卡片上的优先级选择器，或在事项详情右侧的「优先级」中选择；选择「无」即可清除。无需打开标题/描述编辑表单。

## 常见问题

- **没有新建或编辑按钮：** 当前项目可能只有只读权限，或者会话已过期；请核对顶部显示的项目、身份和到期时间。
- **提示任务已被别人修改：** 先查看最新内容，再决定是否重新提交。网页会保留未提交草稿，不会自动覆盖他人的修改。
- **保存超时：** 不要连续创建同样的任务。让 Agent 核实原操作，或按网页提供的重试/核实入口继续，确认实际结果后再操作。
- **找不到任务：** 检查项目范围、筛选条件与是否已删除；恢复入口见[协作与附件](./collaboration.md)。
