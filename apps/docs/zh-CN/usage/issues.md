# 查找、创建和编辑任务

任务在网页中称为「事项」，用 `CFK-123` 这样的编号引用。把下面的项目名和任务编号换成自己的，就可以复制给 Agent。

## 查找任务

```text
请查看 DemoProject 中分配给我的未完成任务，列出编号、状态和优先级。
```

```text
在 DemoProject 查找标题含“登录”的任务。
```

需要项目读取权限。搜索支持标题和任务编号；项目同名时，再说明所属工作区。这里的「未完成」包括 Backlog、待办和进行中。

**在网页中：** 打开项目看板，输入标题或编号后按 Enter 或点击「搜索」。选择优先级或标签后，筛选立即生效；搜索框中尚未提交的文字不会顺带生效。各列可继续加载更多；列头数字表示该状态按当前已提交筛选匹配的事项总数，与已加载页数无关。省略号表示正在读取，短横线表示总数不可用，可单独重试；卡片仍可使用。并发更新后的总数可通过重新搜索或刷新核对。

```text
请统计 DemoProject 中优先级为高、标题含“登录”的未删除任务，按状态列出总数。
```

完整版项目页面和本地工作台均可切换「看板 / 列表」，顺序统一为 Backlog → 待办 → 进行中 → 已完成 → 已取消。首次进入列表且无显式状态筛选时，只展开并加载 Backlog；展开其它组时读取该组第一页。各组独立 cursor 和缓存，重复折叠/展开复用已加载页；切到看板时补齐未加载列。刷新及同项目返回保留展开选择，换项目重置为只展开 Backlog；筛选变化重置页，明确状态筛选优先展开该组而不额外读取 Backlog。

「未加载」、加载中、可重试错误和已加载为空分别显示，搜索时仍可发现折叠组。组头数字表示已加载数量，后面的「+」表示还有下一页。父事项在列表中作为层级或上下文出现，不计入子事项所在状态的数量；有多个父事项时显示其他父事项提示。历史循环会标注并停止展开，原关系可核对。两种主题使用一致的 Backlog 灰、待办蓝、进行中橙、已完成绿、已取消红标记，同时保留状态文字和图形。

列表与看板上的圆环和 `5/6` 表示当前有权查看的 6 个未删除直接子事项中，5 个已完成；取消的子事项不算完成，筛选不会缩小这项进度的统计范围。没有子事项或旧版本服务未提供进度时不显示。

点击右上角的翻译图标切换 English / 简体中文，悬停提示会说明当前语言和切换目标。完整版和本地工作台的优先级、按钮、系统提示及五个默认状态标签同步切换；项目自定义状态名称保留原文。名称恰好等于该状态默认英文名时按默认标签处理，API 状态 key 保持原值。切换不会清除尚未保存的表单内容。

跨项目查看时，打开右上角账户菜单 →「工作清单」，选择项目、视图和筛选条件，再点击「查看工作」；更改条件后需再次点击。状态可以选择一个或全部；要合并查看多个指定状态，可直接让 Agent 查询。

## 按优先级、负责人和标签筛选

```text
查看 DemoProject 中分配给我、优先级为高的待办任务。
```

```text
查看 DemoProject 中带 bug 或 performance 标签的未完成任务，先展示前 20 项。
```

```text
查看 DemoProject 中所有未分配的任务，不限状态。
```

```text
在 DemoProject 找带 bug 标签、优先级为高或紧急、未分配且未阻塞的待办任务。
```

多个标签或优先级选择表示匹配其中任意一个；不同条件需要同时满足。例如「高或紧急」加「待办」，会同时找到两种优先级的待办任务。跨项目筛选时，同名标签仍分属不同项目，请选择各目标项目的标签。

结果较多时，可以继续说：

```text
继续查看刚才查询的下一页，保持原来的项目和筛选条件。
```

## 创建任务

```text
请在 DemoProject 创建“修复移动端登录错误”，
描述为：在小屏手机上提交登录表单后出现错误，请复现并修复。
放入 Backlog，优先级设为高，创建后告诉我任务编号。
```

需要协作者或相应管理权限。创建任务只记录工作；要让 Agent 实际处理，可以接着说「请修复 CFK-123 描述的问题」。

**在网页中：**「新建事项」→ 填写标题、描述、状态和优先级 →「保存」。描述支持 Markdown；任务完成后再使用[完成操作](./workflow.md)。

## 编辑内容和优先级

```text
把 CFK-123 的标题改为“修复移动端登录超时”，
在描述末尾补充：网络切换后首次登录。保留其他内容。
```

```text
把 CFK-123 的优先级设为紧急。
```

需要写入权限。优先级可选「无、低、中、高、紧急」；要求清除优先级时，选择「无」。

**在网页中：** 打开事项 →「编辑事项」→ 修改并保存。优先级可直接在看板卡片或详情中选择。

修改状态、优先级或负责人后，看板会等待保存确认，再更新卡片和总数，保留已加载内容和滚动位置。卡片按最近更新时间排序，修改后可能移到列首或不再符合当前筛选。发生冲突时，页面会读取最新事项并保留你想做的修改；保存结果不确定时，先核对已保存内容，再点击「核实保存」检查原操作，不会自动重复提交。

## 遇到问题

- **找不到任务：** 检查项目和筛选条件；有写入权限的成员也可在「项目设置 → 已删除事项」中查找。
- **没有编辑按钮：** 核对项目权限和登录是否到期。
- **提示别人已修改：** 查看最新内容后再保存，避免覆盖他人的更新。
- **保存超时：** 先让 Agent 核实原操作，或使用页面的重试入口，避免重复创建。
- **页面加载失败：** 点击「重试页面」。若部署已更新、重试仍失败，可点击「刷新页面」获取最新版本；先保存已有草稿，刷新会受未保存内容提示保护。
