# 查找、创建和编辑任务

任务在网页中称为「事项」，用 `CFK-123` 这样的编号引用。把下面的项目名和任务编号换成自己的，就可以复制给 Agent。

## 查找任务

```text
请用 $cfkanban 查看 DemoProject 中分配给我的未完成任务，列出编号、状态和优先级。
```

```text
在 DemoProject 查找标题含“登录”的任务，先列出结果，不修改内容。
```

需要项目读取权限。搜索支持标题和任务编号；项目同名时，再说明所属工作区。这里的「未完成」包括 Backlog、待办和进行中。

**在网页中：** 打开项目看板，输入标题或编号后按 Enter 或点击「搜索」。选择优先级或标签后，筛选立即生效；搜索框中尚未提交的文字不会顺带生效。各列可继续加载更多；列头数字表示已加载数量。

跨项目查看时，打开顶部「工作清单」，选择项目、视图和筛选条件，再点击「查看工作」；更改条件后需再次点击。状态可以选择一个或全部；要合并查看多个指定状态，可直接让 Agent 查询。

## 按优先级、负责人和标签筛选

```text
查看 DemoProject 中分配给我、优先级为高的待办任务。
```

```text
查看 DemoProject 中带 bug 或 performance 标签的未完成任务，先展示前 20 项。
```

```text
查看 DemoProject 中所有未分配的任务，不限状态。
```

```text
在 DemoProject 找带 bug 标签、优先级为高或紧急、未分配且未阻塞的待办任务。
先列出，不要领取。
```

多个标签或优先级选择表示匹配其中任意一个；不同条件需要同时满足。例如「高或紧急」加「待办」，会同时找到两种优先级的待办任务。跨项目筛选时，同名标签仍分属不同项目，请选择各目标项目的标签。

结果较多时，可以继续说：

```text
继续查看刚才查询的下一页，保持原来的项目和筛选条件。
```

## 创建任务

```text
请用 $cfkanban 在 DemoProject 创建“修复移动端登录错误”，
描述为：在小屏手机上提交登录表单后出现错误，请复现并修复。
放入 Backlog，优先级设为高，创建后告诉我任务编号。
```

需要协作者或相应管理权限。创建任务只记录工作；要让 Agent 实际处理，可以接着说「请修复 CFK-123 描述的问题」。

**在网页中：**「新建事项」→ 填写标题、描述、状态和优先级 →「保存」。描述支持 Markdown；任务完成后再使用[完成操作](./workflow.md)。

## 编辑内容和优先级

```text
把 CFK-123 的标题改为“修复移动端登录超时”，
在描述末尾补充：网络切换后首次登录。保留其他内容。
```

```text
把 CFK-123 的优先级设为紧急，保留状态和负责人。
```

需要写入权限。优先级可选「无、低、中、高、紧急」；要求清除优先级时，选择「无」。

**在网页中：** 打开事项 →「编辑事项」→ 修改并保存。优先级可直接在看板卡片或详情中选择。

## 遇到问题

- **找不到任务：** 检查项目和筛选条件；有写入权限的成员也可在「已删除事项」中查找。
- **没有编辑按钮：** 核对项目权限和登录是否到期。
- **提示别人已修改：** 查看最新内容后再保存，避免覆盖他人的更新。
- **保存超时：** 先让 Agent 核实原操作，或使用页面的重试入口，避免重复创建。
