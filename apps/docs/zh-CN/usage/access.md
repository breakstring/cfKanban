# 加入与登录

加入项目决定你有权做什么；登录网页决定你通过哪个会话访问。打开公开首页本身不会建立身份或授予项目权限。

## 接受项目邀请

```text
请用 $cfkanban 加入这个项目：<邀请链接>。
核对站点、项目、角色和现有本地身份，说明需要确认的内容后继续。
```

需要有效邀请。首次加入可能需要选择显示名称；已有身份时，Agent 会先核对是否可以复用。

普通邀请授予明确项目的只读者（reader）或协作者（writer）权限，不授予管理员身份。邀请只能兑换一次；既有有效角色不会因接受普通邀请而被覆盖。需要调整既有角色时，联系项目管理员。

**在网页中操作：** 已登录的非 Owner 参与者可以打开普通邀请链接，核对显示的身份、项目与角色，再明确点击「以当前身份接受邀请」。仅打开链接不会接受邀请。当前会话范围不足以覆盖邀请目标时，接受会失败，不会只加入其中部分项目；请使用 Agent 处理。

首次创建身份、身份恢复以及 Owner 设备接入使用专门的 Agent 流程。普通邀请不能用来找回丢失的旧身份。

## 加入公开项目

```text
我想加入 <站点地址> 首页列出的 DemoProject，选择只读者。
请用 $cfkanban 核对公开入口与本地身份，向我说明加入计划。
```

项目需要由 Owner 开启公开加入。访客每次选择一个公开项目，并明确选择只读者或协作者。最直接的做法是使用首页为该项目和角色生成的 Agent 提示词；它包含准确入口和同语言的加入指南。

确认并加入后，你获得该项目的实际访问权限。公开加入不会一次授予整个工作区，项目已满或入口已关闭时可能无法加入。

**在网页中操作：** 在首页公开项目列表选择目标及角色。未登录时复制 Agent 提示词；通过 Passkey 登录后，可以直接执行加入并进入看板。已是协作者时选择只读者不会自动降级；已有只读权限可以在仍开放的公开入口选择协作者。

## 让 Agent 打开已登录网页

```text
请用 $cfkanban 在浏览器中打开 DemoProject 看板。
```

```text
请在 IAB 中打开 CFK-123，使用我当前的 cfKanban 身份。
```

需要可用的本地身份、目标访问权限，以及宿主支持的浏览器交付能力。Agent 核对站点和身份后，通过专用入口打开已登录页面。指定浏览器不可用时，应说明问题而不是悄悄换一个。

网页登录有效期为 8 小时，顶部显示到期时间。到期后重新登录即可；不要把长期凭据复制到页面或聊天。

**在网页中操作：** 已登录页面直接使用当前会话。到期后让 Agent 重新打开，或使用已登记的 Passkey 登录。浏览器交付失败时，让 Agent 检查交付路径；不要因此自行创建第二个身份。

## 使用 Passkey 登录

```text
请用 $cfkanban 打开 DemoProject 的已登录网页，我要为当前身份登记 Passkey。
```

首次登记以及增加 Passkey 都需要从 Agent 打开的会话进入，登记过程由你在浏览器或系统中完成。Agent 不能代替生物识别、安全密钥或系统确认。

**在网页中操作：** 顶部自己的名称 →「我的资料」→「登记通行密钥」。之后打开同一站点首页，点击 Passkey 登录并完成系统提示。参与者登录后选择获授权项目；Owner 进入管理概览。

Passkey 只用于网页身份验证，不增加项目权限，也不能替代 Agent 的本地凭据。它与登记时的域名关联；站点换成另一个域名后，需要让 Agent 在新地址打开页面并重新登记。撤销方式见[个人资料](./profile.md)。

## 切换项目

```text
请用 $cfkanban 查看我能访问的项目，然后打开 Product 工作区中的 DemoProject。
```

**在网页中操作：** 点击顶部工作区/项目名称，在按工作区分组的面板中搜索并选择项目。新参与者 Agent 登录会话和参与者 Passkey 会话可在当前授权项目之间切换；每个项目分别显示当前身份和权限。

看不到预期项目时，让 Agent 核对权限并重新打开。已归档或已撤销访问的项目不能继续使用。

## 常见问题

- **邀请已过期、被撤销或签发者失去授权：** 请有权限的管理员重新邀请；不要反复兑换同一无效链接。
- **Passkey 登录未完成：** 取消、超时、系统不可用或无匹配密钥都可能导致失败；这不等于服务器证明你没有 Passkey。可以改用 Agent 打开网页。
- **接受邀请的结果不确定：** 保持当前页面，用原操作重试；不要刷新后猜测成功。若页面已丢失原操作，重新打开原邀请并核对当前访问。
- **凭据丢失：** 普通参与者联系 Owner 获取身份恢复邀请，恢复原身份；Owner 的恢复路径见[管理](../administration/index.md)与[部署](../deployment/index.md)。
