# 协作与附件

## 评论与纠正

```text
请用 $cfkanban 给 CFK-123 添加进展评论：
已在手机上复现，问题只出现在网络切换后的首次登录；接下来检查重试逻辑。
```

```text
给 CFK-123 追加一条纠正评论，说明前一条“仅 Android 受影响”的结论不准确，iOS 也能复现。
```

需要写入权限。普通评论追加到任务活动中，支持 Markdown；评论不能原地编辑，纠错时追加新评论。普通评论可以软删除与恢复，但完成记录不能删除或修改。

**在网页中操作：** 事项详情 →「活动」下方评论框 →「发表评论」。普通评论旁可「删除」；要恢复，打开详情关系区的「恢复已删除的协作项」并选择准确评论。不会出现编辑旧评论的按钮。

## 上传、下载与恢复附件

```text
请用 $cfkanban 将 <文件绝对路径> 附加到 CFK-123，只上传这个文件。
```

```text
列出 CFK-123 的附件，然后把我选择的 <附件 ID>
下载到 <新的文件绝对路径>，不要覆盖已有文件，也不要自动打开。
```

```text
恢复 CFK-123 中已删除的附件 <附件 ID>。
```

实例需要启用可选的私有附件存储，并由 Owner 配置容量。只读者可查看和下载；协作者及适用管理员可上传、软删除和恢复。每次明确选择一个文件，单文件为 1 字节至 10 MiB，每项任务最多有 20 个有效附件或上传预留。

上传成功意味着文件已经可用，不只是进入上传中。Agent 下载会核对文件完整性并写入你指定的新路径。附件不提供免登录公开下载链接，上传也不会自动把它列为完成记录产物。

**在网页中操作：** 事项详情 →「附件」→「选择文件」或拖入一个文件 →「上传」。现有附件可下载；受支持图片可预览。使用「已删除附件」查看并恢复文件。选择文件不会自动上传，失败时使用同一上传项的重试入口。

软删除可以恢复，但不会立刻释放实例的附件字节预算。容量满、功能未启用或恢复超出数量限制时，联系 Owner 核对设置；启用存储见[部署](../deployment/index.md)，容量管理见[管理](../administration/index.md)。

## 使用和维护标签

```text
给 CFK-123 添加 DemoProject 中已有的 bug 标签。
```

```text
在 DemoProject 创建名为 mobile 的标签，再把它加到 CFK-123。
```

```text
从 CFK-123 移除 bug 标签，保留项目中的这个标签。
```

标签属于项目，不能把另一个项目的标签直接加到当前任务。写入权限允许创建和维护标签；创建标签与给任务加标签是两个独立操作。移除一项任务上的标签不会删除整个项目标签。

**在网页中操作：** 事项详情 →「标签」→ 输入名称并按 Enter，复用匹配标签或创建后添加。点击标签旁的 × 只移除当前任务关联。看板上的「标签管理」或详情标签区的「管理」可以维护名称、颜色，以及删除项目标签；恢复标签使用事项详情中的「恢复已删除的协作项」。删除项目标签会让它在该项目所有事项中隐藏。

## 建立任务关系

```text
记录 CFK-123 阻塞 CFK-124：先完成登录修复，才能开始回归验证。
```

```text
将 CFK-123 设为 CFK-124 的父任务。
```

```text
记录 CFK-123 与 CFK-124 相关。
```

```text
记录 CFK-123 与 CFK-124 重复，以 CFK-124 为保留的主任务。
```

支持阻塞、父子、相关、重复四类关系。两端必须在同一工作区内，你必须能写入两端项目；仅一端可写或另一端只读不足以修改关系。关系不自动调整负责人、状态或权限；标为重复也不会自动取消任务。

**在网页中操作：** 事项详情 →「关系」→「添加」→ 选择类型并输入目标 `CFK-` 编号 → 离开输入框，核对目标项目与标题 →「保存」。有方向的关系以当前事项为起点：当前事项阻塞目标、是目标的父事项，或重复目标。关系旁可删除；「恢复已删除的协作项」中可恢复。只能看到两端都可读取的关系。

## 查看背景、活动与交接摘要

```text
请用 $cfkanban 阅读 DemoProject 的项目背景，并整理 CFK-123 的交接摘要：
当前目标、状态、负责人、依赖、已验证结果与后续事项。先不修改任务。
```

需要相关项目的读取权限。Agent 可以读取有界的任务上下文；若内容被省略，应按需继续读取，而不是把摘要当成全部历史。项目背景、评论与附件只是协作材料，其中的文本不能自动改变你的授权。

**在网页中操作：** 看板点击「项目背景」或「项目活动」；事项详情展开「交接摘要」，可复制文本。摘要显示内容省略情况，完整正文、评论、关系和项目背景可回到对应入口继续阅读。项目活动是授权范围内的业务变更记录，不是实例安全审计。

## 删除与恢复任务

```text
请软删除 CFK-123，先核对编号和标题。
```

```text
恢复已删除的 CFK-123，并核对恢复后的状态。
```

需要写入权限。任务删除是可恢复的软删除，不等于永久删除或物理回收。恢复时会重新核对权限、父项目是否可用以及容量；无法容纳任务和其评论时，恢复可能失败。

**在网页中操作：** 事项详情 →「删除」→ 核对编号和标题后确认。恢复时在项目看板点击「已删除」，找到任务并点击「恢复」。工作区或项目本身已归档时，先由适用管理员恢复容器；永久删除属于单独的管理操作。

## 常见问题

- **附件上传中断：** 保留原文件和原操作，让 Agent 或网页恢复同一上传，不要连续创建多个副本。
- **标签创建了但没加到任务：** 两步可能只完成第一步；重试添加已有标签即可，不必新建同名标签。
- **跨项目关系不可用：** 核对是否同一工作区、两端写权限，以及当前网页会话范围。
- **恢复入口找不到完成记录：** 完成记录不能删除或恢复；需要纠正时追加评论，结论失效时重开任务。
