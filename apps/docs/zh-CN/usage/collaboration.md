# 协作与附件

## 评论与纠正

```text
请给 CFK-123 添加进展评论：
已在手机上复现，问题只出现在网络切换后的首次登录；接下来检查重试逻辑。
```

```text
给 CFK-123 追加一条纠正评论，说明前一条“仅 Android 受影响”的结论不准确，iOS 也能复现。
```

需要写入权限。普通评论追加到任务活动中，支持 Markdown；评论不能原地编辑，纠错时追加新评论。普通评论可以软删除与恢复，但完成记录不能删除或修改。

**在网页中操作：** 事项详情 →「活动」下方评论框 →「发表评论」。普通评论旁可「删除」；要恢复，打开详情关系区的「恢复已删除的协作项」并选择准确评论。不会出现编辑旧评论的按钮。

## 上传、下载与恢复附件

```text
请将 <文件绝对路径> 附加到 CFK-123。
```

```text
把 CFK-123 的附件 <附件 ID> 下载到 <新的文件绝对路径>。
```

```text
恢复 CFK-123 中已删除的附件 <附件 ID>。
```

先由 Owner 启用附件并配置容量。只读者可查看和下载；有写入权限的人可上传、删除和恢复。每次上传一个非空文件，最大 10 MiB，每项任务最多 20 个有效附件（包括正在上传的文件）。

附件需要登录并具有项目访问权限才能下载。Agent 下载到新文件，不会覆盖已有文件或自动打开。若要把附件作为完成产物，请在完成任务时明确说明。

**在网页中操作：** 事项详情 →「附件」→「选择文件」或拖入一个文件 →「上传」。现有附件可下载；受支持图片可预览。使用「已删除附件」查看并恢复文件。选择文件不会自动上传，失败时使用同一上传项的重试入口。

软删除可以恢复，但不会立刻释放实例的附件字节预算。容量满、功能未启用或恢复超出数量限制时，联系 Owner 核对设置；启用存储见[部署](../deployment/index.md)，容量管理见[管理](../administration/index.md)。

## 使用和维护标签

```text
给 CFK-123 添加 DemoProject 中已有的 bug 标签。
```

```text
在 DemoProject 创建名为 mobile 的标签，再把它加到 CFK-123。
```

```text
从 CFK-123 移除 bug 标签，保留项目中的这个标签。
```

标签属于项目，需要写入权限才能维护。移除任务上的标签只影响该任务；删除项目标签会影响整个项目。

**在网页中操作：** 事项详情 →「标签」→ 输入名称并按 Enter，复用匹配标签或创建后添加。点击标签旁的 × 只移除当前任务关联。看板上的「项目设置 → 标签」或详情标签区的「管理」可以维护名称、颜色，以及删除项目标签；恢复标签使用事项详情中的「恢复已删除的协作项」。删除项目标签会让它在该项目所有事项中隐藏。

## 建立任务关系

```text
记录 CFK-123 阻塞 CFK-124：先完成登录修复，才能开始回归验证。
```

```text
将 CFK-123 设为 CFK-124 的父任务。
```

```text
记录 CFK-123 与 CFK-124 相关。
```

```text
记录 CFK-123 与 CFK-124 重复，以 CFK-124 为保留的主任务。
```

支持阻塞、父子、相关、重复四类关系。两端必须在同一工作区内，你必须能写入两端项目；仅一端可写或另一端只读不足以修改关系。关系不自动调整负责人、状态或权限；标为重复也不会自动取消任务。

**在网页中操作：** 事项详情 →「关系」→「添加」→ 选择类型并输入目标 `CFK-` 编号 → 离开输入框，核对目标项目与标题 →「保存」。有方向的关系以当前事项为起点：当前事项阻塞目标、以目标为父事项，或重复目标。关系旁可删除；「恢复已删除的协作项」中可恢复。只能看到两端都可读取的关系。

新增或恢复父子关系如果会形成循环，服务会拒绝，请选择其他父事项；父子图过大而无法安全校验时，也会拒绝，请先简化结构。历史关系仍可读取和核对。普通「相关」关系可以形成环，因为它不表示任务层级。

## 查看项目信息并复制任务内容

```text
请概括 DemoProject 的项目说明，以及 CFK-123 的目标、进展、负责人、依赖和后续事项。
```

需要相关项目的读取权限。把任务编号或链接交给 Agent，即可查询最新内容和相关历史，无需先打开看板。

**在网页中操作：** 项目描述直接显示在看板标题下；从「项目设置 → 项目活动」查看项目事件，最新变更在前。「加载更早活动」继续查看较早历史，「刷新」开始包含新变更的列表。返回看板时保留已提交的筛选条件。详情右上角的「复制」菜单可选择 CFK 编号或线上 Issue URL，正文与每条评论旁的小按钮可复制原始 Markdown。剪贴板访问受限时，使用显示的纯文本手动复制。

```text
查看 DemoProject 最近的活动，列出谁修改了什么。
```

## 删除与恢复任务

```text
请软删除 CFK-123，先核对编号和标题。
```

```text
恢复已删除的 CFK-123。
```

需要写入权限。任务删除是可恢复的软删除，不等于永久删除或物理回收。恢复时会重新核对权限、父项目是否可用以及容量；无法容纳任务和其评论时，恢复可能失败。

**在网页中操作：** 事项详情 →「删除」→ 核对后确认。从看板进入「项目设置 → 已删除事项」，找到任务并点击「恢复」；此标签仅对有写入权限的成员显示。若项目或工作区已归档，先由管理员恢复。

## 常见问题

- **附件上传中断：** 保留原文件和原操作，让 Agent 或网页恢复同一上传，不要连续创建多个副本。
- **标签创建了但没加到任务：** 两步可能只完成第一步；重试添加已有标签即可，不必新建同名标签。
- **跨项目关系不可用：** 核对是否同一工作区、两端写权限，以及当前网页会话范围。
- **恢复入口找不到完成记录：** 完成记录不能删除或恢复；需要纠正时追加评论，结论失效时重开任务。
