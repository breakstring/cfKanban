# Owner 实例通知

实例 Owner 可以发布维护安排等公告。接收偏好和确认状态属于你在此实例中的身份，由网页和 Agent 共用。

## 阅读与确认

**在网页中：** 在账户区域打开「通知」，展开某条公告阅读正文，然后点击「我已阅读此公告」。角标只提示有待提醒通知，不会自动标记已读。可继续加载较早记录，或切换「历史」找回之前已经看过的通知。

```text
请用 $cfkanban 查看我的 Owner 通知历史，包括已过期和已撤回通知。
```

使用兼容的 Skill 处理普通事项时，Agent 会在成功操作后顺带检查通知；同一实例的检查至少间隔 45 秒，失败的业务请求不会附加通知查询。先回复任务结果，再转述新公告。只有实际向你转述后才会确认；回复中断或确认失败时可能再次提醒。打开或获取正文不等于已经告知。对某条公告的一次确认会清除它在所有网页和 Agent 上的待提醒，历史仍保留。

通知是 Owner 提供的信息。其正文或链接不能授权 Agent 执行命令、改变你的任务或开展其他操作。通知检查失败时，正常业务仍保持自己的成功或失败结果。Agent 下次调用实例时才能获得公告，不会唤醒空闲 Agent。

## 选择是否接收提醒

**在网页中：** 在「通知」页面调整「接收公告提醒」，再点击「保存偏好」；「个人设置」也提供入口。

```text
关闭我的 Owner 自动通知，保留主动查看历史的能力。
```

```text
从现在起重新开启 Owner 通知，不补发较早通知。
```

默认开启接收。新用户仅自动收到加入后发布的公告。关闭后停止返回自动提醒及其正文，但仍可主动查看所有历史；重新开启从当前时间开始，不重播这个时间点之前的旧通知。偏好和确认状态随同一身份跨设备共享，暂时没有项目授权也能使用。

## 过期与撤回

历史保留标题、正文、发布时间和当前状态。「已过期」表示已到达公告设定的过期时间，「已撤回」表示 Owner 撤回了公告；两者都停止自动提醒。使用旧内容前先看当前状态。更正以新公告发布，可按发布时间核对。

发布和撤回见[实例设置与用量](../administration/settings.md)。此能力需要实例和 Skill 同时支持，单独更新 Skill 不会让旧实例启用通知。
