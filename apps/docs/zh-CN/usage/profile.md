# 个人资料与目录关联

## 查看或修改自己的名称

```text
请用 $cfkanban 查看我当前的显示名称和身份 ID，不展示凭据。
```

```text
请将我的显示名称改为 Lin_Design。
```

任何已登录身份都可以查看和修改自己的显示名称，包括只读者。修改后，身份 ID、项目访问权限、任务指派和历史记录仍属于同一个人。

名称须在站点内唯一，长度为 1–128 个字符。可使用文字、数字及 `_`、`-`、`·`，不含空格或 Emoji；系统保留名称不可使用。名称不可用时，选择另一个即可。

**在网页中操作：** 打开右上角账户菜单 →「个人设置」→ 在「身份资料」中修改显示名称 →「保存」。页面同时展示不可编辑的身份 ID。

## 保存主题配色

```text
请用 $cfkanban 查看我已保存的主题，再将它改为静蓝。
保留我的显示名称，并读回确认主题已保存。
```

可选择默认的「暖橙」或「静蓝」。两种主题使用相同布局、控件和交互，只改变配色。

**在网页中操作：** 打开账户菜单 →「个人设置」→ 选择主题 →「保存主题」。保存后，所有已登录页面（包括管理页面）都使用该配色。偏好保存在这个站点的当前身份中，重新登录或更换浏览器后仍可使用；不会修改其他人的主题。

任何已登录身份都可保存自己的主题，包括只读者。若同时发生其他资料修改而提示版本冲突，刷新资料并核对所选主题后再保存。Agent 使用同一个个人资料 API 读取和保存偏好。

## Owner 实例通知

「个人设置」提供「通知」入口，可调整接收偏好、阅读待提醒和查询历史。关闭后仍可主动查看历史，重新开启从当前时间开始。网页与 Agent 确认方式见 [Owner 实例通知](./notifications.md)。

## 查看和撤销自己的 Passkey

```text
请用 $cfkanban 列出我为这个实例登记的 Passkey，
显示登记时间、最近使用时间和状态，不撤销任何项。
```

```text
撤销我已确认的 Passkey <Passkey ID>。
我知道由它建立的浏览器会话将立即失效。
```

先从列表中核对要撤销的记录和最近使用时间。

撤销会使该 Passkey 建立的所有网页会话立即失效；其他 Passkey、Agent 凭据和项目权限不受影响。如果当前网页会话来自被撤销项，你也会退出该会话。

**在网页中操作：** 打开账户菜单 →「个人设置」→「通行密钥」中查看记录，对准确的一项点击「撤销」。登记新 Passkey 仍必须从 Agent 打开的会话发起，再由你完成浏览器/系统交互，见[加入与登录](./access.md)。

## 会话到期与未提交文本

支持续期的实例对 Agent 与 Passkey 登录都采用前台活动续期：续期后再有效 8 小时，每 30 分钟最多实际延长一次，从会话最初创建起最多 7 天。续期保留原身份、来源与范围；后台轮询、刷新和焦点校验不会延长期限。登录来源被撤销或会话到期后，需要重新登录。

如果原页面提供业务文本草稿的恢复入口，请保持它打开。草稿只在该页面内存中保留，刷新或关闭会丢失，主动退出会清除。以同一身份重新登录后，明确恢复或复制文本，检查后再提交；不会自动重放写入。凭据、登录或邀请链接、附件文件不在恢复范围内。续期支持与恢复步骤见[加入与登录](./access.md)。

## 将工作目录关联到项目

```text
请用 $cfkanban 查看当前目录关联了哪些项目。
```

```text
请用 $cfkanban 将当前目录关联到 Product 工作区的 DemoProject，
保留已有的其他项目关联。
```

```text
把 Mobile 项目也关联到当前目录，供后续查找任务时使用。
```

目录关联适合经常从同一仓库或文件夹处理固定项目。在没有关联的 Git 仓库中，Agent 可以提醒一次，在工作树根目录创建 `.cfkanban-scope.json`；仓库子目录也使用同一个根目录。只有你接受建议或主动要求关联后，才核对项目并保存，保留已有的其他关联。非 Git 目录仅在你要求时处理关联，不主动提醒创建文件。拒绝不会阻塞当前工作，也不会重复提醒。

以后可以省略项目名；本次请求明确指定的项目仍优先。关联不会授予新权限。

**网页说明：** 目录关联由 Agent 在当前执行环境中维护，没有网页编辑入口。网页项目切换只是选择当前浏览器查看的项目，不会修改电脑目录设置。加入项目也不会自动创建目录关联。

## 常见问题

- **当前目录没有关联：** 可以继续按项目名工作，不必先配置。直接查询 `CFK-123` 也不需要关联。
- **换了电脑后没有原关联或身份：** 目录配置与私有身份是两类不同状态；复制项目标识不会带来访问权限。请让 Agent 核对本机可用身份，需要时走正确的恢复或设备接入路径。
- **名称改了但历史还在：** 这是预期行为。名称只是展示，稳定身份不会改变。
- **通过 Passkey 登录后看不到登记按钮：** 新登记要求 Agent 打开的会话；让 Agent 重新打开正确站点后再登记。
