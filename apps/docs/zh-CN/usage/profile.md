# 个人资料与目录关联

## 查看或修改自己的名称

```text
请用 $cfkanban 查看我当前的显示名称和身份 ID，不展示凭据。
```

```text
请将我的显示名称改为 Lin_Design。
```

任何已登录身份都可以查看和修改自己的显示名称，包括只读者。修改后，身份 ID、项目访问权限、任务指派和历史记录仍属于同一个人。

名称在实例内唯一，大小写及全角字符等兼容形式按规范化结果判重。名称为 1–128 个字符，允许文字、数字、组合标记及 `_`、`-`、`·`；不能包含空格、不可见字符、Emoji 或其他标点。`admin`、`administrator`、`owner`、`system`、`管理员`、`所有者`、`系统` 是保留名称。名称冲突时由你另选一个，Agent 不应擅自加后缀。

**在网页中操作：** 点击顶部自己的名称 →「我的资料」→ 在「身份资料」中修改显示名称 →「保存」。页面同时展示不可编辑的身份 ID。

## 查看和撤销自己的 Passkey

```text
请用 $cfkanban 列出我为这个实例登记的 Passkey，
显示登记时间、最近使用时间和状态，不撤销任何项。
```

```text
撤销我已确认的 Passkey <Passkey ID>。
我知道由它建立的浏览器会话将立即失效。
```

先从本人登记列表选择准确记录。列表反映服务器登记情况，不是当前电脑中私钥或硬件的清单，也不能保证某个设备现在可用。Agent 可以读取本人的非秘密记录并撤销指定项。

撤销会使该 Passkey 建立的所有网页会话立即失效；其他 Passkey、Agent 凭据和项目权限不受影响。如果当前网页会话来自被撤销项，你也会退出该会话。

**在网页中操作：**「我的资料」→「通行密钥」中查看记录，对准确的一项点击「撤销」。登记新 Passkey 仍必须从 Agent 打开的会话发起，再由你完成浏览器/系统交互，见[加入与登录](./access.md)。

## 将工作目录关联到项目

```text
请用 $cfkanban 查看当前目录关联了哪些项目。
```

```text
请用 $cfkanban 将当前目录关联到 Product 工作区的 DemoProject，
保留已有的其他项目关联。
```

```text
把 Mobile 项目也关联到当前目录，供后续查找任务时使用。
```

目录关联适合长期从某个仓库或普通文件夹处理固定项目的场景。需要有权访问目标项目，并明确允许 Agent 保存这项本地设置。Agent 核对真实项目后创建或合并 `.cfkanban-scope.json`，文件只保存非秘密项目标识；已有关联应保留。

后续查找会优先使用你本次明确指定的项目，其次使用目录推荐范围。没有两者时，Agent 应说明实际采用的获授权范围。目录关联不是权限控制，不会授予项目访问，也不会阻止你明确查询其他有权访问的事项。

**网页说明：** 目录关联由 Agent 在当前执行环境中维护，没有网页编辑入口。网页项目切换只是选择当前浏览器查看的项目，不会修改电脑目录设置。加入项目也不会自动创建目录关联。

## 常见问题

- **当前目录没有关联：** 可以继续按项目名工作，不必先配置。直接查询 `CFK-123` 也不需要关联。
- **换了电脑后没有原关联或身份：** 目录配置与私有身份是两类不同状态；复制项目标识不会带来访问权限。请让 Agent 核对本机可用身份，需要时走正确的恢复或设备接入路径。
- **名称改了但历史还在：** 这是预期行为。名称只是展示，稳定身份不会改变。
- **通过 Passkey 登录后看不到登记按钮：** 新登记要求 Agent 打开的会话；让 Agent 重新打开正确站点后再登记。
