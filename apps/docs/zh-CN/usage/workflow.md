# 工作流与负责人

## 推进或取消工作

```text
请将 CFK-123 从 Backlog 移到待办。
```

```text
我已开始处理 CFK-123，把它改为进行中。
```

```text
将 CFK-123 设为已取消，因为这个需求已经不再需要。
另加一条评论保留这个原因。
```

需要写入权限。更新状态记录进度，不会自动调整负责人或执行任务描述中的工作。

**在网页中操作：** 拖动卡片到目标列，或使用卡片/详情的状态选择器。选择后等待保存结果；无需拖拽也能完成同样的状态操作。「已完成」遵循下面的完成流程。

## 领取、指派与取消指派

```text
把 CFK-123 分配给我。
```

```text
把 CFK-123 分配给 Lin_Design。
```

```text
清除 CFK-123 的负责人。
```

你需要写入权限，负责人也必须有该项目的写入权限。找不到某个人时，先请管理员核对其权限。

可选择 Owner、管理当前项目的工作区或项目 Admin，以及 Writer；仅有 Reader 权限的人不可分配。同一身份的多个角色和凭据合并为一个人。

指派成功后只改变负责人，不会自动进入「进行中」，也不会锁住任务。负责人后来失去写入资格时，历史指派保留并可能显示「需重指派」，不会悄悄换人。

**在网页中操作：** 点击看板卡片底部的负责人，或打开事项详情 →「负责人」下拉框。选择项目可指派人员或「未分配」，服务端确认后保存，保持当前状态。候选按需加载，可用「加载更多」查看后续页；只读者仅看到当前负责人。没有某个人时，先请管理员核对其项目权限。

## 查看待领取或需重指派的任务

```text
请列出 DemoProject 中未分配、没有被阻塞的待办任务。
```

```text
查看 DemoProject 中需要重新指派的待办任务。
```

读取权限即可查看；领取需要写入权限。队列只包含待办，默认排除阻塞任务，按优先级和创建先后排序。要查看全部未完成工作，应另外包含 Backlog 和进行中。

**在网页中操作：** 右上角账户菜单 →「工作清单」→ 选择项目 →「视图」选择「待领取」或「需重指派」→「查看工作」。查看队列不会领取任务；打开具体事项后再设置负责人。

## 完成并记录结果

```text
请将 CFK-123 标为完成，使用以下实际结果记录：
结果：<已经完成的内容>
验证：<实际执行的检查及结果>
产物：<链接、提交或文件路径>
后续事项：<尚需跟进的内容；没有则写无>
```

需要写入权限。完成后会保存不可编辑、不可删除的记录；说明可以留空，也可填写实际结果、验证、产物和后续事项。只记录实际完成和核验的内容。

**在网页中操作：** 事项详情 →「完成事项」→ 填写可选说明 → 确认。详情的状态选择器选「已完成」也会打开同一弹窗。当前网页说明框是文本输入；可以写清结果与验证，需要分别填写结构化验证、产物及后续列表时使用 Agent。

看板上直接把卡片拖到 Done，或用卡片状态选择器选 Done，会直接完成并生成空说明记录。希望记录说明时，先进入详情。空说明显示「已完成」，不会自动生成测试结论。

## 重新打开任务

```text
问题复现了，请把 CFK-123 重新打开为待办。
```

需要写入权限。Done 或 Canceled 可以返回非完成状态，先前完成记录继续保留。再次完成会追加新记录，不覆盖上一轮。完成记录写错时，可以追加纠正评论；完成结论失效时，应重新打开并在处理后再次完成。

**在网页中操作：** 已完成事项右侧点击「重新打开到待办」，或在状态选择器中选择适当阶段。也可以从已完成/已取消列把卡片移到目标列。

## 报告和解除阻塞

```text
标记 CFK-123 被阻塞，原因是：等待测试环境恢复。
```

```text
测试环境已恢复，请清除 CFK-123 的人工阻塞原因。
```

人工阻塞需要写入权限，独立于工作状态；任务可以仍在进行中但无法继续。外部条件恢复后要明确清除人工原因。也可以建立「CFK-123 阻塞 CFK-124」的[任务关系](./collaboration.md)；前置任务未 Done 时，该关系会贡献阻塞原因。完成前置任务或移除关系会消除该原因，其他阻塞原因仍可能存在。

**网页差异：** 当前 Web 暂不展示人工阻塞标识、原因、筛选或标记/解除按钮，请使用 Agent。关系区仍支持依赖关系；普通看板仍展示阻塞任务，候选工作队列默认排除它们。清除人工原因不会删除任务依赖关系。

## 常见问题

- **“我的任务”和“待领取”结果不同：** 前者按负责人查普通任务，可包含任意状态；后者是可开始的未分配 Todo 候选。
- **完成后仍有负责人或阻塞信息：** 完成不会自动清理这些独立字段，需要时明确调整。
- **取消前置任务后依然阻塞：** 依赖以是否 Done 判断；若该依赖不再需要，请明确移除关系。
- **无法指派给只读者：** 指派不授予写权限，先由管理员处理权限或选择当前有资格的负责人。
