# 公开加入与配额

公开加入让访客从实例首页选择项目，并选择只读或协作权限加入。它适合愿意接纳未知参与者的项目，由 Owner 决定是否开启。

## 先了解公开范围

```text
请用 $cfkanban-admin 检查 <项目名称> 的公开加入状态、当前用量和资源限额。
说明开启后的权限与影响，先不要修改。
```

需要 Owner 的实例管理权限。Agent 会说明项目是否允许公开加入、访客能看到的摘要，以及任务、评论、非 Owner 成员三项配额和用量。内部项目说明不会自动公开。

访客可选择只读或协作权限。协作者能修改和删除项目内容；公开加入无需逐人审批，开启前请确认适合接受陌生人参与。

## 开启或调整

```text
请用 $cfkanban-admin 为 <项目名称> 开启公开加入。
公开摘要为“<适合所有访客阅读的说明>”。
活跃任务上限设为 50，评论上限设为 500，非 Owner 成员上限设为 50。
先核对当前用量并说明影响，再按此范围执行。
```

这里的 `50 / 500 / 50` 是示例选择，不是自动套用的默认值。开启时必须明确三项上限。设置可以低于当前用量：既有内容和成员保留，继续增加相应计数的操作会被阻止。

**在网页中：** Owner 进入「管理中心 → 工作区与项目」，打开对应项目行的更多操作菜单 →「公开加入」。核对风险说明、公开摘要、当前用量与三项配额，确认后开启或更新策略。

人数统计包括普通成员、直接项目管理员和继承的工作区管理员；同一非 Owner 身份只计一次。软删除内容或撤销相应成员访问可以释放活跃配额，恢复或重新授权会再次占用。配额在该项目开启公开加入期间强制生效。

## 关闭公开加入

```text
请用 $cfkanban-admin 关闭 <项目名称> 的公开加入，并核对关闭结果。
保留现有成员权限。
```

**在网页中：** 打开同一个「公开加入」弹窗，选择「关闭」。预期不再接受新的自助加入，并停止该项目的公开加入配额强制；已经取得的成员权限不自动撤销。要移除现有访问，请另行 [管理成员](./members.md)。

## 常见问题

**撤销成员后，对方为什么又能加入？** 公开加入没有针对该人的禁止再加入名单。项目保持公开时，对方可以再次自助加入。

**归档后恢复会重新公开吗？** 会恢复此前仍开启的策略。恢复前会显示这些项目与影响，详见 [归档与恢复](./cleanup.md)。

**配额没满，为什么仍收到请求过多？** 项目活跃资源配额与 Worker 的访问频率限制是两套机制。Owner 可在「用量与配额」查看和调整频率配置，详见[访问频率限制](../deployment/optional.md)。不要把限流当作成员或任务配额问题。
