# 归档、恢复与永久清理

归档停止容器访问并保留内容和权限。永久删除是单独、不可恢复的操作，需要先查看准确影响。

## 归档旧项目或工作区

```text
请用 $cfkanban-admin 归档 Product 工作区中的 OldProject 项目，并核对结果。
```

Owner 可以归档工作区或项目；工作区管理员可归档其有效工作区内的项目；项目管理员不能归档项目。归档工作区会暂停所有子项目的数据访问和继承管理权限，归档项目会暂停该项目访问。

**在网页中：** Owner 在「管理中心 → 工作区与项目」点击准确目标的「归档」。工作区管理员在工作区的项目列表，或从看板进入「项目设置 → 项目管理」使用归档入口。预期内容和既有权限保留，普通列表不再显示归档容器。

## 恢复访问

```text
请用 $cfkanban-admin 检查恢复 OldProject 会重新开启哪些访问和公开加入策略；
核对准确项目后恢复它。
```

恢复权限与归档相同。所属工作区已归档时，先由 Owner 恢复工作区。此前仍开启的公开加入策略会重新生效；已关闭的策略继续关闭。Agent 或页面会在恢复前说明公开影响。

**在网页中：** Owner 打开「管理中心 → 已归档内容」，展开所属工作区，对项目或工作区选择「恢复」。工作区管理员在工作区管理「项目 → 显示归档项目」中定位项目，再进入其管理页恢复。

恢复后保留原内容和权限。单条任务或评论的删除恢复见[使用](../usage/index.md)。

## 预览永久删除

```text
请用 $cfkanban-admin 预览永久删除已归档 OldProject 的影响，暂不执行。
列出准确目标、内容数量、跨项目关系，以及会失效的邀请和会话。
```

仅 Owner 可以永久删除已归档项目，或已归档且没有尚未永久删除项目的工作区。非空工作区要逐个处理其项目，没有批量永久删除。

预览会说明任务、普通评论和完成记录、标签、关系、授权、项目会话及相关历史的清理范围。包含该项目的未兑换邀请会失效，包括共享多项目邀请；其他项目已经取得的成员权限保留。附件对象回收遵循附件清理流程，不能承诺即时释放预算或平台容量。

## 确认不可逆清理

```text
我确认永久删除刚才预览的 <准确已归档目标>，理解该操作不可恢复。
请用 $cfkanban-admin 重新核对预览一致性，执行并读回结果。
```

归档授权不等于永久删除授权。预览目标或内容发生变化时，要重新核对影响。

**在网页中：** 「管理中心 → 已归档内容 → 永久删除」。检查准确名称、所属工作区、可展开的完整 ID 和影响计数，输入完整显示名称后确认。完成后目标从归档列表移除，不能再恢复。

永久删除不会清除 Cloudflare 备份或他人已保存的副本，也不保证存储用量立即下降。

## 失败或结果不确定

结果不确定时，使用「重试同一请求」核实。永久删除不可在应用中撤销，请勿另发一次删除来猜测结果。
