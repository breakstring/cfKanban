# 设备与身份恢复

你可以在多台可信设备上使用同一个 Owner 身份，每个执行环境保存自己的凭据。添加设备不会复制长期凭据，也不会自动授予 Cloudflare 部署权限。

## 添加 Owner 设备

在新电脑的 Agent 中说：

```text
请用 $cfkanban-admin 将这台电脑接入 <实例地址>，使用同一个 Owner 身份。
设备名称为“<设备名称>”。生成可交给现有 Owner 设备或管理网页批准的配对请求。
```

新电脑生成配对请求后，在已有 Owner 设备或管理网页核对站点、Owner 身份、设备名和到期时间，确认指纹与新电脑上的请求一致后再批准。请求最多有效一小时；不要传递长期凭据。

**在网页中：** 以 Owner 打开「管理中心 → 成员与权限 → Owner 设备」，粘贴非秘密配对请求，核对预览并明确批准。浏览器不会接收或保存新设备的长期凭据。批准后回到新设备：

```text
请用 $cfkanban-admin 完成刚才的 Owner 设备接入验证，并核对当前身份。
```

网页批准后，还要回到新电脑完成验证才能使用。中断时继续原请求即可。

## 查看、改名或撤销设备

```text
请用 $cfkanban-admin 列出我的 Owner 设备，并将 <准确设备> 改名为“工作电脑”。
```

```text
请用 $cfkanban-admin 撤销 <准确设备> 的 Owner 访问，先核对设备标识和影响。
```

设备可能同名，撤销前请核对准确记录。改名只改变名称，不影响访问权限。

**在网页中：**「Owner 设备」列表支持改名和撤销其他设备。不能撤销当前登录所用的设备凭据或最后一份有效 Owner 凭据。

撤销使该设备凭据及其派生网页登录访问失效；其他设备和独立通行密钥保留。设备表示执行环境，不是硬件绑定。

## 这台电脑已有另一身份

```text
请用 $cfkanban-admin 将这台电脑切换为 <实例地址> 的 Owner，保留当前身份以便恢复。
```

需要明确选择替换本地当前身份，并使用支持身份切换的技能。批准和验证完成前，旧身份仍可用；切换成功后，旧身份安全保存在本机，便于以后切回。原身份及其权限不会升级、合并或删除。

```text
请用 $cfkanban-admin 恢复这台电脑在 <实例地址> 之前保存的身份。
```

Agent 核验保存的旧身份后切回，并保留 Owner 身份以便再次切换。**网页没有本地身份切换入口**；发生冲突时让 Agent 检查，不要手动删除私有文件。

## 轮换当前 Owner 凭据

```text
请用 $cfkanban-admin 安全轮换当前 Owner 凭据，并验证新的本地凭据可用。
```

需要当前仍有效的 Owner 凭据。Agent 安全替换当前设备凭据，其他设备保留。此操作通过 Agent 完成，网页没有对应按钮。

## 恢复参与者身份

```text
请用 $cfkanban-admin 为 <参与者名称> 检查身份恢复选项。
先说明普通轮换和完全恢复各会撤销哪些访问，核对准确身份后再创建恢复邀请。
```

仅 Owner 可以签发恢复邀请，有效一小时。普通轮换要求对方仍能使用旧身份，只替换本次凭据；完全恢复不要求旧凭据，会撤销该身份全部旧 Agent 凭据。被撤销凭据建立的网页登录也会失效；两种方式都保留任务、权限、历史和独立 Passkey。

**在网页中：** Owner 在「成员与权限」查找参与者并打开详情，核对身份标识与恢复模式，确认保留的权限和将撤销的访问后创建恢复邀请。Agent 操作也会核对准确身份，不只凭显示名称判断。邀请安全交付给本人，接收人在 Agent 中完成恢复；浏览器不保存替代长期凭据。Owner 也可在参与者详情查看并撤销其特定凭据或通行密钥，先核对相应登录失效影响。

## Owner 全部凭据丢失

仍有有效 Owner 管理网页会话，且服务端保留至少一份未撤销 API 凭据记录时，可按本页流程批准新设备。这不会自动撤销所有旧凭据。

无法使用上述路径，或需要统一撤销全部旧凭据时，使用具有 Cloudflare 控制权限的 [Owner 全失恢复](../deployment/recovery.md)。普通邀请、参与者恢复或重新部署空实例都不能替代它。
