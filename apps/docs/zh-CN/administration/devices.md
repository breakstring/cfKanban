# 设备与身份恢复

Owner 多设备用于在多个可信执行环境管理同一实例，每个环境保存独立凭据。它不复制长期秘密，也不自动授予 Cloudflare 部署权限。

## 添加 Owner 设备

在新电脑的 Agent 中说：

```text
请用 $cfkanban-admin 将这台电脑接入 <实例地址>，使用同一个 Owner 身份。
设备名称为“<设备名称>”。生成可交给现有 Owner 设备或管理网页批准的配对请求。
```

需要已部署 Service 支持多设备，以及新环境的私有持久存储。新设备先生成本地私有凭据，只输出不含秘密的配对请求。已有 Owner 设备或 Owner 完整管理会话核对实例、Owner、设备名、fingerprint 与到期时间后批准。配对请求最长有效一小时。

**在网页中：** 以 Owner 打开「管理中心 → 成员与权限 → Owner 设备」，粘贴非秘密配对请求，核对预览并明确批准。浏览器不会接收或保存新设备的长期凭据。批准后回到新设备：

```text
请用 $cfkanban-admin 完成刚才的 Owner 设备接入验证，并核对当前身份。
```

只有新设备完成实例和凭据身份验证，接入才算完成。网页的批准成功不等于本地已经切换。中断后续用同一个请求，不能为了重试生成第二份凭据。

## 查看、改名或撤销设备

```text
请用 $cfkanban-admin 列出我的 Owner 设备，并将 <准确设备> 改名为“工作电脑”。
```

```text
请用 $cfkanban-admin 撤销 <准确设备> 的 Owner 访问，先核对设备标识和影响。
```

设备名称可能重复或为空，操作前由 Agent 核对准确凭据 ID 与 fingerprint。改名只改变显示名称，不改变秘密、身份或权限；名称长度为去除首尾空白后 1–80 个 Unicode 字符。

**在网页中：** 同一「Owner 设备」列表支持加载更多、补名/改名，以及确认撤销另一设备。不能撤销当前认证来源或最后一份有效 Owner API 凭据。最多保留 100 份有效 Owner API 凭据；“有效”表示服务端未撤销，不证明本地秘密文件仍存在。

撤销使该设备凭据及其派生网页登录访问失效；其他设备和独立通行密钥保留。设备表示执行环境，不是硬件绑定。

## 这台电脑已有另一身份

```text
请用 $cfkanban-admin 将这台电脑切换为 <实例地址> 的 Owner，保留当前身份以便恢复。
```

需要明确选择替换本地当前身份，并使用支持身份切换的技能。批准和验证前旧身份仍可用；成功后旧身份保存在私有恢复槽。原身份及其权限不会升级、合并或删除。

```text
请用 $cfkanban-admin 恢复这台电脑在 <实例地址> 之前保存的身份。
```

Agent 先核验旧凭据仍有效，再切回，同时保留 Owner 凭据。已有不同恢复槽、身份冲突或切换中断时先恢复原操作，不能手动清空本地文件绕过。**Web 没有本地身份槽管理入口**；此步骤发生在保存 Agent 凭据的环境中。

## 轮换当前 Owner 凭据

```text
请用 $cfkanban-admin 安全轮换当前 Owner 凭据，并验证新的本地凭据可用。
```

需要当前仍有效的 Owner API 凭据。Agent 先私有保存替代凭据，再原子撤销本次旧凭据并核验新凭据，保留其他设备。普通轮换没有 Web 操作入口；不要通过撤销当前设备模拟它。

## 恢复参与者身份

```text
请用 $cfkanban-admin 为 <参与者名称或稳定 ID> 检查身份恢复选项。
先说明 rotation 和 full_recovery 的撤销范围，核对准确身份后再创建恢复邀请。
```

仅 Owner 可为既有参与者签发恢复邀请，固定有效一小时。`rotation` 要求对方仍持有有效旧凭据，兑换后仅撤销本次使用的一份；`full_recovery` 不要求旧凭据，兑换后撤销该身份此前全部 API 凭据。两者保留稳定身份、既有权限、指派、历史和通行密钥，模式不能在兑换时更改。

**在网页中：** Owner 在「成员与权限」查找参与者并打开详情，核对稳定身份与恢复模式，确认继承和撤销范围后创建恢复邀请。邀请安全交付给本人，接收人在 Agent 中完成恢复；浏览器不保存替代长期凭据。Owner 也可在参与者详情查看并撤销其特定凭据或通行密钥，先核对相应登录失效影响。

## Owner 全部凭据丢失

仍有有效 Owner 管理网页会话，且服务端保留至少一份未撤销 API 凭据记录时，可按本页流程批准新设备。这不会自动撤销所有旧凭据。

无法使用上述路径，或需要统一撤销全部旧凭据时，使用具有 Cloudflare 控制权限的 [Owner 全失恢复](../deployment/recovery.md)。普通邀请、参与者恢复或重新部署空实例都不能替代它。
