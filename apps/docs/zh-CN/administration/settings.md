# 实例设置与用量

本页能力属于 Owner 的实例管理范围。工作区或项目管理员不具有全局设置、用量或安全审计权限。

## 首页实例说明

```text
请用 $cfkanban-admin 修改首页实例说明：
中文：<公开中文说明>
英文：<public English notice>
保存后核对两种语言。
```

说明对未登录访客公开，每种语言最多 500 个 Unicode 字符，仅作为纯文本显示。空值表示使用回退文案；中文缺失时先回退已配置英文，再使用内置说明。只改一种语言时，Agent 保留另一种语言的现有值。

**在网页中：** 「管理中心 → 概览 → 首页实例说明」提供中英文输入、保存和恢复默认。点击恢复默认只清空草稿，仍需保存才生效。

预期结果是两份说明读回一致，公开首页使用对应语言。不要在说明中填写私有项目内容、凭据或恢复链接。

## 查询用量

```text
请用 $cfkanban-admin 查看此实例的用量与剩余附件容量，并说明数据更新时间。
```

Agent 按缓存规则请求刷新，不会为了查看用量自动配置统计凭据或修改容量。结果区分附件应用预留预算与可选 Cloudflare D1/R2 指标。未知不等于零，实例用量不等于账户总用量或剩余免费额度。

**在网页中：** 「管理中心 → 概览 → 用量与限额」，可点击「刷新用量」；准确观测窗口在「数据详情」。Web 与 Agent 共用 15 分钟成功快照缓存和 60 秒尝试冷却；手动刷新也不绕过缓存。

附件预留量包括上传中、可用、软删除和未确认回收的文件。云端日累计量按 UTC 统计，容量指标可能延迟。显示「未配置」时，应用预算仍可能有效；启用云端指标见 [可选部署配置](../deployment/optional.md)。

## 选择附件容量

```text
请用 $cfkanban-admin 将此实例的附件应用容量上限设为 2 GiB，先检查当前预留量并读回设置。
```

也可明确请求「不限制」。未设置与不限制不同：未设置时暂停新增上传。Owner 选择正整数字节上限，或者明确取消应用容量上限；部署不会替你选择。设置容量本身不会开启 R2。

**在网页中：** 「概览 → 用量与限额 → 附件应用预算 → 设置上限」。选择容量模式，有限容量按 MiB 输入，保存后核对。`1 GiB = 1024 MiB`。降低上限不会删除已有文件，超出时暂停新上传。

预期只改变应用预算。它不是 R2 实际占用，也不是 Cloudflare 账单封顶；软删除文件需实际回收后才释放预算。

## 查看操作记录

```text
请用 $cfkanban-admin 查看 DemoProject 最近的权限变更记录，限定该项目，并说明实际操作者与变更对象。
```

**在网页中：** 「管理中心 → 操作记录」，按项目和事件流筛选，再加载更多。Agent 同样按明确范围分页读取。修改筛选条件会重新开始分页，不把旧游标用于新筛选。

审计用于核对已发生操作。历史授权来源与事件实际变更对象是不同字段，不能仅因为一条任务事件引用某个授权，就认定该事件修改了授权。

## 访问地址与频率限制

```text
请用 $cfkanban-admin 检查当前实例的首选 API 地址和已部署的访问频率限制，暂不修改。
```

**在网页中：** 「概览 → 服务信息与访问限制」只读展示发行版本、实例地址和请求限制。

修改已就绪的首选 API 地址使用 Agent：

```text
请用 $cfkanban-admin 检查 https://<新域名> 是否确实指向同一实例；
验证通过后提出首选 API 地址变更，并核对新旧入口。
```

目标先经不带凭据的探测验证，不能依赖跨域重定向转发认证。绑定域名、DNS 和 Worker 请求限制属于独立 [部署操作](../deployment/optional.md)，修改应用首选地址不会创建域名绑定。

## 保存失败时

版本冲突表示设置被其他操作修改，先读取最新内容并检查保留草稿。上次响应不确定时使用原保存的恢复入口；不要以多次新保存猜测结果。旧 Service 不支持某功能时，需要另行评估升级，安装新技能不会让服务器自动拥有该能力。
