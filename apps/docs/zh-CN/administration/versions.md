# 版本与更新

**网页入口：** 具有实例管理范围的 Owner 可打开 **管理中心 → 版本与更新**。页面展示当前实例实际产品版本及 GitHub 公开 `releases/latest` 重定向选定的正式版；另从公开发行列表第一页最多检查二十张卡片，展示最多五份预发行版。通道按 GitHub 原生 Pre-release 标记识别，列表按发行发布时间排序，每项链接到官方说明。

较新版本仍须核验兼容性和不可变工件；晚发布时间不能证明适合升级当前实例。预发行版须明确准确版本，不替代默认正式目标。发现直接读取 GitHub 公开网页，无需 token、不请求 REST API。成功信息在 Worker isolate 内缓存十五分钟，**重新检查** 可能复用缓存。网页访问受限或解析结构变化时展示未知或过期状态与检查时间，其他功能继续可用。

在 **交给 Agent 升级** 区选择准确版本，点击复制提示后交给自己的 Agent。也可以保留「先让 Agent 检查版本并由我选择」，先核对可用版本再确认目标。提示包含当前实例地址，要求先检查本机技能和插件、展示并确认本地更新计划，再展示并确认实例升级计划；两个步骤仍独立。

站点无法检查本地技能，复制提示也不会执行更新。Agent 应在本地核对 `cfkanban --version`、完整 bundle 和宿主安装，并在实例升级后读回实际版本、健康状态与原身份。详细步骤见[更新流程](../deployment/updates.md)。

```text
使用 $cfkanban-admin 检查此实例实际版本、可选正式版和预发行版。说明本地技能更新与实例升级的选择，不执行更新。
```

```sh
cfkanban admin updates show --json --no-interactive
```

API 为 `GET /api/v1/admin/release-updates`，仅限项目的 Owner Session 和局部管理员不能读取。同页的自动公告设置见[实例升级](../deployment/updates.md)。
