# 管理

`cfkanban-admin` 用于组织工作区与项目、管理成员和邀请，以及维护 Owner 的实例设置。日常任务协作见 [使用](../usage/index.md)，Cloudflare 资源维护见 [部署](../deployment/index.md)。

## 先确认可以管理什么

```text
请用 $cfkanban-admin 查看我在 <实例地址> 的身份与管理范围，并列出我可以管理的工作区和项目。
```

Agent 会返回当前可管理的工作区和项目。只读者或协作者不自动拥有管理权限；使用多个站点时请写明地址。

| 能力 | Owner | 工作区管理员 | 项目管理员 |
| --- | --- | --- | --- |
| 创建工作区、归档/恢复工作区 | 可以 | 不可以 | 不可以 |
| 创建项目 | 全实例 | 本工作区 | 不可以 |
| 项目名称、说明和列名称 | 全实例 | 全部子项目 | 本项目 |
| 普通成员与项目邀请 | 全实例 | 全部子项目 | 本项目 |
| 任免工作区管理员 | 可以 | 不可以 | 不可以 |
| 任免项目管理员 | 全实例 | 本工作区 | 不可以 |
| 归档/恢复项目 | 全实例 | 本工作区 | 不可以 |
| 公开加入、配额、全局用量和审计 | 可以 | 不可以 | 不可以 |
| 身份恢复、他人凭据、永久清理 | 可以 | 不可以 | 不可以 |

工作区管理员继承现在和未来全部子项目的管理和读写权限。普通成员的 `reader` 与 `writer` 授权独立存在；多种来源合并生效。Owner 是实例的唯一所有者，但 Owner 的应用凭据不授予 Cloudflare 控制权限。

## 打开管理页面

```text
请用 $cfkanban-admin 在 <指定浏览器> 打开我可以使用的管理页面。
```

**在网页中：** Owner 可从右上角账户菜单 →「管理中心」进入；完整管理入口是 `/app/admin`，包含「概览」「工作区与项目」「成员与权限」「操作记录」「已归档内容」。工作区或项目管理员从有权管理的看板进入「项目设置 → 项目管理」，只看到所属范围的设置、成员和项目。Agent 也可直接打开空工作区的管理页。

浏览器会话范围同样限制权限。Owner 只打开某个项目的会话时，不会自动获得实例管理界面；需要由 Agent 重新打开完整管理目标。页面未显示某个动作时，先检查当前身份、范围及已部署版本。
