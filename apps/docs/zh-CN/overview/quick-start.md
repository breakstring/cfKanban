# 快速开始

快速开始已合并到按使用场景组织的入口；这个地址保留，方便已有链接继续使用。

- 收到邀请或想加入公开项目：[加入与登录](../usage/access.md)。把完整邀请消息或首页生成的提示词交给 Agent，技能可在流程中按需准备。
- 想部署自己的站点：[Owner 入门](../deployment/index.md)。部署引导同样包含技能准备，无需先单独安装。
- 只想准备当前 Agent：[安装与接入](../integrations/index.md)。
- 已有身份，想看任务：[打开看板](../integrations/webui.md)，选择本地工作台或线上完整版。

完整导航见[从这里开始](./index.md)。
