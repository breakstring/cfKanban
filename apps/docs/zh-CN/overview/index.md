# 从这里开始

cfKanban 是人与 Agent 共用的任务看板。你可以让 Agent 记录和推进工作，也可以自己在网页里浏览、编辑和讨论；两种方式使用同一份任务与权限。

## 你要做什么？

| 你的情况 | 从这里继续 |
| --- | --- |
| 收到团队邀请，或想加入公开项目 | [加入与登录](../usage/access.md)：把完整邀请消息或首页生成的加入提示词交给 Agent |
| 已经加入，开始处理任务 | [日常协作](../usage/index.md)或[打开看板](../integrations/webui.md) |
| 负责工作区、项目或成员 | [管理工作区与项目](../administration/index.md)：使用你的管理范围，无需部署站点 |
| 想拥有自己的 cfKanban 站点 | [Owner 入门](../deployment/index.md)：准备、部署和维护自己的实例 |
| 只想先接入当前 Agent | [安装与接入](../integrations/index.md)：通用 Skills 或 DSH 插件 |

**首次加入和首次部署都可以按需安装技能。** 直接走对应引导即可，不必先完成一套独立安装教程。已有兼容安装会被复用；安装技能本身不会加入项目，也不会创建云端资源。

## 这份文档怎么读

- **开始使用**：共同需要的安装、打开看板和基本概念。
- **加入与使用**：普通成员的日常协作，以及工作区、项目管理员的操作。
- **部署与管理**：Owner 的实例设置、设备、升级和恢复。

安装完成后，可以直接向 Agent 描述任务，例如：

```text
请查看 DemoProject 中分配给我的未完成任务，按优先级列出，并打开看板。
```

文档中的 `DemoProject`、`CFK-123` 和尖括号内容需要换成你的目标。示例可能产生真实修改，只发送你确实希望执行的请求。

网页首页和应用页脚都有「文档」入口，无需退出看板。文档随站点版本提供；本地技能与站点分别更新。如果入口与这里不同，可以让 Agent 核对版本和权限。不了解实例、工作区与项目的区别时，先读[概念与角色](./concepts.md)。
