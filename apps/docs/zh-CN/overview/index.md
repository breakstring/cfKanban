# 概述

cfKanban 是让人与 Agent 共同使用的任务看板。你可以用自然语言让 Agent 查找、创建和推进任务，也可以在网页中查看看板、编辑内容、安排负责人和确认完成结果。两种入口使用同一套任务、权限与历史记录。

```text
请用 $cfkanban 查看 DemoProject 项目目前有哪些待办，
按优先级列出，并告诉我哪些已分配给我。先不要修改任务。
```

已有项目访问权限就可以开始。Agent 会读取指定项目并返回真实结果；你不必先部署自己的站点，也不必每次重新加入项目。

## Agent 与网页如何配合

| 你想做什么 | 合适的入口 |
| --- | --- |
| 在已有工作上下文里记录任务、搜索、补充进展 | 直接向 Agent 描述目标，使用 `cfkanban` 技能 |
| 浏览项目全貌、手动编辑、查看附件和讨论 | 网页看板与事项详情 |
| 邀请成员、配置项目与管理权限 | `cfkanban-admin` 技能，或对应范围的网页管理页 |
| 部署站点、维护云资源、更新技能或实例 | `cfkanban-deploy` 技能 |
| 了解能力与选择下一步 | 这份文档，或 `cfkanban-howto` 教学技能 |

Agent 和网页使用相同的项目权限。

## 这份文档怎么使用

在公开首页的页头或页脚打开「文档」。登录后，应用页脚也提供当前语言的文档和 GitHub 入口；文档在新标签中打开，原看板或管理页面可以继续保留，无需退出登录，也不会改变当前会话的访问范围。

也可以让 Howto 按问题查阅文档并引用来源：

```text
请用 $cfkanban-howto 根据 <实例地址> 的文档，解释如何在 DemoProject
查找优先级为高、带 bug 标签的任务。说明权限前提、网页入口，并附文档链接。
先只讲解，不要执行查询。
```

Howto 会查阅相关文档并提供来源；无法核实时会说明限制。讲解不需要登录，也不会执行示例中的操作。

每个功能先给出可以复制的 Agent 提示词，再说明权限、预期结果和网页操作。把 `DemoProject`、`CFK-123` 以及尖括号中的占位内容替换成自己的目标。示例中的请求可能产生真实修改；只发送你确实希望执行的内容。

文档中的「事项」「任务」都指 Issue。界面支持 English 和简体中文，任务正文、项目名、评论等协作内容不会自动翻译。项目管理员可以调整状态的显示名称，因此你的看板列名可能与文档默认名称不同。

文档随站点版本提供；本地技能与站点版本分别更新。若文档中的某个能力不可用，让 Agent 核对技能与实例版本，或阅读[概念与角色](./concepts.md)确认当前访问范围。
