# 技能更新与实例升级

本地技能和线上站点分别更新。更新技能不会自动升级站点。

## 检查版本

```text
请用 $cfkanban-deploy 检查本地 cfKanban 技能和 <实例地址> 的版本，
说明有哪些兼容的正式版更新，先不要更新。
```

**在网页中：** Owner 可在「管理中心 → 概览 → 服务信息与访问限制」查看站点版本。本机技能版本由 Agent 检查。

## 更新本地技能

```text
请用 $cfkanban-deploy 将本地 cfKanban 技能和当前 Agent 宿主的入口更新到最新兼容正式版。
不要升级线上站点。
```

只需本地安装权限，不需要 Cloudflare 登录。Agent 会核对兼容性并保留可恢复的旧版本。更新后，部分宿主需要新开会话才能加载新技能。

## 升级线上站点

```text
请用 $cfkanban-deploy 为 <实例地址> 准备升级到最新正式版的计划。
说明版本、数据库变化、预计影响和恢复方案，先让我确认，再执行。
```

需要当前 Owner 身份、Cloudflare 账户权限和本机维护记录。换电脑时先[接入已有部署](./attach.md)。Agent 会说明资源、数据及费用影响；升级完成后核对站点版本、访问能力和原有身份。

站点升级通过 Agent 完成，网页没有升级按钮。若旧技能无法处理新版发行，应先更新本地技能。

## 升级中断或失败

保留维护记录，让 Agent [沿原计划检查并继续](./recovery.md)。不要重新部署空实例，也不要手动删除记录。

回退服务程序不会回退数据库。恢复数据库可能覆盖新数据，需要单独确认；新增费用、域名或权限变化也应先说明。执行使用已确认的版本，不会中途自动换成刚发布的新版。
