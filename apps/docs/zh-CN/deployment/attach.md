# 在新电脑接入已有部署

换电脑时，先接入原来的 Owner 身份，再按需配置部署维护。无需重新部署站点。

## 接入 Owner 身份

```text
请用 $cfkanban-admin 把这台电脑接入 <实例地址>，使用同一个 Owner，设备名为“<名称>”。
```

由已有 Owner 设备或管理网页批准，再回到新电脑完成验证。详见[Owner 设备](../administration/devices.md)。若所有访问方式都已丢失，先查看[恢复路径](./recovery.md)。

完成这一步即可管理应用。要在新电脑上升级或维护云资源，再继续下面的步骤。

## 接入部署维护

```text
请用 $cfkanban-deploy 在这台电脑接入 <实例地址> 的已有部署，方便后续维护。
先不要升级站点或改动云端资源。
```

需要当前 Owner 身份及对应 Cloudflare 账户权限。Agent 会核对身份、账户、站点、云资源和现有设置，再在这台电脑安全保存维护记录。接入只写入本地记录，已有数据与访问保持不变。

这一步通过 Agent 完成，没有网页按钮。接入完成后，需要升级时再提出[升级请求](./updates.md)。

## 遇到问题

- **这台电脑已有另一身份：** 明确要求保留旧身份后切换，见[设备与身份恢复](../administration/devices.md)。
- **找到多个实例：** 核对目标地址和账户后再选择。
- **检查发现不一致：** 让 Agent 说明问题并核实，不手动改维护记录或重新初始化。
- **想复制旧电脑的数据目录：** 使用接入流程即可，不要把长期凭据放进聊天、仓库或共享目录。
